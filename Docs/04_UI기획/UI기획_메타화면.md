## 1. 개요

캠페인 맵 하단 바에서 진입하는 메타 화면 4종을 정의한다 (각 뎁스 +1, 취소로 캠페인 맵 복귀). 목업 v0.1의 제안대로 확정한다.

---

## 2. 상점

- 카테고리 탭 5종: 기체 / 기본 무기 / 특수무장 / 슈퍼웨폰 / 보호막
- 목록: 속성/환경 태그 + 이름 + 가격. 보유 장비는 목록 유지 + "보유" 표시 (재구매 불가). 재화 부족 시 가격 비활성 색
- **특화 슈퍼웨폰은 운용 환경을 태그와 상세 양쪽에 명시** ("운용 가능 전장: 지상전") — 사용 불가 상황을 모르고 구매하는 일 방지 (슈퍼웨폰 3.6 준수)
- 상세 패널: 태그 요약 / 운용 환경 / 설명 / 효과 요약
- 구매 = 소비적 행동, 확인 1회. 구매 즉시 보유 반영 (로드아웃 리스트 자동 등장). 구매 시 자동 저장 트리거

## 3. 시너지 도감

- 구조: 좌측 시너지 카드 그리드 (발견 진행 표시 "발견 N/M") + 우측 포커스 상세
- **발견 단계 4종 표시** (시스템_슬롯시너지 v0.5의 발견 단계 정의 준수):

| 단계 | 표시 |
|------|------|
| 1 미발견 | `? + ? = ?` |
| 2 부분 발견 | 보유 소재만 실명, 나머지 `?` |
| 3 조합 완성 | 조합 전체 공개 + 계열 힌트 ("공격 강화") + "로드아웃에서 함께 장착하면 완성" 안내 |
| 4 장착 발견 | 시너지명·드론·효과 완전 공개 (장착 순간 해금, 출격 불요) |

- 발견 기록은 게임 전체 공유 — 도감 진행은 세이브를 넘어 유지됨을 화면에 별도 표기하지 않는다 (자연 동작)
- 신규 발견(단계 4 도달)은 클리어 평가가 아닌 **장착 시점의 로드아웃 씬 강조**로 피드백 (시너지 활성 표시와 동기화). 평가 화면의 "신규 시너지 발견" 알림은 인게임 중 첫 활성화 등 보조 경로용으로 유지

## 4. 도전과제

- 목록 행: 이름 + 현재 단계 목표 설명 + 진행도 바 (수치/목표) + 다음 보상 미리 표시
- 단계형 도전과제는 **현재 단계의 목표만** 표시, 달성 시 다음 단계로 갱신 (전체 단계 리스트는 표시하지 않음 — 화면 과밀 방지)
- 달성 완료 행은 완료 표시 + 수령 완료 (보상은 자동 지급, 수령 조작 없음 — 장비 해금 시스템 준수)
- "도전과제는 모든 세이브 공유" 안내 문구 상시

## 5. 기록실

- 미션 × 난이도(Normal/Hard/Nightmare)별 최고 랭크 일람표 — 지도형 캠페인 맵이 갖지 못한 표 일람성을 이 화면이 흡수
- 격파율 최고 기록: 공중/지상 속성 색상 분리 표시
- 분기 미션 포함, 적용 제외 항목(해당 속성 적 없음)은 "—"
- 미션 선택 → 상세 기록 뷰 (클리어 당시 빌드·일시 등, 클리어 기록 데이터 기반) [제안 — 후순위]

|------|-----------|
| 상점 | 5탭, 특화 슈퍼웨폰 운용 환경 명시, 구매 확인 1회 + 즉시 반영 |
| 도감 | 발견 단계 4종 (점진 공개 + 3단계 계열 힌트 + 장착 시 완전 공개). 장착 = 발견, 출격 불요 |
