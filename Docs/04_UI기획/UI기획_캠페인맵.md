## 1. 개요 및 배치 결정

### 1.1 배치 결정 — A안: 작전 지도형

목업 v0.2의 3안 비교 결과 **작전 지도형**을 채택한다.

결정 근거:
- 전역을 훑으며 진군하는 캠페인 서사감 — 세계관 몰입이 세 안 중 최고
- 에이스컴뱃 X로 검증된 문법 (지도 위 미션 노드 + 분기 연결선)
- 분기 힌트("?" 노드 + 파생 연결선)가 지도 공간에서 갈라져 보여 ③ 분기 노출 정책의 표현력이 좋음
- 환경 타입(지상전/해상전/고고도)이 지형과 자연스럽게 대응

동적캠페인 시스템 7.2에서 UI 기획으로 미뤄둔 "그래프 형태" 결정이 본 결정으로 확정된다 (자유 그래프 — 지도 위 배치).

### 1.2 화면 구조

```

```

## 2. 지도 표현

- 지도는 스타일라이즈드/로우폴리 톤으로 아트 비용을 통제한다 [제안 — 아트 방향과 함께 확정]
- 미션 노드는 캠페인 진행 방향의 공간 흐름을 따라 배치한다 (진군 서사)
- 환경 타입과 지형 대응: 지상전=내륙, 해상전=해역. 고고도 미션은 지형 무관 위치 가능하며 노드 표기로 구분 [제안]
- 1편 규모(미션 10 + 분기)는 단일 화면 수용을 기본으로 한다 [검증 — 초과 시 가벼운 팬 도입]

## 3. 노드·연결선 표기

### 3.1 노드 상태 (동적캠페인 v0.4 7.4 준수)

| 상태 | 표기 |
|------|------|
| 클리어 | 클리어 표시 + 최고 랭크 |
| 현재 선택 가능 | 강조 테두리 |
| 순차 잠김 | 잠김 + 조건 공개 ("미션 N 클리어 필요") |
| 분기 해금 | 본선과 구분되는 시각 처리 (색상/형태) |
| 분기 힌트 (미해금) | "?" 노드 + 파생 연결선, 조건 비표시 (③ 정책) |
| 신규 해금 직후 | 강조 연출 (동적캠페인 7.5) — "?"가 정식 노드로 전환되는 연출 [제안] |

### 3.2 연결선

- 클리어된 경로: 실선 / 미진행 경로: 점선 / 분기 파생선: 본선과 구분되는 색 [색상은 아트 확정 시]

---

## 4. 미션 상세 패널

- 미션 번호·이름 / **전장 환경 태그 (항상 표시 — 공개 정보, 특화 슈퍼웨폰 구매·장착 판단 근거)** / 최고 기록 (종합 랭크) / 브리핑 요약 한 줄
- 난이도 선택: 해금 상태 표시 + 잠김 사유 공개 ("HARD는 NORMAL 클리어 시 해금" — 난이도 해금은 분기가 아니므로 항상 공개)
- 확인 → 브리핑 진입 (선택된 미션+난이도로 출격 컨텍스트 시작)

---

## 5. 허브 기능

- 하단 바에서 단축키 직접 진입: 상점 / 시너지 도감 / 도전과제 / 기록실 / 프리셋 관리 (각각 뎁스 +1, 취소로 복귀)
- 재화 상시 표시 (상단 바)
- 이 화면은 취소 연타 복귀의 종착점이다 (공통 1호 — 어느 하위 화면에서든 취소 연타로 여기까지)
