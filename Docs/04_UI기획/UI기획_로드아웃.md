## 1. 개요 및 배치 결정

### 1.1 배치 결정 — D안: 무뎁스 3컬럼 + 프리뷰 무대 (잠정 채택)

목업 v0.3의 4안 비교 결과 D안을 채택한다. **잠정 결정이며, 프로토타입 사용감에 따라 변경 여지를 남긴다.**

결정 원칙:
- **뎁스 최소화** — UI 뎁스 증가는 플레이어가 보고 눌러야 하는 피로의 증가다. 장비 변경의 핵심 동선은 모달 없이 공간 이동만으로 완결한다 (뎁스 0)
- **프리뷰 상시 비가림** — 동작 프리뷰 무대는 어떤 조작 상태에서도 가려지지 않는다
- **격납고 분위기는 레이아웃이 아니라 배경·아트 스타일로 표현한다** — 감상성을 위해 뎁스를 늘리지 않는다 (뎁스를 늘리는 감상형 재검토는 후순위 보류)

### 1.2 화면 구조

```
[상단 바] ◀브리핑 | 미션명 | 환경 태그 | 적 구성 힌트(Normal만)
┌────────────┬───────────┬─────────────────┐
│ PREVIEW    │ SLOTS     │ EQUIPMENT       │
│ 동작 프리뷰  │ 슬롯 6종   │ 포커스 슬롯의     │

│────────────│           │ (자동 갱신)      │
│ 상세/스탯    │ 활성 시너지 │                 │
└────────────┴───────────┴─────────────────┘
[하단 바] 프리셋 | 상세 | 뒤로 | ————— 출격
```

## 2. 조작 동선 (무뎁스 문법)

| 조작 | 동작 |
|------|------|
| 슬롯 컬럼에서 상하 | 슬롯 포커스 이동 → 우측 장비 리스트 **자동 갱신** (열고 닫는 단계 없음) |
| 슬롯에서 우측 이동 (또는 확인) | 장비 리스트로 포커스 진입 |
| 리스트에서 상하 | 장비 포커스 이동 → **프리뷰 무대 즉시 재생 전환 + 상세/스탯 갱신** |
| 리스트에서 확인 | 장착 확정 — 즉시 반영, 시너지 재평가 |
| 리스트에서 취소 | 슬롯 컬럼으로 포커스 복귀 (화면 전환 없음) |
| 취소 (슬롯 컬럼에서) | 브리핑으로 복귀 |
| 프리셋 키 | 프리셋 패널 열기 (6장 — 여기만 뎁스 +1 허용) |
| 출격 | 확정 확인 1회 → 출격 (검증 통과 시) |

장착은 별도 저장 없이 즉시 반영된다. 현재 로드아웃 상태는 자동 보존 (세이브 시스템의 현재 로드아웃 상태 관리를 따름).

## 3. 동작 프리뷰 (확정 요건)

**모든 장비는 리스트에서 포커스되는 순간 실제 동작이 프리뷰 무대에서 반복 재생된다.** 스탯 지표보다 실동작이 정보량이 크다는 판단에 따른 필수 요건이다.

### 3.1 장비별 프리뷰 내용

| 장비 | 프리뷰 내용 |
|------|-------------|
| 기본 무기 | 발사 패턴 반복 (연사 리듬, 탄 형태) |
| 특수무장 | 발사 패턴 반복 + 속성 표적 명중 데모 (대공이면 공중 표적, 대지면 지상 표적) [제안] |
| 슈퍼웨폰 | 발동 연출 축소판 반복 (지원형은 진입, 기체형은 확산의 축약 표현) |
| 보호막 | 피격 흡수 → 파괴 → (파괴 시 효과) 데모 반복 |
| 기체 | **회전 감상 뷰** + 특성 요약 표시 — 무대가 기체 감상을 겸한다 [제안] |
| (참고) 시너지 드론 | 시너지 활성 시 무대의 기체 옆에 드론 동행 표시 [제안] |

### 3.2 구현 방향 [제안]

사전 제작 영상이 아닌 **실제 게임 데이터 기반 미니 씬 반복 재생**:
- 별도 미니 씬(렌더타겟)에서 해당 장비의 실제 발사/효과 로직을 구동
- 밸런스·패턴 수정이 프리뷰에 자동 반영 — 프리뷰 컨텐츠의 별도 제작·갱신 비용 없음
- 인게임 자산(모델, 이펙트) 그대로 재활용
- 성능·구현 부담은 프로토타입에서 검증 [검증]

## 4. 요소별 명세

### 4.1 슬롯 카드 (중앙 컬럼, 6종)

- 표시: 슬롯명 / 장착 장비명 / 속성 태그 (색+문자 이중 코딩)
- **특수무장 슬롯 1·2는 속성 자유 슬롯** — 슬롯명은 "특수무장 1/2"로만 표기하고 속성을 붙이지 않는다. 속성 태그는 장착된 장비의 것이며, 동일 속성 2개 장착도 정상 상태다 (목업의 대공+대지 조합은 예시 빌드일 뿐)
- **특수 1·2는 할당 키 라벨 고정 표시** (입력 v0.2 이관 — HUD와 동일 라벨)
- 빈 슬롯: 명확한 공백 표시 + 출격 차단 사유로 연결

### 4.2 장비 후보 리스트 (우측 컬럼)

- 보유 장비만 표시 [제안] (미보유 장비의 상점 유도 표시는 7호 상점과 함께 재검토)
- 항목 표시: 속성/운용 환경 태그, 장착 중 표시
- **환경 특화**: 현재 전장과 일치하는 특화 장비는 프리미엄 강조
- **환경 부적합**: 잠금 표시 + 사유 문구 ("이 전장에서는 운용 불가 — 고고도"). 포커스는 가능(정보 열람), 장착만 차단
- 정렬 [제안]: 장착 중 → 사용 가능 → 부적합(잠금) 순

### 4.3 상세/스탯 패널 (좌측 하단)

- 장비명 / 분류·태그 요약 / 효과 요약
- 스탯 지표 1~10 바 + **현재 장착 대비 증감 표시** (▲▼)

### 4.4 활성 시너지 패널 (중앙 컬럼 하단)

- **현재 빌드의 활성 시너지 항상 표시** (기존 결정 — 타 빌드 시너지는 비표시)
- 장비 변경으로 시너지가 활성/해제되는 순간 강조 연출 (빌드 실험의 피드백)
- 표시: 시너지명 + 활성 드론 요약. 발견 단계별 표시 상세는 7호(도감)와 함께 확정

### 4.5 상단 바

- 브리핑 복귀 / 미션명 / **전장 환경 태그 (항상 표시 — 공개 정보)** / 적 구성 힌트 (Normal만)

### 4.6 출격 검증 표시 (3층위)

| 검증 | 표시 방식 |
|------|-----------|
| 빈 슬롯 | 출격 시도 시 차단 + 해당 슬롯 강조 |
| 환경 부적합 슈퍼웨폰 | 장착 단계에서 차단 (4.2) — 출격 시점엔 발생하지 않음 |
| 빌드 유효성 경고 (Normal만) | 출격 시도 시 경고 1회 + 진행 선택 가능 |

## 5. 프리셋 패널

- 프리셋 키로 열리는 패널 — **의도된 뎁스 +1** (사용 빈도가 낮은 보조 기능이므로 핵심 동선의 무뎁스 원칙 예외)
- 기능: 현재 빌드 저장 (이름 입력) / 불러오기 / 덮어쓰기 / 삭제 (파괴적 행동은 확인 1회)
- 불러오기 시 미보유 장비는 빈 슬롯 처리 + 안내 (기존 결정 준수)
- 목록 표시: 프리셋명 + 기체 + 슬롯 요약 아이콘 [제안]

## 6. 프로토타입 검증 항목

| 항목 | 확인 내용 |
|------|-----------|
| 무뎁스 동선 체감 | 슬롯↔리스트 포커스 이동이 설명 없이 자연스러운지 |
| 프리뷰 반응 속도 | 리스트 포커스 이동 시 프리뷰 전환 지연 체감 |

| 재세팅 루프 속도 | 평가 → 로드아웃 재세팅 → 재출격 소요 시간 (1호 루프 속도 원칙) |
| 3컬럼 정보 밀도 | 과밀 여부, 프리뷰 무대 크기 적정성 |

## 7. 확정 사항 요약

| 항목 | 결정 사항 |
|------|-----------|
| 배치 | D안 — 무뎁스 3컬럼 + 좌측 프리뷰 무대 (**잠정**, 프로토타입 후 재평가) |
| 뎁스 원칙 | 핵심 동선(장비 변경) 뎁스 0. 뎁스 증가 = 플레이어 피로 증가. 프리셋만 예외 +1 |
| 격납고 분위기 | 레이아웃이 아닌 배경·아트 스타일로 표현 |
| 동작 프리뷰 | 전 장비 포커스 시 실동작 반복 재생 — 확정 요건. 실데이터 미니 씬 방식 [제안] |
| 기체 프리뷰 | 회전 감상 뷰 + 특성 요약 (무대가 감상 겸용) [제안] |
| 환경 적합성 표시 | 특화 프리미엄 강조 / 부적합 잠금+사유, 포커스 가능·장착 차단 |
| 시너지 표시 | 현재 빌드 활성 시너지 상시 + 활성/해제 순간 강조 |
| 장착 반영 | 즉시 반영, 자동 보존 |
