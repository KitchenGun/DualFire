## 1. 개요 및 배치 결정

### 1.1 배치 결정 — C안: 연출 + 스택형

목업 v0.1의 3안 비교 결과 C안을 채택한다.

결정 근거:
- **연출과 루프 속도의 양립** — 평가 항목 순차 도장 연출로 클리어 보상감을 만들되, 아무 키 스킵으로 즉시 전체 표시 (첫 클리어의 긴장감 + 반복 플레이의 속도)
- **다중 알림 무조작** — 알림은 스택 표시라 동시 발생 개수와 무관하게 조작 0회 (순차 카드형의 조작 피로 배제)
- **확장 대응력** — 평가 항목·알림 종류가 변경되어도 리스트 행 추가/삭제로 대응, 화면 구조 불변

### 1.2 화면 구조

```
[클리어 배너] 미션명 | CLEAR | 보수
┌──────────────────┬──────────┬───────────────┐
│ 평가 항목 리스트     │ 종합 랭크  │ 알림 스택        │
│ (항목·값·랭크 5행)   │ + NEW    │ (해금·보상·발견)  │
│                  │   BEST   │                │
└──────────────────┴──────────┴───────────────┘
[하단 바] 기록 비교(TAB) | ——— 미션 선택으로 | 리플레이(강조)
```

## 2. 표시 흐름 (연출 시퀀스)

1. 화면 진입 → 클리어 배너 즉시 표시
2. 평가 항목이 위에서부터 순차 도장 연출로 등장 (항목당 짧은 간격)
3. 종합 랭크 등장 (+ 최고 기록 갱신 시 NEW BEST 강조)
4. 알림 스택 등장
5. 행동 버튼 활성 (연출 완료 전에도 스킵 입력으로 즉시 활성)

**스킵:** 아무 키 입력 시 연출을 중단하고 전체를 즉시 표시한다. 스킵 입력이 행동 버튼 조작으로 오입력되지 않도록 스킵 직후 짧은 입력 무시 간격을 둔다 [제안].

**연출 길이:** 연출 총 길이가 리플레이 루프 속도의 상한이 되므로 짧게 유지한다. 전체 3초 이내 [제안], 구체 값은 프로토타입 검증 [검증].

## 3. 요소별 명세

### 3.1 클리어 배너

- 미션명 / CLEAR 표시 / 미션 보수 (랭크 반영 최종액)

### 3.2 평가 항목 리스트

- 5행: 공중 격파율 / 지상 격파율 / 피탄 / 스코어 / 사망
- **공중·지상 격파율 항목명은 속성 색상으로 표시** (공통 1호 색상 코딩) — "지상이 낮네, 대지 무장을 보강해 리플레이" 판단이 이 화면에서 일어난다. 코어 루프의 귀결점이므로 두 항목의 시인성을 최우선으로
- 각 행: 항목명 / 실측값 / 항목 랭크 (S~D)
- **적용 제외 항목**: 해당 미션에 존재하지 않는 평가 대상(예: 공중 적 0)은 "해당 없음"으로 표시하고 랭크 산출에서 제외 (클리어 평가 시스템 준수)
- 랭크 색상은 아트 확정 시 지정 [검증] (목업 가정: S금/A녹/B청/C회/D적)

### 3.3 종합 랭크

- 화면 내 최대 크기 요소 — 이 화면의 주인공
- 최고 기록 갱신 시 NEW BEST 표시 + 강조 연출

### 3.4 알림 스택

- 1호 공통의 우선순위로 정렬: ①분기 미션 해금 ②장비/기체 해금 ③도전과제 달성 ④난이도 해금 (시너지 발견 알림은 로드아웃 씬 즉시 표시로 이관 — 평가 화면에서 발생하지 않음)
- 알림 유형별 좌측 컬러 코드 [제안]
- 조작 불필요 — 확인 없이 정보 열람만. 상세 확인은 각 메타 화면(도감·도전과제)에서
- 표시 한도 초과 시(드묾) 스크롤 또는 "+N건" 축약 [제안]

### 3.5 행동 버튼

- **리플레이 (최강조, 우하단)** — 동일 미션·동일 난이도로 브리핑부터 재진입 (게임플로우 준수)
- 미션 선택으로 — 캠페인 맵 복귀
- 취소 키 = 미션 선택으로 (허브 복귀 보장)

### 3.6 기록 비교 (상세 뷰) [제안]

- TAB(탭 전환 키)으로 이전 최고 기록과의 항목별 비교 뷰 전환
- 기본 화면에는 넣지 않는다 — 기본 화면의 정보 밀도 유지

## 4. 미션 실패 시 화면 (확정)

리플레이 루프 속도를 위해 **간이 실패 화면**을 둔다 (기반시스템_게임플로우씬구조 v0.2에 반영):

- 표시: 실패 사유 (격추 / 중도 이탈) — 평가 산출 없음 (시스템 준수)
- 행동: 리플레이 (최강조) / 미션 선택으로
- 실패 직후가 재도전 동기가 가장 높은 순간이므로, 캠페인 맵을 경유하지 않는 즉시 리플레이 동선을 보장한다

## 5. 프로토타입 검증 항목

| 항목 | 확인 내용 |
|------|-----------|
| 연출 총 길이 | 보상감과 루프 속도의 균형점 (3초 이내 [제안]) |
| 스킵 반응성 | 아무 키 스킵의 즉시성 + 오입력 방지 간격 |
| 격파율 시인성 | 공중/지상 분리 표시가 리플레이 판단으로 이어지는지 |
| 리플레이 도달 시간 | 화면 진입 → 리플레이 입력까지 최단 시간 측정 |
| 다중 알림 표시 | 4건 이상 동시 발생 시 스택 가독성 |

## 6. 확정 사항 요약

| 항목 | 결정 사항 |
|------|-----------|
| 배치 | C안 — 연출 + 스택형 (평가 순차 연출 + 알림 스택 + 스킵) |
| 연출 | 순차 도장 → 종합 랭크 → 알림 스택. 아무 키 스킵 → 즉시 전체 표시. 총 3초 이내 [제안] |
| 알림 | 스택 표시, 조작 0회. 우선순위 정렬 (1호 준수) |
| 격파율 표시 | 공중/지상 속성 색상 분리 — 시인성 최우선 |
| 행동 | 리플레이 최강조 (우하단). 취소 = 허브 복귀 |
| 기록 비교 | TAB 상세 뷰 분리 [제안] |
| 실패 화면 | 간이 실패 화면 + 즉시 리플레이 — 확정 (게임플로우 v0.2 반영) |
