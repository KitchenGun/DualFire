## 1. 개요

본 문서는 게임 전체 UI에 적용되는 공통 원칙, 공통 컴포넌트, 용어 통일을 정의한다. 화면별 상세 기획은 후속 문서에서 다룬다.

UI 기획 문서 체계:

| 호 | 문서 | 범위 |
|----|------|------|
| 1호 | UI 공통 (본 문서) | 전 화면 공통 원칙·컴포넌트 |
| 2호 | 인게임 HUD | 플레이 중 표시 정보 |
| 3호 | 로드아웃 (격납고) | 장비 선택·프리셋·시너지 표시 |
| 4호 | 클리어 평가 | 평가 결과·보상·알림 |
| 5호 | 캠페인 맵 (허브) | 미션 선택·메타 진입 |
| 6호 | 브리핑·세이브·타이틀·옵션 | 단순 화면 묶음 |
| 7호 | 메타 화면 | 상점·시너지 도감·도전과제·기록실 |

## 2. UI 설계 원칙

### 2.1 시선 집중

인게임 정보는 플레이필드 안에서 해결한다. 플레이어의 시선이 플레이필드 밖으로 나가야만 얻을 수 있는 게임플레이 정보를 만들지 않는다. (HUD 필드 내 오버레이 결정의 근거 — 2호 참고)

### 2.2 연출 우선

**UI는 연출을 가리지 않는다.** 좌우 영역은 월드 배경과 연출의 전용 공간이며 UI를 배치하지 않는다. 필드 내에서도 대형 연출과 UI가 충돌할 경우 연출이 우선한다 (처리 정책은 2호).

### 2.3 루프 속도

리플레이 루프(평가 → 재출격)의 조작 동선을 최소로 유지한다.

- 취소 연타로 어느 하위 화면에서든 허브(캠페인 맵)까지 복귀 보장 (입력 v0.2)
- 확인 단계는 파괴적·소비적 행동에만, 1회 상한 (출격 확정, 구매, 삭제, 덮어쓰기)
- [검증] 평가 화면에서 재출격까지의 조작 횟수·소요 시간을 프로토타입에서 측정하고 본편 목표치로 삼는다

### 2.4 정보 공개 정책 준수

UI는 정보의 공개/숨김 등급을 시스템 정의에 따라 일관되게 표현한다.

| 정보 | 공개 정책 | 근거 문서 |
|------|-----------|-----------|
| 전장 환경 | 항상 공개 | 슈퍼웨폰 3.6 / 스테이지구조 2.2 |
| 적 구성 힌트 | Normal만 표시 | 난이도 시스템 |
| 빌드 유효성 경고 | Normal만 작동 | 로드아웃 시스템 |
| 분기 조건 | [미정 — 5호 전까지 결정] | 동적 캠페인 시스템 |
| 시너지 상세 | [미정 — 7호 전까지 결정] | 슬롯 시너지 시스템 |

### 2.5 조작 문법 일관

입력 v0.2의 메뉴 공통 문법 5종(방향/확인/취소/탭 전환/상세 보기)을 전 화면에서 동일하게 유지한다. 화면마다 다른 조작 규칙을 만들지 않는다.

## 3. 속성 색상 코딩

지상/공중 속성 분리가 게임의 코어이므로, **속성을 나타내는 색상을 UI 전반에서 통일**한다.

| 속성 | 색상 | 사용처 |
|------|------|--------|
| 대공 (공중) | [검증] 아트 방향 확정 후 지정 | 장비 속성 표시, HUD 특수무장 슬롯, 적 구성 힌트, 평가 화면 공중 격파율, 도감 |
| 대지 (지상) | [검증] 〃 | 〃 (지상 계열) |
| 범용 (양면) | [검증] 〃 | 범용 장비 표시 |

원칙:
- **색 + 형태 이중 코딩** — 색상만으로 구분하지 않고 아이콘/문자를 병행한다 (색각 이상 대응)
- 속성 색상은 게임플레이 의미 전용으로 예약한다. 장식·강조 등 다른 용도로 같은 색을 쓰지 않는다
- 구체 색상 값은 아트 방향(로우폴리 팔레트) 확정 시 함께 지정 [검증]

## 4. 공통 컴포넌트

### 4.1 확인 다이얼로그

파괴적·소비적 행동에만 사용: 출격 확정, 상점 구매, 세이브 삭제/덮어쓰기, 프리셋 삭제/덮어쓰기. 그 외 행동에는 확인 단계를 두지 않는다.

### 4.2 알림 (획득·해금)

미션 클리어 시 발생 가능한 알림 종류와 기본 우선순위 [제안]:

1. 분기 미션 해금
2. 장비/기체 해금 (도전과제 보상)
3. 도전과제 달성/단계 클리어
4. 신규 시너지 발견
5. 난이도 해금

동일 시점 다중 발생 시 위 순서로 정렬해 순차 표시. 구체 표시 방식(스택/순차 카드)은 4호에서. 인게임 중에는 게임플레이를 방해하는 알림을 띄우지 않는다 (모든 획득 알림은 평가 화면으로 이연).

### 4.3 버튼 프롬프트

활성 입력 장치(마지막 입력 기준) 아이콘으로 표시, 장치 변경 시 즉시 전환 (입력 v0.2). 각 화면 하단에 현재 가능한 조작의 프롬프트 바를 상시 표시한다.

### 4.4 포커스 표시

패드/키보드 조작의 현재 포커스는 테두리+명도 변화로 표시. 마우스 호버와 포커스는 동일한 시각 처리를 공유한다.

### 4.5 스탯 지표

장비 성능은 1~10 지표 바로 표시한다 (수치 직접 노출 대신). 지표 종류는 장비 데이터 정의를 따른다. 비교 상황(교체 후보 선택 중)에서는 현재 장착 대비 증감을 함께 표시한다 [제안].

### 4.6 탭 바

한 화면 내 카테고리 전환(로드아웃 슬롯 종류, 도감 페이지 등)은 상단 탭 바 + 탭 전환 키로 통일한다.

## 5. 텍스트·가독성

- 최소 폰트 크기 기준은 해상도 대응 정책과 함께 [검증]
- 숫자는 천 단위 구분자 표기 (스코어, 재화, 가격)
- 게임 용어 통일 (전 UI 동일 표기):

| 용어 | 표기 통일 |
|------|-----------|
| 속성 | 대공 / 대지 / 범용 |
| 생존 | 체력 / 보호막 / 잔기 |
| 슈퍼웨폰 | 게이지 / 스톡 |
| 스코어 | 스코어 / 체인 |
| 평가 | 종합 랭크 / 항목 랭크 (S~D) |
| 환경 | 지상전 / 해상전 / 고고도 |

## 6. 시스템 문서 이관 항목 인덱스

각 시스템 문서에서 "UI 기획으로 이관"된 항목의 처리 위치:

| 이관 항목 | 출처 | 처리 문서 |
|-----------|------|-----------|
| HUD 배치 (좌우 영역 vs 필드 내) | 좌표계카메라화면규격 | **결정 완료 — 필드 내 오버레이.** 상세는 2호 |
| 연출 중 HUD 처리 | 좌표계카메라화면규격 | 2호 |
| 특수무장 슬롯-키 대응 표시 | 입력 v0.2 | 2호 (HUD) + 3호 (로드아웃) |
| 현재 빌드 시너지 표시 | 슬롯 시너지 | 3호 |
| 환경 부적합 슈퍼웨폰 차단 표시 | 로드아웃 v0.5 | 3호 |
| 알림 표시 순서·방식 | 게임플로우씬구조 | 4호 |
| 분기 조건 노출 정책 | 동적 캠페인 | 5호 (결정 필요) |
| 적 구성 힌트 표시 | 미션 브리핑 | 6호 |
| 리매핑 화면 | 입력 v0.2 | 6호 |
| 시너지 도감 발견 단계 | 슬롯 시너지 | 7호 (결정 필요) |
| 상점 운용 환경 표시 | 슈퍼웨폰 3.6 | 7호 |
