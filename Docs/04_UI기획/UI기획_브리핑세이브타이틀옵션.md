## 1. 개요

배치 자유도가 낮은 4개 화면을 묶어 정의한다. 목업 v0.1의 단일 제안대로 확정하되, **본 4화면은 게임 루프 검증을 위한 기준선이며 고도화 단계에서 연출·아트 중심의 재작업을 전제**로 한다. 아래 명세는 구조·정보·상태 분기의 기준이다.

---

## 2. 브리핑

- 구성: 미션명 + 환경 태그 + 난이도 (상단) / 브리핑 본문 / 적 구성 힌트 / 지역 발췌 맵 / 목표 (우측)
- **분기 메시지 변형**: 브리핑 본문은 분기 충족 상태에 따라 변형본으로 치환된다 (미션 브리핑 시스템 준수). 변형 여부를 플레이어에게 별도 고지하지 않는다 — 서사가 자연스럽게 달라질 뿐
- **정보 차등**: 적 구성 힌트는 Normal에서만 표시. Hard 이상은 "사전 정보가 제공되지 않는다" 문구로 대체. 환경 태그와 목표는 난이도 무관 상시 표시
- 힌트 내 속성 언급은 속성 색상 코딩 적용
- 조작: 뒤로 = 캠페인 맵 (자유 왕복), 진행 = 로드아웃, 텍스트 스킵 지원

## 3. 세이브 슬롯

- 5슬롯 고정. 사용 슬롯 표시: 캠페인 진행도 / 진행 난이도 / 플레이 타임 / 마지막 플레이 일시
- **빈 슬롯에 도전과제 누적 보상 고지**: "누적 보상 지급: CR N · 해금 장비 N종 사용 가능" — 게임 전체 공유 보상이 새 세이브에 적용됨을 시작 전에 안내 (장비 해금 시스템의 일시 지급 정책 UI 반영 지점)
- 삭제 = 파괴적 행동, 확인 다이얼로그 1회

## 4. 타이틀

- 메뉴: 계속하기 / 세이브 선택 / 옵션 / 종료 [확정]
- **계속하기 = 최상단 기본 포커스 + 대상 슬롯 요약 표시** — 마지막 세이브로 즉시 진입 (루프 속도 원칙의 시작점)
- 로고·배경은 아트 영역 (자리만 확보)

## 5. 옵션

- 카테고리 4탭: 게임플레이 / 사운드 / 화면 / 조작 [확정]
- 조작 탭: 게임패드 = 프리셋 선택, 키보드 = 전체 리매핑. 패드/키보드 할당을 한 행에 병기. 충돌 시 경고 후 교체(swap). 기본값 복원 제공 (입력 v0.2 준수)
- 옵션 변경 = 자동 저장 트리거. 설정은 게임 전체 공유 저장
- 오버레이 접근: 어느 씬에서든 진입 가능 (게임플로우 준수)

## 6. 확정 사항 요약

| 항목 | 결정 사항 |
|------|-----------|
| 성격 | 루프 검증 기준선 — 고도화 시 재작업 전제 |
| 브리핑 | 분기 메시지 변형 (무고지) + 힌트 난이도 차등 + 환경 태그 상시 |
| 세이브 | 5슬롯, 빈 슬롯에 누적 보상 고지, 삭제 확인 1회 |
| 타이틀 | 계속하기 기본 포커스 + 슬롯 요약 |
| 옵션 | 4탭, 조작은 패드 프리셋 + 키보드 리매핑 병기, 게임 전체 공유 |
