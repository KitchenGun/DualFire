## 1. 개요 및 배치 결정

### 1.1 배치 결정 — 필드 내 오버레이

HUD는 **플레이필드 내부 가장자리에 반투명 오버레이**로 배치한다. 좌우 영역에는 어떤 UI도 배치하지 않는다.

결정 근거 (목업 v0.2 비교 검증):
1. **시선 집중** — 레터박스 배치는 플레이어 시야를 플레이필드 밖으로 분산시킴
2. **연출 우선** — 좌우 영역에 정보를 배치하면 슈퍼웨폰 등 연출 발생 시 정보가 연출을 가리는 본말전도 발생

### 1.2 경계 처리와의 관계

필드 ↔ 좌우 영역 경계는 명도·채도 차이 + 지형 그림자 밴드로 처리하며(좌표계카메라화면규격 v0.3), 밴드 색상은 레벨 환경 팔레트에 맞춘다. HUD는 이 경계 안쪽에만 존재한다.

## 2. HUD 구역 배치

플레이어 기체가 주로 화면 하단부에 위치하므로, 조작 중 시야에 가까운 **하단 두 코너에 실시간성 높은 정보**를, 상단에 누적성 정보를 배치한다.

| 구역 | 표시 정보 | 성격 |
|------|-----------|------|
| 좌하 | 체력 / 보호막 / 잔기 | 생존 정보 (실시간) |
| 우하 | 슈퍼웨폰 게이지+스톡 / 특수무장 1·2 쿨다운 | 화력 자원 (실시간) |
| 좌상 | 스코어 / 체인 | 누적 정보 |
| 상단 중앙 | 보스 체력바 (보스전에만) | 전투 대상 정보 |
| 중앙 | 시스템 메시지 (WARNING, 미션 시작/종료) | 순간 표시 |

- 우상단은 비워둔다 — 적 등장 빈도가 높은 상단 시야를 확보 [제안]
- 모든 HUD 요소는 판정에 관여하지 않는다 (시각 전용)

## 3. 요소별 명세

### 3.1 체력 / 보호막 / 잔기 (좌하)

- 체력: 세그먼트 표시 (총량이 정수 단위이므로). 피격 시 해당 세그먼트 소실 강조, 체력 1 잔여 시 상시 위험 표시 [제안]
- 보호막: 세그먼트 또는 바. 파괴 후 회복 대기/회복 중 상태를 구분 표시. 보호막 종류별 특수 효과(파괴 시 폭발 등)는 연출 영역
- 잔기: 아이콘 × 수량. 기본 1이므로 평상시 존재감 낮게, 증가 시(특성/시너지) 표시

### 3.2 슈퍼웨폰 게이지 / 스톡 (우하)

- 게이지 바: 충전 진행 표시. 100% 도달(스톡 생성) 순간 강조
- 스톡: 아이콘 개수 표시. 사용 가능 스톡이 있으면 저채도 상시 강조 [제안]
- 스톡 0에서 발동 시도 시 간단한 시각 피드백 (슈퍼웨폰 시스템 5.5 준수 — 경고음 없음)

### 3.3 특수무장 슬롯 1·2 (우하)

- 슬롯별 독립 표시: 장비 아이콘 + **속성 색상**(공통 1호의 색상 코딩) + **할당 키 라벨** + 쿨다운 마스크
- 슬롯-키 대응은 고정이며 HUD에 상시 표시 (입력 v0.2 이관 항목 — 가려 쏘기 조작의 근육 기억 지원)
- 쿨다운 완료 순간 짧은 강조 (발사 가능 신호)

### 3.4 스코어 / 체인 (좌상)

- 스코어: 자릿수 고정 + 천 단위 구분
- 체인: 현재 배율 + 유지 타이머 바. 끊김 임박 시 시각 경고 (깜박임 등). 체인 갱신 시 배율 숫자 강조
- 격파 순간의 점수 팝업(+1,200 등)은 격파 위치에 표시하는 연출 영역이며 HUD 상시 요소가 아님 [제안]

### 3.5 보스 체력바 (상단 중앙, 보스전 한정)

- 보스 진입 시 WARNING 연출 후 체력바가 채워지는 등장 연출 (기존 결정 준수)
- Shared 모드: 단일 바. PerPhase 모드: 페이즈 구간 표시가 있는 바
- 현재 페이즈 표기. 파츠 상태(파괴 가능/파괴됨)는 바에 통합하지 않고 보스 본체 위 표시로 처리 [제안 — 시각 과밀 방지]

### 3.6 시스템 메시지 (중앙)

- WARNING(보스), 미션 시작/클리어/실패 배너
- 표시 중에도 게임 판정은 정상 진행되므로 중앙 시야를 오래 점유하지 않는다 (짧은 등장 → 축소/소멸)

## 4. 가독성·반투명 정책

- HUD 기본 상태는 반투명 [검증 — 구체 투명도 값은 프로토타입에서]
- 배킹(배경판)은 최소화하고 아이콘·바 자체의 외곽선으로 탄막 위 가독성을 확보한다
- **기체 근접 페이드**: 플레이어 기체가 HUD 코너 영역에 진입하면 해당 코너의 HUD 투명도를 일시적으로 높여(더 투명하게) 기체와 탄막 시인성을 우선한다 [제안]
- 탄막 최대 밀도 구간에서의 가독성은 프로토타입 검증 항목

---

## 5. 연출과의 관계

- 좌우 영역 연출(지원형/기체형 슈퍼웨폰, 편대 통과 등)과 HUD는 구조적으로 간섭하지 않는다 (배치 결정의 효과)
- 필드 내 대형 연출(슈퍼웨폰 발동 등) 중에도 HUD는 유지한다 [제안 — 전투 판정이 계속되므로 생존/화력 정보 상실 불가]
- 판정이 정지되는 컷씬성 연출(보스 등장 WARNING 등) 중에는 HUD를 딤 처리 [제안]

---

## 6. 프로토타입 검증 항목

| 항목 | 확인 내용 |
|------|-----------|
| 탄막 위 가독성 | 최대 탄막 밀도에서 HP/쿨다운 식별 가능 여부 |
| 코너 잠식 체감 | 하단 코너 HUD가 기동 공간을 침해하는 체감 여부, 기체 근접 페이드 동작 |
| 투명도 값 | 기본/근접 페이드 투명도 확정 |
| 체인 타이머 시인성 | 끊김 임박 경고가 플레이 중 인지되는지 |
| 슬롯-키 라벨 | 가려 쏘기 조작 시 키 라벨 참조가 실제로 일어나는지 |
