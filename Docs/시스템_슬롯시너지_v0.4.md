## 1. 개요

본 문서는 **기체 슬롯 시너지 시스템**의 세부 설계를 정의한다. 플레이어가 로드아웃 슬롯에 특정 조합을 장착하면 기체 주변에 **드론**이 활성화되어 추가 화력 또는 보조 효과를 제공하는 시스템이다.

이 시스템은 빌드 설계의 한 축으로 작동하며, 시너지 조합 발견 자체가 게임의 탐색 동기 중 하나가 된다.

---

## 2. 시스템 철학

### 2.1 효과는 드론으로 통일

시너지 효과는 **드론 활성화로 통일**한다. 단순 스탯 버프나 무기 변환 방식이 아닌, 기체 주변에 드론이 등장하는 방식으로 모든 시너지를 표현한다.

### 2.2 드론 방식을 채택한 이유

- **시각적 즉각 인식:** 기체 주변에 드론이 표시되므로 시너지 활성화 여부가 한눈에 보인다. 1~10 추상화 스탯 표기 환경에서도 시너지 발동을 명확히 체감할 수 있다.
- **공간적 전투 깊이:** 드론의 위치가 게임플레이 변수가 되어, 종스크롤 슈팅에서 드문 공간 전투의 깊이를 만든다.
- **개발 공수 효율:** 무기 변환 방식 대비 데이터 관리가 단순하다. 드론 자체를 정의하고, 시너지 조건 → 드론 매핑만 관리하면 된다.
- **시스템 일관성:** 슈퍼웨폰의 효과 기반 설계와 동일한 철학(효과 데이터로 정의)을 따른다.

## 3. 드론 분류

### 3.1 공격 방식별 분류

| 분류 | 동작 | 플레이 스타일 |
|------|------|---------------|
| 자율공격형 | 드론이 자율적으로 적을 인식하고 공격 | 멀티태스킹 부담 감소, 보조 화력 |
| 추가화력형 | 플레이어 사격에 동기화되어 함께 발사 | 화력 집중 강화, 단발 위력 증대 |

### 3.2 위치 패턴별 분류

조합에 따라 드론의 위치 패턴이 결정된다.

| 위치 패턴 | 설명 | 게임플레이 의미 |
|-----------|------|-----------------|
| 양옆 | 기체 좌우에 드론 배치 | 좌우 적 동시 커버 |
| 전방 | 기체 앞쪽에 드론 배치 | 전방 화력 보강, 방패 역할 가능 |
| 후방 | 기체 뒤쪽에 드론 배치 | 후방 안전 확보, 후방 적 대응 |
| 회전 | 기체 주변을 회전 | 전방위 커버, 방어적 활용 |

### 3.3 역할별 분류

| 역할 | 설명 |
|------|------|
| 공격형 드론 | 적에게 데미지를 주는 것이 주 역할 |
| 방어형 드론 | 적탄을 흡수하여 플레이어 보호 |

## 4. 드론 사양

### 4.1 드론 구성

드론은 공격 방식(자율공격형/추가화력형), 위치 패턴(양옆/전방/후방/회전 등), 역할(공격형/방어형), 무기 정보(속성 포함), 동시 등장 개수(1~4), 적탄 흡수 한계와 재활성화 시간(4.4절 참고), 시인성 컬러(4.6절 참고)를 가진다.

활성화 조건은 드론 데이터에 포함되지 않으며, 시너지 데이터에서 정의한다 (5절 참고).

(본 시스템의 데이터 항목 세부 정의는 별도의 데이터 테이블 문서에서 관리한다.)

### 4.2 드론은 격파되지 않음

드론은 **적의 공격에 의해 격파되지 않는다.** 체력 개념을 두지 않으며, 미션 내내 시너지 활성 상태가 유지된다.

이는 다음 문제를 방지하기 위함이다.

- **격파 용이성:** 드론이 기체 주변에 위치하므로 사실상 히트박스 확장이 되어, 난이도가 올라가면 드론이 활약하기 전에 격파되기 쉬움.
- **빌드 의미 손상:** 시너지 빌드를 짠 보상이 드론 격파로 짧게 끝나면 빌드의 가치가 떨어짐.

드론은 시너지의 시각적·기능적 표현체이며, 별도의 생존 자원으로 관리하지 않는다.

### 4.3 드론 활성화 타이밍

시너지가 충족되면 **미션 시작 시점부터 드론이 활성화**된다. 미션 진행 중 활성화/비활성화 토글은 없으며, 출격과 동시에 드론이 등장한다.

### 4.4 일시 비활성화 메커니즘

방어형 드론이 영구 방패가 되어 과도하게 강력해지는 것을 방지하기 위해, **일시 비활성화 메커니즘**을 둔다.

| 메커니즘 | 동작 |
|----------|------|
| 흡수 한계 도달 | 드론이 일정 수 이상의 적탄을 흡수하면 일시 비활성화 |
| 재활성화 시간 경과 | 비활성화 후 일정 시간이 지나면 자동 재활성화 |

흡수 한계와 재활성화 시간은 드론 데이터에서 개별 설정한다.

| 드론 유형 | 일반적 설정 |
|-----------|-------------|
| 공격형 드론 | 흡수 한계 0(무제한). 일시 비활성화 없음. |
| 방어형 드론 | 흡수 한계와 재활성화 시간 데이터 설정에 따라 강도 차별화 |

방어형이라도 약한 드론은 흡수 한계가 낮고 쿨다운이 길게, 강한 드론은 그 반대로 설정될 수 있다.

비활성화 상태에서는 드론이 적탄을 흡수하지 않으며, 시각적으로도 비활성 상태임이 표현된다(외곽선 색상 변화 등).

### 4.5 드론 무기와 속성

드론이 사용하는 무기에도 **지상/공중 속성**이 적용된다. 판정 분리 시스템의 관통 방식이 동일하게 적용된다.

이 속성 적용이 시너지 시스템의 핵심 가치 중 하나이다. 예를 들어:

- 대공 특화 빌드(대공 무장 위주)에서 시너지로 대지 드론이 활성화되면, 약점인 지상 페이즈를 드론이 커버한다.
- 범용 안정형 빌드에서 시너지로 대공 드론이 추가되면, 부족한 폭발력을 보강한다.

드론의 속성과 플레이어 무장의 속성 조합이 빌드 설계의 한 축이 된다.

### 4.6 드론 시인성 처리

드론은 별도의 모델링 또는 스프라이트를 가지며, 적과 구분되는 시각적 처리를 적용한다.

- **외곽선 컬러 이펙트:** 드론 주변에 붉은색/푸른색/노란색 등 명확한 색상의 외곽선 이펙트를 부여하여 적과 구분
- **드론 수 제한:** 활성화되는 드론 수는 **최대 4개**. 그 이상은 화면이 시끄러워져 플레이어 기체 식별을 방해할 수 있음
- **비활성 상태 표현:** 일시 비활성화 시 외곽선 색상 변화로 상태를 표현

조합의 강력함에 따라 드론 수가 차등 설정된다. 기본 시너지는 1~2개, 강력한 시너지나 후반 조합은 3~4개로 설정한다.

## 5. 시너지 활성화 조건

### 5.1 매칭 방식 (이중 구조)

시너지 활성화 조건은 **태그 기반 매칭**과 **ID 기반 매칭**의 두 가지 방식을 지원한다.

| 매칭 방식 | 동작 | 적용 |
|-----------|------|------|
| 태그 기반 | 장비에 부여된 태그 조합으로 매칭 | 흔한 조합의 일반 드론 |
| ID 기반 | 특정 장비 ID 조합으로 매칭 | 숨겨진 조합 또는 후반 강력 드론 |

### 5.2 태그 기반 매칭

장비마다 태그(예: `Air`, `Heavy`, `Energy` 등)가 부여되어 있고, 시너지 조건이 태그 조합으로 정의된다.

**예시:**
- "Air 태그 무장 + Air 태그 무장" = 대공 화력 집중 드론
- "Energy 태그 보호막 + Energy 태그 무장" = 에너지 회전 드론

같은 태그를 가진 장비라면 어떤 것을 장착해도 시너지가 활성화된다. 장비 추가에 유연하게 대응 가능하다.

### 5.3 ID 기반 매칭

특정 장비 ID 조합에서만 발동되는 시너지. 플레이어가 직접 발견하기 전까지는 알 수 없는 숨겨진 조합 또는 매우 강력한 후반 드론에 사용한다.

**예시:**
- "장비 A + 장비 B" = 시크릿 드론 X
- 후반 해금 장비 + 특정 무장 = 강력 드론 Y

ID 매칭은 발견의 재미를 만들고, 빌드 탐색 동기를 강화한다.

### 5.4 우선순위 처리

태그 매칭과 ID 매칭이 동시에 가능한 경우, **ID 매칭이 우선**된다. ID 매칭이 더 구체적이고 의도적인 시너지이므로, 태그 매칭으로 활성화될 광범위 시너지보다 우선 적용된다.

### 5.5 시너지 구성

시너지는 매칭 방식(태그 기반/ID 기반), 매칭 조건(태그 조합 또는 장비 조합), 활성화되는 드론의 지정으로 구성된다.

활성화 조건은 시너지 데이터에서 관리하며, 드론 데이터에는 포함되지 않는다. 드론은 시너지의 결과물로 작동한다.

(본 시스템의 데이터 항목 세부 정의는 별도의 데이터 테이블 문서에서 관리한다.)

## 6. 시너지 적용 슬롯 범위

### 6.1 무장 속성 조합 중심

시너지는 **무장 속성 조합**을 중심으로 운영한다. 무장 속성은 범용/대공/대지의 3종이며, 이 3종의 조합으로 시너지 다양성을 확보한다.

기본 무장 슬롯 + 특수무장 2개 슬롯 기준 6가지 동질/이질 조합이 가능하다.

| 조합 | 시너지 방향성 |
|------|---------------|
| 대공 + 대공 | 공중 화력 집중 |
| 대지 + 대지 | 지상 화력 집중 |
| 범용 + 범용 | 광역 균형 |
| 대공 + 대지 | 양면 커버 |
| 대공 + 범용 | 공중 강화 + 안정 |
| 대지 + 범용 | 지상 강화 + 안정 |

여기에 ID 기반 매칭으로 특정 장비 조합 시너지까지 더하면 시너지 종류가 충분히 풍부해진다.

### 6.2 슬롯 조합 허용 범위

시스템은 **무장 슬롯과 슈퍼웨폰 슬롯의 조합**을 시너지 활성화 조건으로 허용한다. 단, **기체와 보호막은 시너지 활성화 조건에 포함되지 않는다.**

| 제외 항목 | 사유 |
|-----------|------|
| 기체 | 기체와 시너지는 독립적인 시스템으로 운영 |
| 보호막 | 시너지 종류 폭증 방지 (공수 관리) |

지원 가능한 조합 예시:

| 조합 | 활용 방향성 |
|------|-------------|
| 특수무장 2개 | 기본 시너지 (가장 자유도 높음) |
| 기본 무기 + 특수무장 | 안정적 빌드의 시너지 |
| 슈퍼웨폰 + 무장 | 슈퍼웨폰 카테고리 태그(공격/방어/유틸/복합) + 무장 속성 조합 |

슈퍼웨폰은 **카테고리 태그**를 시너지 매칭 조건으로 사용한다. 슈퍼웨폰의 효과 기반 설계 특성상 슈퍼웨폰 자체에 단일 속성이 부여되지 않으므로, 카테고리 태그가 시너지 매칭의 진입점 역할을 한다.

### 6.3 데이터 기반 제어

실제 어떤 조합을 시너지로 활용할지는 **데이터에서 제어**한다. 초기에는 특수무장 2개 조합 위주로 시작하고, 후속 컨텐츠 추가 시 다른 조합도 활용 가능하다. 시스템 코드 변경 없이 데이터만 추가하면 된다.

## 7. 시너지 발견과 표시

### 7.1 현재 빌드 시너지의 로드아웃 씬 표시

로드아웃 씬에서 **현재 장착한 빌드 조합으로 활성화되는 시너지는 항상 표시**된다. 어떤 시너지가 활성화될지, 어떤 효과인지 명시되어 플레이어가 출격 전 자신의 빌드를 전략적으로 검토할 수 있다.

표시 방식:
- 활성화될 드론의 이름과 효과 안내
- 첫 발견 시에는 "신규 시너지 발견" 같은 추가 강조 가능 (UI 디자인에서 결정)

### 7.2 다른 빌드의 시너지는 비표시

활성화 가능한 모든 시너지 목록을 로드아웃 화면에서 미리 보여주지는 않는다. 플레이어가 다양한 조합을 시도하면서 시너지를 발견하는 것 자체가 게임의 재미이며, 현재 빌드에서 활성화되는 시너지만 표시함으로써 발견의 재미와 전략적 빌드 양쪽을 모두 살린다.

### 7.3 활성화 시 명확한 피드백

미션 출격 후 시너지가 활성화되면 다음 피드백을 제공한다.

- 드론이 시각적으로 등장하는 연출
- 드론 이름이 화면에 일시적으로 표시
- 활성화 효과음

특히 **첫 발견 시**에는 발견 강조 연출을 추가하여 "새로운 시너지를 발견했다"는 쾌감을 강화한다.

### 7.4 시너지 도감

한 번 발견한 시너지는 시너지 목록(도감 형태)에 기록된다. 도감에서 발견한 시너지의 활성화 조건과 효과를 다시 확인할 수 있다. 미발견 시너지는 도감에 잠금 상태로 표시되어, "아직 발견하지 못한 시너지가 N개 있다"는 정보가 추가 탐색 동기를 만든다.

**도감 보존 단위: 게임 전체 공유.** 시너지 발견은 플레이어의 탐색 결과이므로, 새 세이브 데이터를 시작해도 이미 발견한 시너지는 도감에 유지된다.

## 8. 시스템 간 연동 지점

| 연동 시스템 | 연동 내용 |
|-------------|-----------|
| 로드아웃 시스템 | 슬롯 조합이 시너지 활성화 조건의 입력 |
| 기체 시스템 | 독립적. 기체는 시너지 활성화 조건에 포함되지 않음. |
| 슈퍼웨폰 시스템 | 슈퍼웨폰의 카테고리 태그가 시너지 매칭 조건으로 활용 |
| 지상/공중 판정 분리 시스템 | 드론 무기의 속성 판정 |
| 생존 시스템 | 방어형 드론의 적탄 흡수 (플레이어 보호) |
| 플레이어 기동 시스템 | 드론 활성화에 의한 간접적 기동 영향 가능 |
| 장비 해금 시스템 | ID 기반 시너지의 후반 드론 해금 |

## 10. 확정 사항 요약

| 항목 | 결정 사항 |
|------|-----------|
| 효과 표현 | 드론 활성화로 통일 |
| 드론 공격 방식 | 자율공격형 / 추가화력형 |
| 드론 위치 패턴 | 조합에 따라 결정 (양옆/전방/후방/회전 등) |
| 드론 역할 | 공격형 / 방어형 |
| 드론 격파 | 없음. 영구 파괴되지 않음. |
| 드론 활성화 타이밍 | 미션 시작 시점부터 활성화 |
| 일시 비활성화 | 흡수 한계 도달 시 일시 비활성화, 재활성화 시간 후 자동 복귀 |
| 드론 무기 속성 | 지상/공중 판정 적용 |
| 드론 수 | 1~4개 (조합 강도에 따라 차등) |
| 드론 시인성 | 외곽선 컬러 이펙트로 적과 구분 |
| 매칭 방식 | 태그 기반 + ID 기반 이중 구조 |
| 매칭 우선순위 | ID 매칭이 태그 매칭보다 우선 |
| 활성화 조건 위치 | 시너지 데이터에서 관리 (드론 데이터 아님) |
| 시너지 다양성 | 무장 속성 3종(범용/대공/대지) 조합 중심 |
| 적용 슬롯 범위 | 무장 슬롯 + 슈퍼웨폰 슬롯 조합. 기체와 보호막은 제외. |
| 시너지 표시 | 현재 빌드의 시너지는 로드아웃 씬에서 표시. 다른 빌드의 시너지는 비표시. |
| 시너지 도감 | 게임 전체 공유 (세이브 데이터 무관) |
