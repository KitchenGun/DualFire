## 1. 개요

본 문서는 게임의 **시나리오 기획 토대**를 정의한다. 시스템 기획이 완료된 시점에서 시나리오의 큰 방향성, 세계관 골격, 캠페인 구조의 큰 틀을 정리한다.

세부 시나리오 작업(미션별 내용, 진영 역학의 구체적 배치, 분기 조건, 엔딩 분기, 브리핑 텍스트, 설정 도감 등)은 본 문서 이후 단계적으로 검토하며, 시나리오 작업이 게임 전체 플로우와 시스템 흐름에 미칠 영향을 신중히 평가하면서 진행한다.

---

## 2. 작업 방향성

### 2.1 미니멀 시나리오 노선

이 게임의 시나리오는 **플레이가 메인이고 스토리는 배경**인 구조로 운영한다. 거대한 정치 드라마나 깊은 캐릭터 서사를 추구하지 않으며, 다음 원칙을 따른다.

- 큰 흐름과 미션 컨셉 중심으로 작업
- 깊은 드라마 또는 캐릭터 서사 지양
- 후속작 가능성만 열어두는 수준의 마무리
- 메인 스토리는 가볍게, 설정 도감(기체/무기/적)은 풍부하게

### 2.2 두 갈래 시나리오 작업

시나리오 작업은 두 갈래로 분리한다.

| 작업 | 내용 |
|------|------|
| 메인 캠페인 시나리오 | 큰 줄기, 미션별 짧은 브리핑/엔딩 텍스트, 분기별 변경 메시지 |
| 설정 도감 | 기체/무기/적 유닛의 설정 텍스트와 백그라운드 |

작업 우선순위는 메인 캠페인이 먼저이며, 큰 줄기가 잡힌 후 설정 도감을 컨텐츠 추가와 함께 채워나간다.

## 3. 세계관 골격

### 3.1 시대 배경

**현대와 미래 무기가 공존하는 근미래.** 구체적 연도는 명시하지 않는다. 명시할 경우 후속작 작업 시 시간 제약이 생길 수 있으므로, 흐릿한 근미래 톤을 유지한다.

현대 군사 무기는 그대로 등장하며, 외계 기술 역공학 또는 비밀 조직의 시제품 형태로 미래 무기가 추가되는 구조이다.

### 3.2 3진영 구도

세계관은 C&C 타이베리안 시리즈의 GDI/NOD/스크린 구도를 참고한 **3진영 구도**로 운영한다.

#### 3.2.1 다국적 연합 (플레이어 소속)

- 정통성 있는 다국적 군사 연합 정부
- 플레이어는 다국적 연합 정부 산하 **비밀 특수항공대** 소속
- 외계 병기에 대해 인지하고 있으나 대중에게는 비공개. 정보 통제.
- 외계 병기를 연구/통제하려는 입장. 활성화된 외계 병기는 격퇴 대상.
- 비밀 조직이라는 설정이 다양한 임무 수행, 정보 비대칭, 장비 구매 컨셉을 정당화

#### 3.2.2 반체제 세력

- 카리스마형 지도자 중심의 혁명/이념 세력
- **자신들만의 명분과 신념**을 가진 세력. 단순한 악당이 아님.
- 외계 병기를 자신들의 이상 실현 도구로 사용
- 외계 병기의 진짜 정체나 위험성은 완전히 모름. 강력한 무기로만 인식.

#### 3.2.3 외계 잔존 세력

- 고대 외계 문명의 잔존 병기로 처음 등장
- 무인 자율 병기로 시작하지만 캠페인 후반에 자체 의지 또는 본체의 그림자가 드러남
- 반체제가 도구로 사용하지만, 외계 자체는 별도의 목적과 의지를 가진 독립 세력
- 활성화 원인이 1편의 핵심 미스터리. 본격적 위협은 후속작 떡밥으로 남김

### 3.3 3진영 구도의 장점

- **적의 입체감:** 반체제가 단순 악당이 아닌 명분을 가진 세력이 되어 캠페인 적의 매력이 강화
- **다양한 미션 구도:** 진영별 또는 진영 조합별로 다양한 미션 톤이 가능
- **후반 반전 가능성:** 외계 본체가 후반에 본격 등장하는 구조로 임팩트 확보
- **분기 시스템과의 시너지:** 진영 간 관계가 분기 조건과 결과의 다양성을 만듦
- **후속작 떡밥:** 1편에서 외계 정체를 부분적으로만 드러내고 본격 외계 전쟁을 후속작으로 이전

## 4. 캠페인 구조

### 4.1 캠페인 규모

| 항목 | 결정 |
|------|------|
| 기본 루트 미션 수 | 10개 |
| 막 구조 | 3-4-3 (1막 3미션, 2막 4미션, 3막 3미션) |
| 분기 미션 비율 | 미션 번호의 60~70%에 분기 변형 존재 (목표) |
| 총 콘텐츠 미션 수 | 분기 포함 14~17개 정도 |

### 4.2 캠페인 진행 방식

**즉시 리플레이 방식**을 채택한다. 회차 개념을 두지 않으며, 미션 클리어 후 언제든지 해당 미션을 재선택하여 리플레이 가능.

#### 4.2.1 진행 모델

- 미션 클리어 시 다음 미션 해금
- 클리어된 미션은 캠페인 맵에 "클리어됨" 상태로 표시되며 자유롭게 리플레이 가능
- 분기 미션 해금 시 캠페인 맵에 새 노드 추가, 자유 플레이 가능
- 모든 기본 루트 미션 클리어 시 분기 누적에 따라 엔딩 미션 해금
- 엔딩 도달 후에도 모든 미션과 분기 탐색 지속 가능

#### 4.2.2 즉시 리플레이를 채택한 이유

이 게임의 다른 시스템들이 모두 즉시 리플레이를 전제로 설계되어 있다.

- 빌드 다양성 시스템 (기체/로드아웃/슬롯 시너지)을 같은 미션에서 반복 실험 가능
- 도전과제 누적 조건 (예: 공중 격파율 S랭크 3회) 달성에 적합
- Hard 이상 난이도의 적 구성 변화를 학습하려면 반복 플레이 필요
- 동적 캠페인 분기 탐색을 캠페인 재시작 없이 자유롭게 시도 가능

회차 단위 방식은 이야기 몰입이 가장 중요한 게임에 적합하나, 본 게임은 미니멀 시나리오 노선이므로 회차 단위 방식의 장점을 살릴 필요가 적다.

### 4.3 막별 큰 흐름

#### 4.3.1 1막 — 도입 (미션 1~3)

큰 흐름: 다국적 연합 비밀 특수항공대로 출격. 평범한 반체제 토벌 임무로 시작하지만 임무 도중 정체불명의 외계 병기와 조우. 1막 마지막에 외계 병기와 반체제의 연관성에 대한 단서 발견.

미션 컨셉 후보:

- **미션 1 — 입문 작전:** 시스템 소개. 반체제 거점 정찰/소규모 토벌. 인류 측 군사 유닛만 등장. 외계 요소 없음.
- **미션 2 — 본격 토벌:** 반체제 거점 공격. 미션 막바지에 정체불명의 외계 병기 첫 등장 (스크립트성).
- **미션 3 — 첫 조우:** 1막 보스 미션. 외계 병기 + 반체제 결합형 보스. 격파 후 양자 연결 단서 획득.

#### 4.3.2 2막 — 전개 (미션 4~7)

큰 흐름: 외계 병기와 반체제의 결합 본격화. 3진영이 모두 활발히 등장하는 구간. 분기 활용이 가장 활발.

미션 컨셉 후보:

- **미션 4 — 추적:** 반체제의 외계 병기 조달 경로 추적. 반체제 위주, 외계 일부.
- **미션 5 — 양면 전선:** 다국적 연합 시설 공격하는 반체제 vs 그 와중에 등장한 외계 잔존 병기. 3진영 혼전.
- **미션 6 — 외계 거점:** 외계 잔존 병기 활성화 거점 공격. 순수 외계 적. 외계 보스 등장.
- **미션 7 — 반체제 핵심:** 반체제 본거지 공격. 2막 보스 미션. 외계 병기를 가장 적극 활용하는 반체제 정점.

#### 4.3.3 3막 — 결말 (미션 8~10)

큰 흐름: 외계 잔존 세력이 자체 의지를 가진 독립 세력임이 드러남. 활성화 원인 추적과 최종 결전. 엔딩 분기 발생.

미션 컨셉 후보:

- **미션 8 — 본체의 그림자:** 외계 자체 의지 드러남. 외계 핵심 시설 또는 거대 외계 병기와의 결정적 전투. 활성화 원인 일부 공개.
- **미션 9 — 결전 준비:** 최종 결전 직전. 누적 분기 선택에 따른 분기점 위치.
- **미션 10 — 최종 결전:** 분기 누적에 따른 엔딩 분기 발생.

## 5. 진영 역학 (방향성)

3진영의 단순 대립이 아닌, **진영 간 배신/협력/위기**의 입체적 역학을 캠페인에 도입한다. 단, 구체적인 배치는 추후 면밀히 검토한다.

### 5.1 검토 대상 패턴

| 패턴 | 내용 | 예시 |
|------|------|------|
| 반체제의 외계 배신 | 외계가 자체 의지를 드러내며 반체제 자체가 외계의 도구로 역이용됨 | 미션 7~8 사이 전환 |
| 외계가 양측에 몰리는 상황 | 다국적 연합과 반체제가 일시적으로 외계라는 공동 위협 앞에 협력 | 후반 미션 |
| 진영 내부 분열 | 반체제 내 외계 이용 반대 분파, 다국적 연합 내 비공식 협력 모색 세력 등 | 캠페인 곳곳 |
| 외계 본체의 진짜 등장 | 자율 병기 너머의 외계 본체/의지가 드러남. 캠페인의 진짜 위협. | 3막 후반 |

### 5.2 검토 원칙

- 각 패턴이 캠페인 어느 시점에 어떻게 등장할지 신중히 배치
- 분기 시스템과의 결합 시 시나리오 작업량 폭증 가능성 고려
- 게임 전체 플로우와 시스템 흐름에 미치는 영향 평가
- 시간을 들여 여러 각도에서 검토 후 확정

## 6. 추후 검토 항목

다음 항목들은 본 토대 위에서 단계적으로 검토하고 확정한다.

| 항목 | 내용 | 검토 우선순위 |
|------|------|--------------|
| 미션별 구체적 내용 | 기본 루트 10미션 각각의 상세 시나리오 | 높음 |
| 진영 역학의 구체적 배치 | 어느 미션에 어떤 패턴을 넣을지 | 높음 |
| 분기 미션 위치와 조건 | 어느 미션 번호에 어떤 분기 조건을 걸지 | 높음 |
| 엔딩 수와 분기 조건 | 엔딩 미션의 수와 결정 조건 | 중간 |
| 미션 브리핑 텍스트 | 각 미션의 브리핑 메시지 | 중간 |
| 분기 변경 메시지 | 동적 캠페인 연동 메시지 (난이도별 차등) | 중간 |
| 캐릭터 설정 | 지휘관 NPC, 반체제 지도자 등 | 낮음 |
| 설정 도감 | 기체/무기/적 유닛의 설정 텍스트 | 낮음 (컨텐츠 단계) |

## 8. 확정 사항 요약

| 항목 | 결정 사항 |
|------|-----------|
| 시나리오 노선 | 미니멀 (플레이 메인, 스토리는 배경) |
| 작업 분리 | 메인 캠페인 시나리오 + 설정 도감 |
| 시대 배경 | 현대와 미래 무기 공존 근미래 (구체적 연도 미명시) |
| 진영 구도 | 3진영 (다국적 연합 / 반체제 / 외계 잔존 세력) |
| 플레이어 소속 | 다국적 연합 정부 산하 비밀 특수항공대 |
| 외계 정체성 | 잔존형 + 부분 활성. 활성화 원인은 1편의 미스터리. |
| 캠페인 규모 | 기본 루트 10미션, 3-4-3 막 구조 |
| 분기 비율 목표 | 미션 번호의 60~70%에 분기 변형 |
| 진행 방식 | 즉시 리플레이 (회차 개념 없음) |
| 진영 역학 | 단순 대립 아닌 배신/협력/위기 도입 (구체 배치 추후 검토) |
| 후속작 처리 | 1편에서 외계 본격 위협은 부분 노출만, 본격 전쟁은 후속작 떡밥 |
