## 1. 개요

본 문서는 플레이어가 출격 전 장비를 세팅하는 **로드아웃 시스템**의 시스템 로직을 정의한다. 로드아웃은 이 게임에서 플레이어가 전략적 판단을 내리는 핵심 지점이며, 지상/공중 판정 분리 시스템 위에서 동작하는 가장 상위의 플레이어 경험 시스템이다.

본 시스템은 기체 시스템과 결합하여 작동한다. 플레이어는 기체를 선택한 후 그 기체에 장비를 세팅하며, 프리셋은 기체+장비 조합을 함께 저장한다.

기체 슬롯 조합에 따른 시너지 효과는 본 문서의 범위를 벗어나며, **기체 슬롯 시너지 시스템 세부 기획**에서 다룬다. UI 기획은 별도 단계에서 다룬다.

## 2. 로드아웃 슬롯 구조

### 2.1 슬롯 구성

플레이어는 출격 전 다음 슬롯에 장비를 장착한다.

| 슬롯 | 수량 | 장착 가능 속성 |
|------|------|----------------|
| 기본 무기 | 1 | 범용 / 대공 / 대지 |
| 특수무장 | 2 | 범용 / 대공 / 대지 (각 슬롯 독립 선택) |
| 슈퍼 웨폰 | 1 | 효과 기반 설계 (슈퍼웨폰 시스템 참고) |
| 보호막 | 1 | 속성 없음 |

기체 선택 또한 출격 전 결정되며, 본 슬롯과 함께 로드아웃을 구성한다 (기체 시스템 참고).

### 2.2 장비 선택 자유도

해금·보유 중인 장비는 **등급, 속성, 종류에 따른 조합 제한 없이** 자유롭게 선택할 수 있다. 이는 로드아웃 시스템의 근간 원칙이며, 플레이어의 빌드 자유도를 최대한 보장한다. 단, 슈퍼웨폰의 전장 환경 적합성(2.4)처럼 **해당 장비 자체의 운용 조건에 따른 장착 제한은 적용**된다 — 조합의 제약이 아니라 운용 가능성의 제약이다.

극단적 빌드(예: 특수무장 2개 모두 대공) 역시 플레이어의 선택으로서 허용된다.

**동일 장비 중복 장착 허용:** 같은 특수무장을 두 슬롯에 중복 장착할 수 있다. 각 슬롯은 별도의 런타임 무장 인스턴스를 생성하며, 쿨다운과 사용 상태를 독립적으로 관리한다. 동일 장비 조합 시너지(예: 대공 미사일 ×2)가 슬롯 시너지 시스템에 이미 존재하므로, 중복 장착은 설계 전제다.

### 2.3 빈 슬롯 처리

**모든 슬롯이 채워져야 출격이 가능**하다. 빈 슬롯이 하나라도 있으면 출격이 차단되며, 어떤 슬롯이 비어 있는지 안내 메시지가 표시된다.

이는 빌드 유효성 경고와는 다른 차원의 "필수 조건 미충족" 처리이다. 빌드 유효성 경고는 출격 자체를 막지 않지만, 빈 슬롯은 출격 자체가 불가능하다.

### 2.4 슈퍼웨폰 환경 적합 검증

슈퍼웨폰 슬롯은 출격 대상 스테이지의 **전장 환경 태그**와 슈퍼웨폰의 **운용 환경 태그**를 매칭하여 장착 가능 여부를 판정한다 (매칭 규칙은 슈퍼웨폰 시스템 3.6절).

- 환경 부적합 슈퍼웨폰은 **장착 단계에서 차단**된다 — 장착해놓고 인게임에서 발동이 안 되는 방식이 아니라, 애초에 선택할 수 없게 하고 사유를 표시한다 ("이 전장에서는 운용 불가 — 고고도 전장")
- 이 검증은 **난이도와 무관하게 항상 작동**한다. 전장 환경은 공개 정보이므로 정보 차등 정책(빌드 유효성 경고의 Normal 한정 작동)의 대상이 아니다
- 빌드 유효성 경고(속성 구성 조언, 무시 가능) / 빈 슬롯(차단) / 환경 부적합(차단, 사유 표시)은 서로 다른 세 층위의 검증이다

| 검증 | 성격 | 난이도 적용 |
|------|------|-------------|
| 빈 슬롯 | 출격 차단 | 전 난이도 |
| 환경 부적합 슈퍼웨폰 | 장착 차단 + 사유 표시 | 전 난이도 |
| 빌드 유효성 경고 | 경고만 (출격 가능) | Normal만 |

**환경 재검증의 공통 적용 (3상황 동일 로직):** 다음 세 상황에서 **출격 준비 로드아웃(4.1)**/로드 대상을 확정 스테이지의 전장 환경으로 재검증하고, 부적합한 슈퍼웨폰 슬롯은 **비운 뒤 사유를 안내**한다 ("[슈퍼웨폰명]은 이 전장에서 운용 불가 — 슬롯이 비워졌습니다"). 빈 슬롯 상태가 되므로 출격 차단(2.3)이 자연히 적용된다.

1. **로드아웃 씬 진입 시** — 현재 로드아웃에서 복사된 출격 준비 로드아웃에 이번 스테이지 부적합 장비가 있을 수 있다 (가장 일반적인 경우). **비워짐은 준비 로드아웃에만 적용되며, 출격 확정 커밋 전에는 영속 상태에 반영되지 않는다**
2. **프리셋 로드 시** — 적합한 슬롯은 전부 로드하고 부적합 슬롯만 비운다 (부분 로드, 전체 거부 없음 — 일반 규칙은 4.5)
3. **다중 스테이지 미션의 간이 로드아웃 진입 시** — 다음 스테이지의 환경으로 재검증

장착을 유지한 채 인게임에서 발동만 막는 방식은 "장착 단계 차단" 원칙과 모순이므로 사용하지 않는다.

**진행 불가 방지 (콘텐츠 보장 규칙):** 슈퍼웨폰 슬롯은 필수이므로, 환경 제한으로 슬롯을 채울 수 없으면 진행이 막힌다. 모든 출격 가능 스테이지는 해당 미션 해금 시점에 플레이어가 **최소 1개 이상의 환경 적합 슈퍼웨폰을 보유하거나 즉시 획득 가능**해야 하며, 이 조건을 만족하지 않는 미션·해금 구성은 콘텐츠 데이터 오류로 처리한다. 가장 단순한 보장책으로 **전천후(명시적 "전체 환경" 태그) 슈퍼웨폰 1개를 초기 지급**한다 (장비 해금 시스템 연동, 태그 표현 규칙은 슈퍼웨폰 시스템 3.6).

## 3. 장비 교체 시점

### 3.1 교체 가능 시점

장비 교체는 다음 시점에만 가능하다.

- **미션 출격 전:** 로드아웃 씬에서 세팅
- **스테이지 클리어 후:** 다음 스테이지 출격 전 재세팅 가능
- **미션 실패 후 재도전 시:** 새로운 세팅으로 재출격 가능

### 3.2 스테이지 진행 중 교체 금지

**스테이지 진행 중** 실시간 장비 교체는 지원하지 않는다. 이는 로드아웃 판단의 무게감을 유지하기 위함이다. 플레이어는 출격 전 판단에 책임을 지며, 해당 스테이지는 세팅된 장비로 끝까지 전투한다. 다중 스테이지 미션에서는 한 스테이지가 종료된 뒤, 다음 스테이지 출격 전의 간이 로드아웃 구간(7.4)에서만 교체할 수 있다.

### 3.3 미션과 스테이지의 관계

- **기본 구조:** 1미션 = 1스테이지
- **확장 구조:** 1미션 = N스테이지 (시스템상 허용)

한 미션에 여러 스테이지를 묶을 경우, 스테이지 간 연속 전투로 진행된다. 스테이지 사이에는 로드아웃 재세팅이 가능하다. 이 구조를 통해 "미션"은 캠페인 흐름상의 단위, "스테이지"는 실제 플레이 단위로 구분된다.

## 4. 프리셋 시스템

### 4.1 현재 로드아웃과 프리셋의 관계

**현재 로드아웃** — 세이브 데이터마다 1개 존재하는, 마지막으로 확정된 **영속 장착 상태**다. 프리셋 저장 여부와 무관하게 항상 유지된다.

**출격 준비 로드아웃** — 출격 준비 컨텍스트 생성(캠페인 맵에서 미션·난이도 선택 — 게임플로우 문서) 시 현재 로드아웃을 **복사해 만드는 임시 편집 상태**다.

- 로드아웃 씬의 모든 편집(슬롯 변경, 프리셋 로드)은 출격 준비 로드아웃에 적용된다
- 브리핑 ↔ 로드아웃 왕복 중 유지된다 (돌아와도 편집 사항 유지)
- **환경 재검증(2.4)으로 비워지는 슬롯도 이 임시 상태에서만 비워진다** — 미션을 구경만 하고 캠페인 맵으로 복귀해도 현재 로드아웃(영속)은 손상되지 않는다
- **출격 확정 시 현재 로드아웃으로 커밋**된다 (다음 출격 준비의 복사 원본이 됨)
- 캠페인 맵으로 취소 복귀하면 폐기된다

**프리셋** — 로드아웃 조합을 플레이어가 이름을 붙여 보존한 선택적 스냅샷이다. 프리셋 로드는 **출격 준비 로드아웃**을 해당 조합으로 덮어쓰고, 프리셋 저장은 현재 편집 중인 출격 준비 로드아웃을 저장한다.

**새 세이브** — 기본 보유 장비로 채워진 **초기 현재 로드아웃**을 제공한다 (빈 슬롯으로 시작하지 않는다). 이를 이름 있는 기본 프리셋으로 자동 등록하지는 않는다 — "기본 프리셋 미제공"(4.3)은 빈 시작을 뜻하지 않는다.

**로드아웃 씬의 두 진입 모드:** 같은 로드아웃 씬을 두 모드로 나눠 진입한다.

| 진입 모드 | 진입 경로 | 편집 대상 | 환경 적합 검증 | 출격 버튼 |
|-----------|-----------|-----------|----------------|-----------|
| 출격 준비 모드 | 캠페인 맵 → 브리핑 → 로드아웃 (출격 준비 컨텍스트 존재) | 출격 준비 로드아웃 | 적용 (확정 스테이지 기준) | 있음 |
| 프리셋 관리 모드 | 캠페인 맵 허브의 프리셋 관리 메뉴 | 선택한 프리셋 스냅샷 | **미적용** (확정 스테이지 없음) | 없음 |

프리셋 관리 모드의 규칙:

- 출격 준비 컨텍스트를 생성하지 않는다 — 미션·확정 스테이지가 없는 상태의 순수 빌드 작성 공간이다
- 환경 적합 검증을 하지 않으므로 **환경 특화 슈퍼웨폰을 포함한 프리셋도 자유롭게 작성**할 수 있다 (실제 미션에서 로드할 때 환경 재검증이 수행됨 — 2.4)
- 프리셋을 생성·수정·삭제할 뿐 **현재 로드아웃은 변경하지 않는다**
- 이 모드에서의 조합 작성은 "실제 장착"이 아니므로 **시너지 장착 발견을 발생시키지 않는다** (슬롯 시너지 시스템 — 발견은 출격 준비 모드의 장착 조합 완성 시에만)

### 4.2 프리셋 기본 사양

플레이어는 **기체 + 장비 조합**을 프리셋으로 저장하고 불러올 수 있다.

- **저장 단위:** 기체 1 + 장비 슬롯 5칸 (기본 무기 1, 특수무장 2, 슈퍼웨폰 1, 보호막 1 — 4종 장비)
- **최대 저장 개수:** 50개
- **이름 지정:** 가능. 플레이어가 프리셋에 자유롭게 이름 부여
- **기본 프리셋:** 제공하지 않음

### 4.3 기본 프리셋 미제공 사유

시스템이 "대공 특화", "대지 특화" 같은 기본 프리셋을 미리 제공하지 않는다. 플레이어가 직접 빌드를 시행착오하면서 찾아가는 경험 자체가 이 게임의 재미이며, 기본 프리셋이 있으면 이 탐색 과정이 축소될 수 있다.

### 4.4 프리셋 저장 범위

프리셋은 **세이브 데이터 단위로 보존**된다.

| 항목 | 처리 |
|------|------|
| 같은 세이브 내 | 프리셋 유지 |
| 새 세이브 생성 | 프리셋 새로 시작 (이전 세이브의 프리셋 미공유) |
| 세이브 삭제 | 해당 세이브의 프리셋도 함께 삭제 |

세이브 데이터 단위로 운영하는 이유는 게임이 즉시 리플레이 방식이라 캠페인 단위 개념이 따로 없으며, 세이브 데이터가 곧 한 캠페인의 진행 단위이기 때문이다.

### 4.5 프리셋 운용

- 로드아웃 씬에서 프리셋 목록 접근 가능
- 프리셋 선택 시 기체와 모든 슬롯이 해당 빌드로 즉시 로드
- 현재 세팅을 새 프리셋으로 저장 가능
- 기존 프리셋 수정/삭제 가능
- 간이 로드아웃(7.4)에서도 프리셋 사용 가능
- **프리셋 로드 시 각 슬롯을 독립적으로 검증한다 (부분 로드 일반 규칙):** 유효한 슬롯은 로드하고, 미보유·데이터 참조 오류·슬롯 타입 부적합·환경 부적합 슬롯은 비운 뒤 **슬롯별 사유를 안내**한다 (환경 부적합의 상세는 2.4)
- **프리셋 원본은 자동 수정하지 않는다.** 플레이어가 현재 세팅으로 다시 저장할 때만 갱신된다 — 다른 환경에서 재사용할 때 원래 슈퍼웨폰 구성이 보존되어야 하기 때문
- **프리셋 저장 조건 — 완성된 로드아웃만 저장 가능:** 기체 1 + 장비 슬롯 5칸이 전부 채워져 있고, 각 참조 데이터가 존재하며, 현재 세이브에서 보유 중이고, 슬롯 타입이 일치해야 저장할 수 있다. 빈 슬롯 상태는 프리셋으로 저장할 수 없다 (미완성 프리셋 상태를 별도 관리하는 복잡도가 이익보다 크다). 환경 적합성은 모드에 따라 다르다 — 출격 준비 모드에서는 부적합 슬롯이 이미 비워져 있으므로 자연히 저장이 차단되고, 프리셋 관리 모드에서는 환경 검사 자체가 없다
- 프리셋 50개 도달 시 새 프리셋 생성이 차단된다. 기존 프리셋의 수정·덮어쓰기·삭제는 가능하다 (중복 이름 허용 여부는 UI 정책)

## 5. 장비 스탯 표기

### 5.1 추상화된 지표 사용

장비 스탯 중 **성능 비교용 연속 수치는 1~10 단계의 추상화된 지표**로 표기한다 (정확한 DPS·데미지 값·쿨다운 초 등 원시 수치는 미노출). 반면 **장비 운용에 필요한 이산값과 규칙은 정확히 표시**한다 — 감추면 운용 판단 자체가 불가능한 정보이기 때문이다.

| 구분 | 항목 |
|------|------|
| 추상 표기 (1~10) | 데미지, 연사력, 유효범위, 탄속, 안정성, 광역성, 보호막 내구도, 보호막 재생 성능, 슈퍼웨폰 충전 성능 |
| 정확 표기 | 무장 속성, 슈퍼웨폰 최대 스톡·1회 소비 스톡, 전장 환경 태그, 장비 효과와 발동 조건, 장착 가능 여부와 제한 사유 |

슈퍼웨폰 최대 스톡은 인게임 HUD에서 아이콘 개수로 정확히 보이므로, 로드아웃에서만 추상화하는 의미가 없다.

### 5.2 추상화 표기를 채택한 이유

- **최적해 고정 방지:** 정확한 수치가 노출되면 플레이어가 최적 빌드를 계산으로 도출할 수 있으며, 이는 이 게임이 추구하는 "직접 써보고 찾아가는 재미"를 축소한다.
- **플레이 동기 부여:** 추상화된 지표는 "이 무기 어떤 느낌인지 써보고 싶다"는 호기심을 자극한다.
- **정보 과잉 방지:** 로드아웃 UI가 복잡한 수치로 채워지는 것을 방지하여, 플레이어의 인지 부담을 줄인다.

### 5.3 표기 지표 목록

모든 후보 지표를 정의하되, 실제 UI 노출은 장비 종류에 따라 필요한 지표만 선택하여 표기한다.

| 지표 | 의미 | 주 적용 대상 |
|------|------|--------------|
| 데미지 | 1회 발사 트리거의 대표 단일 대상 피해량 | 무장 전반 |
| 연사력 | 시간당 발사 횟수 | 무장 전반 |
| 유효범위 | 탄환이 도달하는 거리 | 무장 전반 |
| 탄속 | 탄환이 날아가는 속도 | 무장 전반 |
| 안정성 | 탄환의 명중률 또는 집탄성 | 무장 전반 |
| 광역성 | 타격 범위의 넓이 | 특수무장, 슈퍼웨폰 |
| 내구도 | 방어 자원의 총량 | 보호막 |
| 재생속도 | 방어 자원의 자동 재생 속도 (생존 시스템의 보호막 자동 재생) | 보호막 |
| 충전속도 | 게이지 충전 속도 | 슈퍼웨폰 |

장비 종류별로 표시할 지표 조합은 차후 각 장비 시스템 세부 기획에서 결정한다.

**데미지 지표의 기준:** 데미지 지표는 "1회 발사 트리거가 표준 유효 대상 1개에 줄 수 있는 대표 피해량"을 기준으로 한다. 산탄·다중 미사일·지속형·설치형도 이 기준으로 대표값을 산정한다.

**수동 지정 원칙:** 추상 지표는 컨텐츠 디자이너가 장비의 실제 체감과 역할을 기준으로 **수동 지정**하며, 원시 수치에서 자동 계산하지 않는다. 체감과의 일치 여부는 프로토타입 검증 항목(12장)이다.

## 6. 빌드 유효성 경고

### 6.1 검증 대상

빌드 유효성 검증은 **기본 무기 + 특수무장 2개**의 속성 구성만을 대상으로 한다. 슈퍼웨폰은 검증 대상에서 제외한다.

### 6.2 슈퍼웨폰 제외 사유

슈퍼웨폰은 게이지 충전이 필요하고 사용 횟수가 제한적이라 "기본 화력원"이 아니다. 미션 전반의 적 대응을 책임지는 무기는 기본 무기와 특수무장이며, 빌드 유효성도 이 3개 슬롯의 구성으로 판단한다.

**직접 무장만 평가한다:** 기체 특성, 슈퍼웨폰, 슬롯 시너지, 드론 등 부가·조건부 공격 수단은 커버리지에 포함하지 않는다. 예를 들어 대공 ×3 + 대지 공격 드론 시너지 빌드도 경고를 받는다 — 이는 오판이 아니라 **보수적인 직접 화력 경고**이며, 경고 메시지에 판정 범위를 명시한다 ("직접 장착 무장에 지상 대응 수단이 없습니다").

### 6.3 검증 시점

**빌드 유효성 경고의 판정**은 출격 버튼을 누른 시점에만 수행한다 — 슬롯 조합을 실험하는 과정에서 불필요한 알림이 반복되는 것을 방지. 반면 환경 적합성 확인·활성 시너지 재계산·스탯 표시·빈 슬롯 상태 갱신은 편집 중 실시간으로 수행한다 (7.2).

### 6.4 난이도별 검증 작동 여부

빌드 유효성 검증은 **Normal 난이도에서만 작동**한다. Hard 이상 난이도에서는 검증 자체가 비활성화된다.

| 난이도 | 빌드 유효성 검증 | 사유 |
|--------|------------------|------|
| Normal | 작동 | 적 구성 힌트 표시 → 힌트 기반 검증 가능 |
| Hard / Nightmare | 비작동 | 적 구성 힌트 비표시 → 검증이 작동하면 정보가 간접 누설됨 |

이 규칙은 미션 브리핑 시스템의 정보 차등 원칙과 일관된다. Hard 이상은 플레이어의 자율적 빌드 선택에 무게를 두는 난이도이며, 사전 경고 없이 본인 판단으로 빌드를 구성하는 것이 컨셉에 맞다.

### 6.5 경고 기준: 브리핑 정보 불일치

(Normal 난이도 한정) 로드아웃 세팅이 미션 브리핑에서 제공된 적 구성 힌트와 불일치할 경우 경고를 표시한다.

| 브리핑 힌트 | 경고 조건 |
|-------------|-----------|
| 지상 적 다수 예상 | 검증 대상 슬롯 중 대지 무장 및 범용 무장이 모두 0개 |
| 공중 위협 높음 | 검증 대상 슬롯 중 대공 무장 및 범용 무장이 모두 0개 |
| 혼합 구성 예상 | 검증 대상 슬롯 중 지상 커버리지(대지 또는 범용)가 0개 또는 공중 커버리지(대공 또는 범용)가 0개 |

Normal인데 적 구성 힌트 데이터가 비어 있는 미션은 빌드 유효성 경고를 생략한다. 필수 힌트가 누락된 미션은 콘텐츠 검증 오류로 별도 기록한다.

### 6.6 절대적 속성 커버리지 경고 미채용

"지상 커버리지 0" 또는 "공중 커버리지 0"을 브리핑과 무관하게 경고하는 방식은 채용하지 않는다. 이 게임은 지상 100% 또는 공중 100% 미션도 디자인 가능한 구조이며, 이런 극단 미션에서는 반대 속성 커버리지가 없는 빌드가 오히려 최적해일 수 있다.

### 6.7 경고 메시지

경고 메시지에는 **어떤 부분이 부적합한지 구체적으로 명시**한다. 단순히 "빌드 부적합" 같은 추상적 메시지가 아닌, "지상 적 다수가 예상되나 대지/범용 무장이 없습니다" 같은 구체적 안내를 제공한다.

### 6.8 경고 후 처리

- 플레이어가 "무시하고 출격" 또는 "세팅 수정"을 선택할 수 있다
- 경고를 무시한 출격 자체는 막지 않는다
- 플레이어의 판단에 책임을 맡긴다

## 7. 출격 플로우

### 7.1 기본 순서

```
캠페인 맵 (미션+난이도 선택) → 미션 브리핑 (난이도 표시) → 기체 선택 + 로드아웃 씬 → 출격 → (전투) → 클리어 평가 / 실패 화면 → ...
```

기체 선택과 장비 세팅은 동일한 씬에서 진행되며, 함께 프리셋으로 저장될 수 있다.

### 7.2 각 단계의 역할

| 단계 | 플레이어 행동 | 시스템 처리 |
|------|---------------|-------------|
| 캠페인 맵 | 미션 선택 + **난이도 선택·변경 (이 단계 전용)** | **출격 준비 컨텍스트 생성 — 확정 스테이지 식별자가 이 시점에 결정됨** (게임플로우 문서). 출격 준비 로드아웃 생성 (현재 로드아웃 복사) |
| 미션 브리핑 | 적 구성 힌트 확인 (선택된 난이도 표시, 변경 불가) | 브리핑 정보 표시 (분기 변형·난이도 차등) |
| 기체 선택 + 로드아웃 씬 | 기체 선택 + 장비 세팅 (프리셋 사용 가능) | 슬롯 변경 시 즉시: 장착 가능 확인(환경 차단 포함) · 출격 준비 로드아웃 갱신 · 활성 시너지 재계산(상시 표시) · 스탯/속성 표시 갱신 · 빈 슬롯 상태 갱신. **빌드 유효성 경고만 미실행** (출격 시점 전용, 6.3) |
| 출격 버튼 | 출격 시도 | 7.3절의 출격 검증 전체 흐름(7단계) 수행 |
| 전투 | 미션 수행 | 스테이지 진행 |

### 7.3 출격 검증 흐름

출격 버튼 클릭 시 다음 순서로 검증한다.

1. **로드아웃 참조 유효성 확인** — 장비 데이터 존재 / 현재 세이브에서 보유 중 / 슬롯 타입 일치 (내부 무결성 검사)
2. **전장 환경 적합성 최종 확인** — 슈퍼웨폰 환경 태그 검증. 선택 단계에서 이미 차단되므로 통상 통과하며, 실패 시 해당 슬롯을 비우고 출격 차단 (사용자에게 같은 경고를 반복하지 않는 내부 방어 검사)
3. **빈 슬롯 검사** — 기체 1 + 장비 슬롯 5칸이 모두 채워져 있는지. 빈 슬롯 있으면 안내 후 출격 차단
4. **활성 시너지 최종 재계산** — 편집 중 계산값과 무관하게 출격 직전 최종 확정
5. **빌드 유효성 경고 (Normal만)** — 6장 규칙에 따라 검사, 위반 시 구체적 메시지 표시. 플레이어가 "무시하고 출격" 또는 "세팅 수정" 선택. Hard 이상은 건너뜀
6. **출격 준비 로드아웃을 현재 로드아웃으로 커밋**하고, 최종 출격 컨텍스트에 로드아웃·활성 시너지 스냅샷을 저장한다 (게임플로우 문서 4장)
7. **출격 진행**

### 7.4 스테이지 간 전환 (1미션 N스테이지인 경우)

**구현 범위:** 1미션 = N스테이지는 **시스템 확장 사양**이며, 초기 개발·프로토타입 범위에서는 1미션 = 1스테이지만 구현한다. 아래 규칙과 상태 이전 위임은 1:N 구현 착수 전에 확정한다. 착수 전 결정 목록: 스테이지 실패 시 재시작 지점(1스테이지부터 vs 실패 스테이지만) / 미션 스코어·체인의 스테이지 간 유지 / 중간 스테이지 종료 시 자동 저장 / 간이 로드아웃에서 캠페인 맵 이탈 가능 여부 / 게임플로우 메인 루프의 스테이지 종료 분기 추가.

다중 스테이지 미션의 경우, 각 스테이지 클리어 후 다음 스테이지 시작 전에 간이 로드아웃 씬이 열린다. 여기서 플레이어는 기체 선택과 로드아웃을 재세팅할 수 있다 (프리셋 사용 가능). 출격 검증 흐름(7.3)과 환경 재검증(2.4)은 동일하게 적용된다.

**스테이지별 힌트와 빌드 경고:** 다중 스테이지 미션은 스테이지별 적 구성 힌트를 가질 수 있다 (미션 브리핑 시스템의 데이터 확장). Normal에서는 간이 로드아웃 진입 시 **다음 스테이지의 힌트**를 표시하고 그것을 기준으로 빌드 유효성을 검증한다. Hard 이상은 힌트 비표시·경고 비작동. 다음 스테이지 힌트 데이터가 없으면 간이 로드아웃에서 빌드 유효성 경고를 생략한다.

**스테이지 간 상태 이전 (위임):** 스테이지 간 로드아웃 변경은 다음 스테이지의 장착 구성을 결정할 뿐이다. 미션 내 생존 자원(체력·보호막·잔기)·슈퍼웨폰 게이지/스톡·특수무장 쿨다운·체인·스코어·평가 기록의 유지/초기화 규칙은 **게임플로우·생존·스코어링 문서에서 정의한다** — 기체 교체 시의 자원 이전을 포함하며, 1미션 N스테이지 구현 전 확정 필수.

### 7.5 미션 실패 후 재도전

미션 실패 시 실패 화면에서 리플레이를 선택하면 **동일 미션·난이도·분기 상태 스냅샷·확정 스테이지로 브리핑부터 재진입**하며 (게임플로우 문서의 리플레이 규칙 — 브리핑 변형까지 이전 플레이와 동일하게 재현), 로드아웃 씬에서 새로운 세팅으로 출격할 수 있다. **출격 직전에는 로드아웃과 활성 시너지만 새로 확정한다.** 출격 검증 흐름은 동일하게 적용된다. 클리어 후 리플레이도 같은 흐름이다.

## 8. 로드아웃 데이터

로드아웃은 기체, 기본 무기, 특수무장 2개, 슈퍼웨폰, 보호막의 선택 조합으로 구성된다. 프리셋은 이 조합에 플레이어가 지정한 이름과 생성 일시를 더해 보존된다.

출격 확정 시 로드아웃과 활성 시너지는 **출격 컨텍스트**(미션·난이도·분기 상태·확정 스테이지 식별자 포함)에 묶여 인게임에 전달된다 (게임플로우 문서 4장).

(본 시스템의 데이터 항목 세부 정의는 별도의 데이터 테이블 문서에서 관리한다.)

## 10. UI 영역

레이아웃·화면 구성은 UI기획_로드아웃 문서(무뎁스 3컬럼 + 프리뷰 무대) 소관이다. 본 시스템이 UI에 요구하는 계약은 다음과 같다.

- 특수무장 슬롯 1·2는 속성 자유 슬롯 — 슬롯명에 속성을 붙이지 않는다 (속성 태그는 장착 장비의 것)
- 장착 조합의 활성 시너지를 상시 표시하고, **출격 준비 모드**에서의 표시 시점 = 시너지 도감의 장착 발견 처리와 동기화한다 (슬롯 시너지 시스템). 발견 알림은 로드아웃 씬에서 즉시 표시하며, 클리어 평가에는 시너지 발견 알림이 없다
- 환경 부적합 슈퍼웨폰은 선택지에서 차단 상태 + 사유를 표시한다 (프리셋 부분 로드로 비워진 슬롯의 사유 포함)
- 빈 슬롯(차단)과 빌드 유효성 경고(무시 가능)는 층위에 맞게 구분된 표현을 가진다
- 성능 비교용 연속 수치는 1~10 추상 지표로 표시한다
- 무장 속성, 스톡 수, 환경 태그, 장비 효과·발동 조건 등 운용에 필요한 이산값과 규칙은 정확히 표시한다 (5.1)

## 11. 확정 사항 요약

| 항목 | 결정 사항 |
|------|-----------|
| 슈퍼웨폰 환경 적합 검증 | 스테이지 환경 태그와 매칭. 부적합 시 장착 차단 + 사유 표시. 난이도 무관 항상 작동 (공개 정보 기반). |
| 프리셋 부분 로드 | 슬롯별 독립 검증 — 미보유/참조 오류/타입 부적합/환경 부적합 슬롯만 비움 + 슬롯별 사유. 원본 자동 수정 금지. 50개 도달 시 신규 생성만 차단 |
| 환경 재검증 | 3상황 공통 로직 (씬 진입/프리셋 로드/스테이지 전환) — 부적합 슬롯 비움 + 사유. 해금 시점 적합 슈퍼웨폰 보유 보장 (전천후 1개 초기 지급, 위반 = 콘텐츠 오류) |
| 슬롯 구성 | 기체 1 + 장비 슬롯 5칸 (기본 무기 1, 특수무장 2, 슈퍼웨폰 1, 보호막 1 — 4종 장비) |
| 로드아웃 상태 구조 | 현재 로드아웃(영속) / 출격 준비 로드아웃(임시 편집 — 준비 컨텍스트 생성 시 복사, 출격 확정 시 커밋, 취소 시 폐기, 환경 비움은 여기만) / 프리셋(스냅샷). 새 세이브는 기본 장비로 채워 시작 |
| 씬 진입 모드 | 출격 준비 모드(환경 검증 O·출격 O·준비 로드아웃 편집) / 프리셋 관리 모드(캠페인 맵 허브 진입 — 검증 X·출격 X·프리셋만 편집, 현재 로드아웃 불변, 특화 슈퍼웨폰 포함 작성 자유, 시너지 발견 미발생) |
| 프리셋 저장 조건 | 완성된 로드아웃만 (전 슬롯 충족+참조 유효+보유+타입 일치). 빈 슬롯 프리셋 불허 |
| 장비 선택 자유도 | 조합 제한 없음 + 동일 장비 중복 장착 허용 (독립 인스턴스·독립 쿨다운). 단 장비 자체 운용 조건(환경 적합)의 장착 제한은 적용 |
| 빈 슬롯 처리 | 모든 슬롯 채워야 출격 가능. 빈 슬롯 있으면 출격 차단 + 안내. |
| 교체 가능 시점 | 출격 전, 스테이지 간(간이 로드아웃), 재도전 시. 스테이지 진행 중 불가 |
| 미션-스테이지 구조 | 1:1 기본, 1:N 허용 (시스템 지원) |
| 프리셋 저장 단위 | 기체 1 + 장비 슬롯 5칸 조합 |
| 프리셋 저장 개수 | 최대 50개 |
| 프리셋 이름 지정 | 가능 |
| 기본 프리셋 | 제공하지 않음 |
| 프리셋 보존 범위 | 세이브 데이터 단위 |
| 스탯 표기 방식 | 성능 연속치 = 1~10 추상 지표 (디자이너 수동 지정, 자동 계산 금지) / 운용 이산값·규칙 = 정확 표기 |
| 정확한 수치 노출 | 원시 성능 수치 미노출. 속성·스톡·환경 태그·효과 조건·제한 사유는 정확 표시 |
| 빌드 유효성 검증 대상 | 직접 장착 무장만 (기본 무기 + 특수무장 2). 시너지·드론·기체 특성·슈퍼웨폰 미포함 — 메시지에 판정 범위 명시. Normal 힌트 부재 시 생략 |
| 검증 시점 | 빌드 유효성 경고만 출격 버튼 시점. 환경 적합·시너지·슬롯 상태 갱신은 편집 중 실시간 |
| 검증 작동 난이도 | Normal에서만 작동. Hard 이상에서는 비작동. |
| 빌드 유효성 경고 | 브리핑 힌트 기반 불일치 경고만 (Normal 한정) |
| 경고 메시지 | 구체적 부적합 항목 노출 |
| 경고 후 출격 제한 | 없음 (플레이어 판단 존중) |
| 출격 플로우 | 캠페인 맵(미션+난이도) → 브리핑(난이도 표시) → 기체+로드아웃 → 출격 검증 → 출격 |
| 출격 검증 순서 | 참조 유효성 → 환경 최종 확인 → 빈 슬롯 → 시너지 최종 재계산 → Normal 경고 → 컨텍스트 스냅샷 → 출격 (7단계) |
| 다중 스테이지 | **확장 사양 — 초기 구현 범위 제외 (1미션=1스테이지)**. 스테이지별 힌트·상태 이전·재시작 지점 등은 1:N 착수 전 확정 목록 |
