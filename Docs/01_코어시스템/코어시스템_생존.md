## 1. 개요

본 문서는 플레이어 기체의 **생존 시스템**을 정의한다. 이 게임은 일격에 격파되는 하드코어 슈팅을 지양하고, 체력과 보호막의 2층 구조를 통해 피탄을 허용하는 설계를 채택한다. 본 시스템은 진입장벽을 낮추면서도 보호막 관리라는 리소스 판단 요소를 제공하는 기반 시스템이다.

기체별 세부 설계(기체 종류, 스탯 밸런스, 특성 상세 등)는 본 문서의 범위를 벗어나며, **기체 시스템** 세부 기획에서 다룬다.

## 2. 기체의 생존 자원 구조

### 2.1 2층 구조

플레이어 기체는 2가지 생존 자원을 가진다.

| 자원 | 역할 | 결정 요소 |
|------|------|-----------|
| 체력 (HP) | 최후의 방어선 | 기체 선택에 따라 결정 |
| 보호막 (Shield) | 피해 1차 흡수층 | 보호막 장비 선택에 따라 결정 |

### 2.2 체력 — 기체 고유 스탯

체력 총량은 **기체 자체의 스탯**으로 결정된다. 플레이어는 다중 기체 시스템에서 기체를 선택하며, 각 기체는 고유한 체력 수치를 가진다.

### 2.3 보호막 — 장비 슬롯 스탯

보호막은 **별도 장비 슬롯**에서 장착한 장비에 의해 결정된다. 보호막 장비는 다음 속성들을 결정한다.

- 보호막 총량
- 자동 재생 속도
- 파괴 시 특수 효과
- 기타 추가 특성

보호막 장비 세부 사양은 **보호막 컨텐츠 기획**에서 별도로 다룬다.

## 3. 피격 처리 로직

### 3.1 데미지 최소값

모든 데미지의 최소값은 **정수 1**이다.

- **무적 판정은 데미지 계산 전에 수행한다.** 무적이면 피해 이벤트 자체가 무시된다 (슈퍼웨폰 무적 등은 공격을 완전히 무시할 수 있다)
- 무적이 아닌 경우, 모든 공격력·피해 감소 보정을 적용한 최종 데미지를 정수화한 뒤 **최소 1로 보정**한다 — 일반 피해 감소로는 0 피해가 나올 수 없다

### 3.2 피격 처리 순서

적의 공격이 플레이어에게 명중했을 때의 처리 순서:

1. 플레이어가 생존·피격 가능 상태인지 확인 (사망 연출 중이면 종료)
2. **모든 무적 출처 확인** (4.5절) — 하나라도 활성이면 피해 이벤트 무시 후 종료
3. 공격·피해 감소 보정을 적용한 최종 데미지 계산
4. 최종 데미지 정수화 + 최소 1 보정 (3.1절)
5. **유효 피탄 카운트 +1** (클리어 평가 집계)
6. 보호막 ≥ 1이면:
   - 보호막 감소 (최소 0 보정, 완전 흡수 원칙 — 초과분 체력 미전달)
   - 처리 직전 보호막 > 0 이고 처리 직후 = 0 이면 보호막 파괴 처리 (6장)
   - 체력에 피해를 넘기지 않고 종료
7. 보호막 = 0이면 체력 감소
8. 체력 ≤ 0이면 **사망 처리 — 피격 후 무적을 시작하지 않는다** (사망 상태 전환이 우선)
9. 체력 > 0이면 피격 후 무적 시작

**용어 정의 — 유효 피해 이벤트:** 플레이어가 생존·피격 가능 상태이며, 모든 무적 판정을 통과한 뒤 **최종 데미지 1 이상이 보호막 또는 체력에 실제 적용되는 피해 이벤트**를 뜻한다. 보호막 재생 초기화(3.4), 피탄 카운트, 보호막 파괴(6장)는 전부 이 정의를 기준으로 판정한다.

**피탄 카운트 단위:** 피탄 카운트의 기본 단위는 본 시스템이 승인한 **유효 피해 이벤트**다. 지속형 공격(빔·장판의 틱, 램 재피격)을 이벤트마다 각각 집계할지, 접촉 단위(최초 접촉만 1회)로 집계할지는 **전투 처리 흐름 문서에서 확정한다** — 클리어 평가 구현 전 필수 결정.

### 3.3 보호막의 완전 흡수 원칙

**보호막 잔량보다 큰 데미지가 들어와도 보호막이 반드시 1회 완전히 흡수한다.** 초과 데미지는 체력으로 전달되지 않는다.

**예시:**
- 보호막 잔량 1, 체력 100 상태에서 100 데미지 피격
- 처리 결과: 보호막 0, 체력 100 (초과 데미지 99가 체력에 전달되지 않음)

이 규칙은 보호막을 "최후의 방패"로 기능하게 한다. 보호막 잔량이 낮을 때 큰 데미지가 들어와도 즉시 격파되는 상황을 방지하며, 피탄 허용형 설계의 근간 원칙과 일관된다.

### 3.4 보호막 자동 재생

보호막은 **보호막 장비에 의해 결정되는 자동 재생 속도**에 따라 시간 경과로 서서히 재생된다. 자동 재생은 느린 속도로 설정하며, 주요 회복 수단은 회복 아이템이다. 자동 재생은 백업 역할에 한정한다. 구체적 속도는 보호막 장비별 차등 설정.

**재생 규칙:**

1. 보호막이 최대치 미만이면 재생 가능 상태다 (보호막 0에서도 동일 규칙으로 재생)
2. 보호막 또는 체력에 **유효 피해**가 들어오면 재생 대기 시간과 **재생 누적값을 모두 0으로** 초기화한다 (부분적으로 쌓인 재생도 함께 잃는다)
3. 재생 대기 시간이 지난 뒤 재생 속도에 따라 재생한다
4. 재생 중 유효 피해를 받으면 재생을 중단하고 대기 시간을 다시 시작한다
5. **무적으로 무시된 공격은 재생 대기 시간을 초기화하지 않는다** (유효 피해가 아니므로)
6. 일시정지·사망 상태에서는 재생 시간도 정지한다
7. 보호막이 최대치에 도달하면 재생 누적값을 0으로 초기화하고 재생을 중지한다 (최대치에서 누적을 유지하면, 보호막이 깎인 직후 대기 시간만 지나면 거의 즉시 1이 복구되는 문제가 생긴다)
8. 미션 시작·사망·리스폰 시 재생 대기 시간과 누적값을 모두 초기화한다

**재생 단위 — 정수 보호막 + 별도 재생 누적값:**

보호막 잔량은 정수로 관리하고, 자동 재생은 별도의 실수 누적값에 쌓는다. 누적값이 1.0에 도달할 때마다 보호막을 1 올리고 누적값에서 1.0을 차감한다. **보호막 흡수(완전 흡수 원칙 포함)는 보호막이 실제로 1 이상이 된 시점부터 다시 활성화된다** — 미세하게 회복된 소수점 보호막이 대형 공격을 한 발 완전히 막는 구멍을 차단한다.

### 3.5 회복 한도

회복 아이템과 자동 재생을 통한 회복은 **최대치까지만 적용**된다. 최대치를 초과하는 회복은 발생하지 않는다.

단, 슈퍼웨폰 효과로 발동되는 회복은 본 규칙을 따르지 않고 슈퍼웨폰에 명시된 동작을 따른다. 일시적 오버차지(예: 보호막 게이지 일시적으로 1000%) 같은 효과도 슈퍼웨폰 효과로 구현 가능하다.

### 3.6 램 충돌 데미지

적 본체와의 충돌(램 — 지상/공중 판정 분리 시스템 6장) 데미지는 **일반 피격과 완전히 동일한 파이프라인**으로 처리한다. 램이라는 이유로 특별 취급하지 않는다.

- 한 번의 램 판정 = 한 번의 일반 피격: 무적 확인 → 보호막 흡수 (완전 흡수 원칙 동일 적용) → 체력 적용 시 피격 후 무적 발동
- **램 데미지 기본값 = 1.** 특수 적(대형 자폭기 등)만 몬스터 데이터로 오버라이드한다
- 연속 접촉의 재피격 간격은 판정 분리 시스템의 램 재피격 주기가 제어한다 — 본 시스템은 개별 판정의 데미지 처리만 담당한다
- 의도적 피격으로 무적을 버는 트레이드(체력 1 소모 ↔ 무적 창 확보)는 규칙으로 금지하지 않는다. 체력 희소성(총량 3~4), 피탄 평가 항목, 램 재피격 사이클의 반복 비용이 자연 억제로 작동하며, 이는 램 고유가 아니라 피격 무적 일반의 성질이다. 과도한 이득 여부는 프로토타입 검증 항목이고, 조정 레버는 데이터(무적 시간·램 데미지 값)다

## 4. 무적 시간

### 4.1 피격 후 무적 시간 발동 조건

피격 후 무적 시간은 **체력에 데미지가 들어가는 순간에만** 발동한다.

| 상태 | 피격 시 처리 | 무적 시간 |
|------|-------------|-----------|
| 보호막 잔량 ≥ 1 | 보호막이 데미지 흡수, 체력 데미지 없음 | 발동하지 않음 |
| 보호막 잔량 = 0 | 체력에 데미지 적용 | 발동 |

이 설계의 결과로, 보호막이 살아있는 동안에는 **연속 피격이 가능**하다. 탄막을 보호막으로 뚫고 나가는 공격적 생존 플레이가 자연스럽게 가능해지며, 보호막이 깨진 후에는 신중한 플레이로 전환하는 흐름이 만들어진다.

### 4.2 피격 후 무적 시간 사양

- **지속 시간:** 2~3초 (프로토타입에서 확정)
- **효과:** 해당 시간 동안 적의 공격이 모두 무시됨
- **공격 가능 여부:** 공격 가능, 피격만 무시
- **회복 가능 여부:** 회복 적용됨 (무적과 회복은 별개)

무적 시간 동안 플레이어는 정상적으로 조작(이동, 공격, 슈퍼웨폰 사용 등) 가능하다. 회복 아이템이나 슈퍼웨폰 회복 효과도 정상적으로 적용된다.

### 4.3 보호막 파괴 시 무적 시간

보호막이 0이 되는 순간에 별도의 짧은 무적 시간이 발동될 수 있다. 이는 보호막 장비의 "파괴 시 특수 효과"로 데이터에서 설정 가능하다 (6장 참고).

| 항목 | 설명 |
|------|------|
| 발동 시점 | 보호막 잔량이 0이 되는 순간 |
| 지속 시간 | 짧음. 피격 후 무적과 별개의 값 |
| 사용 목적 | 보호막 파괴 직후 즉사를 방지하는 안전 장치 |

보호막 파괴 무적은 피격 후 무적과 **별도의 무적 출처**로 관리한다 (4.5절).

**데이터 단일 출처:** 보호막 파괴 무적 값은 **파괴 시 특수 효과 데이터에서만 관리**한다. 보호막 장비 데이터에 별도의 기본 파괴 무적 필드를 두어 이중 정의하지 않는다 — 같은 파괴 이벤트에서 무적 시간이 중복 정의되는 것을 방지 (프로그래머 테이블 설계 전달 사항). 보호막의 완전 흡수 원칙에 의해, 보호막을 파괴한 동일 피해 이벤트에서는 체력 피해가 발생하지 않으므로 **피격 후 무적이 같은 이벤트에서 동시에 새로 발동하지 않는다.**

### 4.4 리스폰 무적 시간

사망 후 예비기로 리스폰할 때 부여되는 무적 시간.

- **지속 시간:** 3초
- **효과:** 리스폰 직후 탄막 한가운데 복귀 시 즉사 방지
- **공격 가능 여부:** 공격 가능, 피격만 무시
- **회복 가능 여부:** 회복 적용됨

리스폰 사양:

- **위치:** 화면 하단 중앙 고정 + 짧은 진입 연출 (사망 지점 복귀는 탄막 정중앙일 위험이 있어 배제)
- **생존 자원:** 체력·보호막 모두 풀 충전 복귀
- **슈퍼웨폰 게이지·스톡:** 유지 — 사망 페널티는 잔기 소모·체인 리셋·피탄/사망 평가로 충분하며, 게이지까지 회수하면 재기가 불가능해진다
- **특수무장 쿨다운:** 초기화 (즉시 사용 가능 — 재기 지원. 쿨다운 값이 0인 무기에는 무의미)
- **적탄 소거:** 리스폰 순간 화면 내 적탄을 1회 소거한다 (리스폰 무적과 함께 리스폰 킬 이중 방지). 소거 대상 여부는 **탄환/효과 데이터의 "리스폰 시 소거" 속성**으로 결정 — 일반 적 탄환·유도탄·미사일은 기본 소거, 지속형 빔·환경 장판·시네마틱 연출 오브젝트는 기본 비소거. **소거는 보상이 전혀 없는 단순 제거다**: 스코어·체인·게이지·아이템 드롭 없음, 탄환의 파괴 시 효과(폭발·분열)도 실행하지 않음. 제거 전용 이펙트만 재생 가능
- **시너지 드론:** 사망 시 기체와 함께 소멸하며, 리스폰 시 자동 재생성된다

### 4.5 무적 공통 구조

게임 내 무적 출처는 다음과 같다: **피격 후 무적 / 보호막 파괴 무적 / 리스폰 무적 / 슈퍼웨폰 무적 / 기타 효과 무적.**

- 플레이어는 **하나 이상의 무적 출처가 활성 상태이면 무적**이다
- 각 출처의 타이머는 **독립적으로 관리**하며, 무적 시간이 서로 합산되지 않는다
- 동일 출처가 다시 발동되면 남은 시간 = max(현재 남은 시간, 새 지속 시간)
- 서로 다른 출처는 각각의 남은 시간을 유지한다
- **사망 상태 진입 시 플레이어 귀속 무적 출처와 타이머를 모두 제거한다.** 리스폰 시에는 리스폰 출처의 무적만 새로 시작한다 — 이전 생명의 무적이 새 기체로 이월되지 않는다. 보호막 재생 대기·누적값도 같은 시점에 초기화한다

**무적으로 무시된 공격의 효과:** 생존 자원(체력·보호막) 피해 없음 / 피탄 카운트 없음 / 보호막 파괴 효과 없음 / 재생 대기 초기화 없음 / 기타 피격 발동 효과 없음.

단, **공격 측의 재판정 주기·상태(예: 램 재피격 타이머)는 해당 공격 시스템의 규칙을 따른다** — 피해의 흔적은 남지 않지만 공격자의 행동 시간을 되돌리지는 않는다 (판정 분리 시스템의 "무시된 램 판정도 재피격 시점을 소비한다" 규칙과 정합).

## 5. 잔기 시스템

### 5.1 기본 구조

기본 기체 + 예비기 1기의 **잔기 1기 구조**를 채택한다.

용어 정의: **잔기 수 = 남은 리스폰 가능 횟수.** 기본 잔기 1 = 현재 기체 1회 + 리스폰 1회, 총 2회의 생존 기회다.

| 상태 | 결과 |
|------|------|
| 1차 사망 | 예비기로 리스폰. 체력/보호막 풀 충전, 3초 무적 시간 부여. |
| 2차 사망 | 미션 실패. |

**사망 순간 처리 (사망 → 리스폰 사이):**

- 격추 연출 중에도 게임은 정지하지 않는다 — 적 행동·적탄·스크롤 모두 정상 진행, 플레이어 조작만 불가
- 이미 발사된 플레이어 탄환·설치물은 유지된다 (날아가던 미사일은 정상 판정)
- 사망~리스폰 사이 딜레이(격추 연출 길이)는 짧게 유지하며, 값은 프로토타입에서 확정한다
- 체인 리셋 등 스코어 측 처리는 스코어링 시스템 규칙을 따른다

**사망 시 상태 처리 분류:**

| 분류 | 사망 시 처리 |
|------|--------------|
| 독립적으로 날아간 탄환 | 유지 |
| 월드에 독립 설치된 오브젝트 | 기본 유지 |
| 플레이어에 붙은 지속 공격 (차지 중인 빔 등) | 즉시 종료 |
| 차지·조준·록온 상태 | 초기화 |
| 플레이어 임시 버프/디버프 | 기본 제거 |
| 플레이어 귀속 무적 출처·타이머 | 전부 제거 (리스폰 시 리스폰 무적만 새로 시작) |
| 보호막 재생 대기·누적값 | 초기화 |
| 보호막 오버차지 | 제거 후 기본 최대치로 복구 |
| 월드형 슈퍼웨폰 효과 | 효과 데이터에 따라 유지 가능 |
| 시너지 드론 | 제거 후 리스폰 시 초기 상태 재생성 |

**설치물과 쿨다운 초기화의 중첩 방지:** 설치물은 유지되고 쿨다운은 초기화되므로, 사망을 활용해 강력한 설치물을 중첩 배치하는 루트가 생길 수 있다. 이를 막기 위해 **무장별 최대 활성 설치물 수를 데이터로 제한**한다 — 상한 도달 상태에서 추가 배치 시 가장 오래된 설치물이 제거된다 (사망 여부와 무관하게 항상 적용되는 일반 규칙이므로 확장성이 좋다)

### 5.2 잔기 1기를 채택한 이유

- 체력과 보호막이라는 생존 자원이 이미 두껍기 때문에, 잔기까지 과도하게 부여하면 게임이 쉬워짐
- 잔기를 아예 두지 않으면 플레이어가 심리적으로 몰리는 문제 발생
- 잔기 1기는 "한 번은 실수해도 된다"는 심리적 안전망을 제공하면서도 긴장감을 유지할 수 있는 균형점

### 5.3 잔기 초기화

잔기는 **미션 출격 시점에 1기로 초기화**된다. 미션 간에 잔기가 누적되거나 이월되지 않으며, 모든 미션은 잔기 1기 상태로 시작한다.

### 5.4 잔기 수의 변동 가능성

기본 잔기는 1기이지만, 다음 시스템들이 잔기 수에 영향을 줄 수 있는 가능성을 열어둔다.

- 기체 특성 (특정 기체의 추가 잔기 또는 잔기 0 시작)
- 슬롯 시너지 효과
- 슈퍼웨폰 효과
- 도전과제 보상 (장비 형태)

예를 들어 "잔기 0으로 시작하는 대신 특정 버프"같은 트레이드오프형 빌드 디자인이 가능하다. 구체적 효과는 컨텐츠 기획에서 정의한다.

### 5.5 미션 실패 처리

미션 실패는 **새 클리어 기록과 보상을 생성하지 않는다.** 기존 미션 클리어 상태·최고 랭크·난이도 해금 기록은 유지되며, 미클리어 미션이었다면 계속 미클리어 상태로 남는다.

실패 후 흐름(실패 화면의 즉시 리플레이/미션 선택 복귀)은 게임플로우·UI 문서를, 캠페인 진행 규칙은 동적 캠페인 시스템을 따른다.

### 5.6 미션 시작 시 생존 자원 초기화

미션 출격 시점에 다음 항목이 초기화된다.

| 항목 | 초기 상태 |
|------|-----------|
| 체력 | 기체의 최대 체력으로 초기화 (풀 상태) |
| 보호막 | 보호막 장비의 최대 보호막으로 초기화 (풀 상태) |
| 잔기 | 기본값 1에 기체 특성·시너지·장비 보정을 적용한 **최종 출격 시작값** (5.4 참고) |
| 무적 출처·타이머 | 모두 비활성 |
| 보호막 재생 대기·누적값 | 0 |
| 보호막 오버차지 | 없음 (기본 최대치) |
| 임시 생존 버프·디버프 | 없음 |

이전 미션의 체력/보호막 잔량은 이월되지 않으며, 모든 미션은 풀 상태로 시작한다.

## 6. 보호막 파괴 시 특수 처리

### 6.1 기본 원칙

보호막이 파괴되는 순간에는 특수 효과가 발동될 수 있다. 특수 효과는 **보호막 장비별로 데이터로 관리**되며, 장착한 보호막 종류에 따라 달라진다.

**발동 조건 (정확한 정의):** 보호막 파괴는 **유효 피해 처리 직전 보호막 > 0 이고, 처리 직후 보호막 = 0 이 된 경우에만** 발생한다.

- 보호막이 이미 0인 상태에서 체력 피해를 받아도 미발동
- 보호막이 다시 1 이상으로 회복된 뒤 재차 0이 되면 다시 발동
- 미션 시작·리스폰·디버그 설정으로 보호막이 0이 된 경우 미발동 (유효 피해가 아님)
- 무적으로 피해가 무시된 경우 미발동
- 오버차지 종료·디버그 값 변경 등 **유효 피해가 아닌 값 감소로 보호막이 0이 되어도 미발동** — 파괴 이벤트는 유효 피해가 원인인 0 전환으로만 한정한다

**처리 순서:** 보호막 피해 적용 → 보호막 0 확정 → 보호막 파괴 이벤트 발생 → 효과 실행 (파괴 무적·범위 피해·게이지 충전·버프 등). 파괴 범위 공격이 적을 격파한 경우의 귀속·스코어 처리는 판정 분리 시스템의 격파 귀속 규칙과 전투 처리 흐름 문서를 따른다.

### 6.2 특수 효과 예시

구체적인 효과 목록은 컨텐츠 기획 단계에서 정의하되, 고려 가능한 방향성은 다음과 같다.

- 보호막 파괴 후 짧은 추가 무적 시간 (4.3절 참고)
- 보호막 파괴 시 주변 적에게 에너지파 데미지
- 보호막 파괴 시 슈퍼웨폰 게이지 일정량 충전
- 보호막 파괴 시 일정 시간 화력 증가

이러한 효과들을 통해 플레이어가 **보호막을 의도적으로 깨뜨리는 전략적 플레이**도 가능하게 하며, 보호막 선택이 단순한 방어 스탯이 아닌 빌드 구성의 한 축이 되도록 한다.

구체적 효과 목록 및 데이터 구조는 **보호막 컨텐츠 기획**에서 다룬다.

## 7. 회복 시스템

### 7.1 회복 아이템

인게임에서 체력/보호막을 회복하는 수단은 **회복 아이템 1종**으로 통합한다.

### 7.2 회복 우선순위

회복 아이템 획득 시 처리:

1. 회복량을 먼저 **체력에 최대치까지 배분**한다
2. 체력을 채우고 남은 회복량이 있으면 **보호막에 이월 배분**한다 (예: 회복 2, 체력 1 부족 → 체력 +1, 보호막 +1)
3. 체력·보호막이 모두 최대인 상태에서 접촉하면 아이템은 소비되며 회복 효과는 없다 (만충 시 스코어 전환 여부는 아이템 드롭 시스템에서 결정)
4. 회복량 보정 결과가 소수이면 정수화(내림) 후 최소 1로 보정한다
5. "회복 아이템"은 회복 타입 1종을 뜻하며, 회복량이 다른 컨텐츠 변형이 가능하다. 프로토타입은 회복량 1 고정

이 우선순위를 통해 회복 아이템의 가치가 상황에 따라 달라진다.

- 위험한 상황(체력 낮음)에서는 생존에 직결되는 체력 회복
- 여유 있는 상황(체력 만충)에서는 보호막 충전으로 다음 전투 대비

### 7.3 슈퍼웨폰의 회복 효과

슈퍼웨폰 효과로 발동되는 회복은 **본 시스템의 회복 우선순위 규칙을 따르지 않고**, 슈퍼웨폰 효과 데이터에 명시된 동작을 따른다.

예시:
- 슈퍼웨폰 효과로 보호막만 회복 가능
- 슈퍼웨폰 효과로 체력만 회복 가능
- 슈퍼웨폰 효과로 보호막을 일시적 오버차지

슈퍼웨폰의 회복 효과는 슈퍼웨폰 시스템에서 효과별로 정의한다.

## 8. 저체력 경고 이펙트

체력이 일정 수치 이하로 낮아지면 **화면 주변에 경고 이펙트**가 표시된다. 시각적 피드백을 통해 플레이어가 즉각적으로 위험 상태를 인지할 수 있도록 한다.

저체력 경고는 **현재 체력이 저체력 경고 임계값 이하일 때 활성화**한다. 임계값은 전역 기본값을 두고 기체 데이터로 오버라이드 가능하다. 체력 총량이 3~4의 작은 정수이므로 프로토타입 기본값은 **체력 1**로 검증한다 [검증].

## 9. 시스템 간 연동 지점

| 연동 시스템 | 연동 내용 |
|-------------|-----------|
| 기체 시스템 | 체력 총량 결정. 기동 스탯은 전 기체 동일 (플레이어 기동 시스템 참고). |
| 로드아웃 시스템 | 보호막 장비 선택 |
| 슈퍼웨폰 시스템 | 회복 효과는 슈퍼웨폰에 명시된 동작을 따름. 오버차지 등 특수 효과 가능. |
| 슬롯 시너지 시스템 | 방어형 드론의 적탄 흡수 처리 (플레이어 보호) |
| 인게임 아이템 드롭 | 회복 아이템 드롭 |
| 플레이어 기동 시스템 | 무적 시간 중 조작 가능 범위 |
| 지상/공중 판정 분리 | 램 충돌의 발생 조건·재피격 주기는 판정 분리 시스템, 개별 판정의 데미지 처리는 본 시스템 (3.6) |
| 스코어링 시스템 | 사망 카운트가 노데스 보너스 판정에 사용 |
| 클리어 평가 시스템 | 피탄 카운트와 사망 카운트가 평가 항목으로 집계 |
| 동적 캠페인 시스템 | 미션 실패 시 기존 캠페인 진행·해금 상태 유지 (본 시스템은 상태만 담당, 실패 후 화면 흐름은 게임플로우·UI 문서 소관) |

**전투 처리 흐름 문서 결정 위임 항목 (동일 프레임 사건의 결정론적 순서):**

- 플레이어와 보스가 동시에 사망한 프레임
- 치명적 피해와 회복 아이템 획득이 같은 프레임
- 마지막 잔기 사망과 미션 종료가 같은 프레임
- 보호막 파괴 효과가 적을 격파해 미션이 끝난 프레임에 플레이어도 사망
- **사망 딜레이 중 잔존 탄환·설치물이 적을 격파했을 때의 보상 적용** (스코어·체인·게이지·도전과제·드롭 — 특히 사망으로 리셋된 체인이 잔존 미사일 격파로 재시작되는 것이 의도인지는 스코어링 문서와 함께 확정)
- **지속형 공격의 피탄 카운트 단위** (유효 피해 이벤트별 vs 접촉 단위 — 클리어 평가 구현 전 확정 필수)
- **동일 프레임에 복수의 피해 이벤트가 플레이어에게 도달한 경우의 처리 순서** — 1건씩 순차 처리하는지 / 앞선 이벤트에서 발동한 보호막 파괴 무적·피격 후 무적이 같은 프레임의 후속 이벤트에 즉시 적용되는지 / 복수 이벤트의 결정론적 정렬 기준. (권장안 [제안]: 결정된 순서로 1건씩 순차 처리하고, 앞선 이벤트로 발동한 무적은 같은 프레임의 후속 이벤트에도 즉시 적용 — 예: 보호막 1 상태에서 동시 2발 피격 시 첫 발이 보호막 파괴 → 파괴 무적 발동 → 둘째 발 무시. 보호막·무적의 의미가 가장 일관됨)

## 10. UI 영역

레이아웃·배치는 UI 기획 문서(인게임 HUD) 소관이다. 본 시스템이 UI에 요구하는 상태 전달 계약은 다음과 같다.

- 체력과 보호막을 별도 자원으로 표시한다
- 보호막 피해와 체력 피해의 이펙트·사운드를 명확히 구분한다
- 보호막 파괴 순간에 강한 피드백을 준다
- 각 무적 상태가 식별 가능한 시각 효과를 가진다
- 잔기 수를 표시한다
- 리스폰 진입과 조작 가능 시점을 표현한다
- 리스폰 적탄 소거는 전용 연출로 표현한다 (보상 연출 아님)
- 저체력 경고 (8장), 보호막 재생 시작·진행, 오버차지 영역 구분을 표시한다

## 11. 확정 사항 요약

| 항목 | 결정 사항 |
|------|-----------|
| 생존 자원 구조 | 체력(기체 스탯) + 보호막(장비 스탯)의 2층 구조 |
| 데미지 최소값 | 무적 판정 → 보정 계산 → 정수화 → 최소 1. 일반 피해 감소로 0 피해 불가 |
| 피격 처리 순서 | 9단계 확정 (3.2). 사망 시 피격 무적 미발동 |
| 피탄 카운트 | 기본 단위 = 승인된 유효 피해 이벤트. 지속형 틱별/접촉 단위 집계는 전투 처리 흐름 문서에서 확정 |
| 보호막 완전 흡수 | 잔량보다 큰 데미지도 1회 완전 흡수 (초과분 체력 비전달). 흡수는 보호막 정수 1 이상일 때만 활성 |
| 보호막 자동 재생 | 장비별 속도, 백업 역할. 유효 피해 시 대기+누적 0 초기화, 무시된 공격 무영향, 최대치 도달 시 누적 0·중지, 시작/사망/리스폰 초기화 |
| 재생 단위 | 정수 보호막 + 실수 재생 누적값 (1.0 도달마다 보호막 +1) |
| 램 데미지 | 기본 1 (몬스터 데이터 오버라이드), 일반 피격과 동일 파이프라인. 무적 트레이드 금지 안 함 (비용 구조 억제) |
| 무적 구조 | 출처 5종 독립 타이머, 합산 없음, 동일 출처 = max 갱신. 사망 시 귀속 무적 전부 제거, 리스폰 시 리스폰 출처만 시작 |
| 무시된 공격 | 생존 자원·피탄·파괴·재생 대기·피격 발동 효과에 흔적 없음. 단 공격 측 재판정 상태(램 타이머)는 해당 시스템 규칙 |
| 피격 후 무적 | 체력 데미지 시에만 발동. 2~3초 [검증]. 공격/회복 가능 |
| 보호막 파괴 무적 | 장비 데이터 효과, 짧은 시간. 완전 흡수 원칙상 동일 이벤트에서 피격 무적과 동시 신규 발동 없음 |
| 리스폰 무적 | 3초. 공격/회복 가능 |
| 보호막 파괴 이벤트 | 유효 피해로 직전>0 → 직후=0일 때만 발동. 비피해 감소(시작/리스폰/디버그/오버차지 종료)로는 미발동 |
| 보호막 파괴 특수 효과 | 장비 데이터 관리. 세부 효과는 컨텐츠 기획 |
| 잔기 | 잔기 수 = 남은 리스폰 횟수. 기본 1 (총 2회 생존 기회). 미션 시작 시 초기화, 변동 시스템 허용 |
| 사망 순간 | 게임 진행 유지 (조작만 불가). 상태 처리는 5.1 분류표. 격추 연출 길이 [검증] |
| 리스폰 | 하단 중앙+진입 연출 / 자원 풀 충전 / 게이지·스톡 유지 / 쿨다운 초기화 / 적탄 소거 1회 (데이터 속성, 보상 전무) / 드론 재생성 |
| 설치물 상한 | 무장별 최대 활성 수 데이터 제한 (초과 시 최고령 제거) — 사망 중첩 배치 차단 |
| 회복 | 회복 타입 1종 (변형 허용). 체력 우선 → 잔여 보호막 이월. 만충 시 소비+무효과. 정수화(내림)+최소 1. 한도 최대치 (슈퍼웨폰 오버차지 예외) |
| 미션 실패 | 새 기록·보상 미생성. 기존 클리어·랭크·해금 유지. 실패 후 흐름은 게임플로우/UI 문서 |
| 미션 시작 초기화 | 체력/보호막 풀, 잔기 1 (변동 허용), 재생 상태 초기화 |
| 저체력 경고 | 화면 주변 이펙트. 임계값 [검증] |

## 12. 프로토타입 검증 항목

| 항목 | 검증 내용 |
|------|-----------|
| 리스폰 딜레이·무적 값 | 격추 연출 길이 + 3초 무적의 체감 (재기 흐름이 끊기지 않는지) |
| 의도적 피격 무적 트레이드 | 체력 1 ↔ 무적 창 교환이 과도한 이득인지 (특히 램 밀착 딜) |
| 리스폰 적탄 소거 | 소거가 난이도를 과도하게 낮추지 않는지 |
| 램 데미지 기본값 | 기본 1이 공중 적 밀도 대비 적정한지 |
| 보호막 재생 대기·속도 값 | 대기 시간과 재생 속도의 체감 (백업 역할 수준 유지) |
| 설치물 상한 값 | 무장별 활성 상한의 적정 수 |
| 총 유효 생존력 | 체력+보호막+자동 재생+잔기+리스폰 풀 회복+적탄 소거의 합산이 게임을 지나치게 관대하게 만들지 않는지 (개별 규칙은 합리적이어도 총합은 반드시 별도 확인) |
| 지속형 피탄 집계 가혹성 | 빔·장판을 틱별로 셀 경우 클리어 평가가 지나치게 가혹해지지 않는지 (전투 처리 흐름의 단위 결정과 연동) |
