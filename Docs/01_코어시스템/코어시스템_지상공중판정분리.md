# 지상/공중 판정 분리 시스템 — 세부 기획

**문서 종류:** 코어 시스템 세부 기획
**상위 문서:** 슈팅게임 기획서 v0.6 (2.1절)
**Version 0.7**
**2026.08.13**

## 1. 개요

본 문서는 게임의 핵심 정체성인 **지상/공중 판정 분리 시스템**의 시스템 로직을 정의한다. 이 시스템은 다른 모든 시스템(로드아웃, 보스 페이즈, 스코어링 등)의 기반이 되며, 플레이어의 무장 선택이 전략적 판단으로 이어지는 구조의 뿌리이다.

데이터 테이블 스키마는 별도의 데이터 테이블 명세(프로그래머 관리)를 따른다. 본 문서는 런타임 판정 규칙과 시스템 간 책임만 정의한다.

## 2. 속성 정의

### 2.1 속성 분류

속성은 **적 대상(일반 적 유닛, 보스 본체, 보스 파츠)**과 **플레이어 및 아군이 적에게 사용하는 공격 수단(무장, 탄환, 데미지 효과)**에 부여하며, 다음 2가지 속성 중 하나 이상을 가진다.

적 → 플레이어 방향의 공격은 속성 시스템을 사용하지 않는다 (5장 단방향 원칙).

| 속성 | 의미 |
|------|------|
| 지상 | 지상에 위치한 유닛 또는 지상 대상 무장/탄환 |
| 공중 | 공중에 위치한 유닛 또는 공중 대상 무장/탄환 |

플레이어 기체는 속성 시스템 외부에 존재한다 (8장 참고).

### 2.2 단순 2분류 원칙

레이어 확장(지면/저공/중공/고공 등)은 도입하지 않는다. 플레이어 인지 부담을 최소화하기 위해 지상/공중의 2분류만으로 운영하며, 향후에도 이 원칙을 유지한다.

### 2.3 속성 할당 방식

| 대상 | 속성 할당 방식 |
|------|----------------|
| 일반 적 유닛 | 단일 속성 (Ground 또는 Air) |
| 보스 본체 | 단일 속성 또는 양면(지상+공중) 속성 가능 |
| 보스 파츠 | 단일 속성 또는 양면(지상+공중) 속성 가능 |
| 플레이어·아군 무장 / 탄환 / 데미지 효과 | 단일 또는 복수 속성 가능 |

대공 무장은 공중 속성만, 대지 무장은 지상 속성만, 범용 무장은 지상과 공중 속성을 모두 가진다.

무장이 복수 속성을 가질 수 있는 구조를 채택한 이유는 확장성 때문이다. 향후 특수 무장(예: 특정 조건에서만 두 속성을 가지는 무장)을 추가할 때 구조 변경 없이 대응 가능하다.

### 2.4 보스의 속성 처리

보스는 **본체와 파츠의 조합**으로 구성되며, 각각이 독립적인 속성을 가질 수 있다. 본체와 파츠 모두 단일 속성 또는 양면(지상+공중) 속성을 가질 수 있다.

이를 통해 다양한 보스 디자인이 가능하다. 예시:

- 비행형 보스: 본체 공중 + 파츠 공중
- 지상 거대 전차: 본체 지상 + 파츠 지상
- 혼합형 보스: 본체 양면 + 지상 파츠 + 공중 파츠
- 변신형 보스: 페이즈마다 다른 속성 구성 (페이즈 전환은 4장 참고)

## 3. 피격 판정 로직 (플레이어 및 아군 → 적)

### 3.1 기본 원칙: 관통 방식 채택

탄환과 적의 충돌 판정은 **관통 방식**으로 처리한다. 콜리전 자체는 발생하지만, 데미지 판정 단계에서 속성이 불일치하면 데미지를 무시하고 탄환이 계속 진행한다.

### 3.2 관통 방식을 채택한 이유

- **확장성:** 관통 레이저, 관통탄 같은 특수 무장을 추가할 때 자연스럽게 구현 가능
- **시각적 피드백:** 속성 불일치 시 "탄환이 지나간다"는 결과가 플레이어에게 "이 무기는 저 적에 통하지 않는다"를 직관적으로 전달

### 3.3 판정 흐름

탄환이 적(일반 적 유닛, 보스 본체, 보스 파츠)과 충돌했을 때의 처리 순서:

1. **콜리전 감지:** 탄환과 적의 콜리전이 겹친 것을 감지
2. **속성 비교:** 탄환의 속성 배열과 적의 속성을 비교
3. **분기 처리:**
    - **속성 일치:** 데미지 적용, 피격 이펙트 재생, 탄환 처리(3.5절 참고)
    - **속성 불일치:** 데미지 무시, 피격 이펙트 미재생, 탄환은 그대로 진행

### 3.4 속성 일치 판정 규칙

탄환이 가진 속성 중 **하나라도** 적의 속성과 일치하면 "속성 일치"로 판정한다.

| 탄환 속성 | 적 속성 | 판정 |
|-----------|---------|------|
| 대공 (공중) | 공중 | 일치 |
| 대공 (공중) | 지상 | 불일치 |
| 대지 (지상) | 지상 | 일치 |
| 대지 (지상) | 공중 | 불일치 |
| 범용 (지상+공중) | 공중 | 일치 |
| 범용 (지상+공중) | 지상 | 일치 |
| 대공 (공중) | 양면 (지상+공중) | 일치 |
| 대지 (지상) | 양면 (지상+공중) | 일치 |
| 범용 (지상+공중) | 양면 (지상+공중) | 일치 |

### 3.5 탄환의 충돌 후 처리

속성 일치로 데미지가 적용된 후 탄환의 처리는 **탄환 데이터의 "충돌 후 처리" 속성**으로 결정한다.

| 처리 유형 | 설명 |
|-----------|------|
| 소멸 | 첫 번째 속성 일치 **유효 명중** 후 즉시 소멸. 일반 탄환의 기본 동작. (불일치 접촉으로는 소멸하지 않음) |
| 관통 | 충돌해도 소멸하지 않고 계속 진행. 관통 레이저, 관통탄 등. |
| 제한 관통 | 최대 N개 대상에 **유효 명중**한 뒤 소멸 (N에 첫 명중 포함). 데이터에서 N 값 설정. |

소멸/관통/제한 관통은 탄환마다 데이터로 차등 설정 가능하다.

**제한 관통의 의미:** 관통 수치는 **최대 명중 대상 수**로 정의한다 (첫 명중 포함). 예: 제한 관통 3 = 총 3개 대상에게 명중 후 소멸. 일반 탄환은 최대 명중 1과 동일한 규칙으로 통일된다.

**동일 적 재타격 금지:** 한 탄환이 관통 후 동일한 적에게 다시 데미지를 주지 않는다. 명중 이력은 적의 종류가 아니라 **개체(인스턴스) 단위**로 관리한다 — 같은 종류의 적 여러 마리는 서로 다른 대상이다.

**속성 불일치 접촉:** 유효 명중으로 처리하지 않는다. 명중 이력에 등록되지 않으며, 관통 가능 횟수도 차감하지 않는다. (구현 주의: "콜리전 발생 = 관통 차감"으로 구현하면 안 된다)

**동일 프레임 다중 접촉:** 무제한 관통이거나 남은 명중 가능 수가 충분하면, 같은 프레임에 접촉한 속성 일치 대상 전부에 각각 명중한다. 남은 명중 가능 수가 접촉 대상 수보다 적으면 **탄환 진행 방향 기준으로 가까운 대상부터 순서대로** 남은 수만큼만 명중하고, 나머지에는 판정을 발생시키지 않는다. (구현 주의: 물리 엔진의 충돌 콜백 수신 순서는 안정적이지 않으므로 콜백 순서로 처리하지 않는다. 진행 방향 투영 거리가 동일한 경우 런타임 개체 식별자 오름차순으로 처리하여 결과를 결정론적으로 유지한다)

복수의 탄환이 같은 적에 동시 명중하는 경우는 각각 독립적으로 데미지를 적용한다. 격파 발생 시의 스코어·체인 처리 순서는 전투 처리 흐름 문서를 따른다.

### 3.6 범용 무장의 판정

범용 무장의 탄환은 지상과 공중 속성을 모두 가지므로, 지상 적과 공중 적 모두에 피격 판정이 유효하다. 하나의 탄환이 양쪽 속성 모두를 가지는 단일 객체로 처리되며, 탄환을 두 개로 분리 발사하거나 별도의 처리 로직을 두지 않는다.

### 3.7 폭발·범위 데미지의 속성 판정

**범위 데미지는 발생원 공격 효과의 속성을 사용한다.** 탄환이 발생원이면 탄환 속성을, 슈퍼웨폰·보호막·드론 효과가 발생원이면 해당 효과 데이터의 속성을 사용한다. 대지 미사일의 폭발 범위에 공중 적이 걸쳐 있어도 공중 적은 타격하지 않는다.

- 범위 안의 유닛 각각에 대해 속성 일치 판정을 개별 수행한다
- 양쪽 속성 모두를 타격하는 광역은 범용 속성으로 정의한다 (범용은 "속성 무시"가 아니라 지상·공중 모두에 일치하는 복수 속성이다)
- **직격과 폭발은 별개의 데미지 이벤트다.** 직격 대상이 폭발 범위 데미지도 추가로 받을지는 폭발 효과 데이터의 **"직격 대상 포함" 설정으로 무기별 결정**한다. 기본값은 포함 안 함 (일반 무기의 이중 타격 인플레 방지). 관통 후 폭발하는 철갑유탄류 컨셉 무기는 이 설정을 켜서 직격+폭발 데미지를 모두 적용한다

### 3.8 지속형 히트 (빔·레이저·장판)

지속형 무기는 **틱 주기 기반 재판정**으로 처리한다.

- 지속 무기는 **탄환/효과 데이터에 정의된 틱 주기**마다, 그 시점에 접촉 중인 **속성 일치 대상 전체**에 데미지를 적용한다
- 틱과 틱 사이에는 판정이 발생하지 않는다 (접촉 유지와 무관)
- 3.5의 동일 적 재타격 금지는 단발 탄환의 규칙이며, 지속형은 틱마다 재타격이 정상 동작이다
- **첫 틱은 최초 접촉 시점에 즉시 적용**하고, 이후 틱 주기마다 재판정한다 (짧게 스친 대상에게 데미지가 전혀 없는 상황 방지)
- 틱 주기는 해당 탄환/효과 데이터에서 단일 관리한다 (무기 데이터와 탄환/효과 데이터에 중복 저장하지 않는다)

### 3.9 유도 무장의 표적 선택

**유도(호밍) 무장은 속성 일치 대상만 표적으로 선택한다.**

- 대공 유도 무장은 공중 적만, 대지 유도 무장은 지상 적만 추적한다
- 범용 유도 무장은 양쪽 속성 모두를 표적 후보로 삼는다
- 속성 일치 표적이 화면 내에 없으면 유도하지 않고 직진한다
- 표적 선택 우선순위(최근접 등)의 세부는 무기 데이터/컨텐츠 기획에서 정의한다
- **표적 소실 시:** 표적이 파괴되거나 화면 밖으로 완전 이탈하면, 재탐색형 무장은 새 유효 표적을 탐색하고 직진형 무장은 현재 진행 방향으로 직진한다 (재탐색 여부는 무기 데이터)
- **표적 획득 시점:** "발사 시점만 탐색" / "비행 중 계속 탐색"의 2모드를 무기 데이터로 지원한다. 프로토타입 기본 모드는 발사 시점 탐색으로 확정한다 (단순하고 탄환 행동 예측이 쉬움)
- **유효 표적 조건:** 활성 상태 + 미파괴 + 피격 콜리전 활성 + 속성 일치 + 플레이필드 내 + 페이즈 전환 무적 상태 아님

### 3.10 적탄 상쇄 (탄소거)

**플레이어의 일반 공격은 적탄을 상쇄하지 않는다.** 탄막 회피가 이 게임의 기본 문법이다.

- 탄소거는 슈퍼웨폰 효과, 시너지(드론) 효과 등 특수 효과로만 발생 가능하다 (효과 카탈로그의 확장 여지)
- 드론의 적탄 흡수(슬롯 시너지 시스템)는 별개의 방어 메커니즘이며 본 규칙과 충돌하지 않는다
- 구현 규칙: **일반 플레이어 탄환과 적탄은 충돌 검사 자체를 수행하지 않는다** (탄환 간 충돌 채널 무시). 특수 탄소거 효과만 별도의 범위 검사로 처리한다

### 3.11 아군 발사체의 소속

드론 등 아군 유닛의 발사체는 플레이어 탄환과 **동일한 판정 규칙**을 따른다. 속성은 해당 드론 무기 데이터의 속성을 사용한다 (슬롯 시너지 시스템 참고).

**격파 귀속:** 플레이어가 소유한 모든 공격 수단(기체 무장, 드론, 설치물, 슈퍼웨폰)에 의한 격파는 전부 **플레이어 격파로 귀속**된다 — 격파율·체인·슈퍼웨폰 게이지·도전과제에 동일하게 반영된다. 세부 스코어 처리 순서는 전투 처리 흐름 문서를 따른다. (구현상 모든 발사체·공격 효과는 소유자와 발생 무기 식별 정보를 가져야 한다)

### 3.12 슈퍼웨폰 효과의 처리

슈퍼웨폰 효과는 본 시스템의 관통 방식 판정을 그대로 따르지 않는다. 슈퍼웨폰의 효과는 다양한 형태(광역 폭격, 즉시 회복, 무적 등)를 가지므로 일반 탄환의 판정 흐름으로 처리하기 어렵다.

슈퍼웨폰 효과의 처리는 **슈퍼웨폰 시스템 세부 기획**에서 효과별로 개별 정의한다. 단, 효과에 부여된 속성은 본 시스템의 속성 일치 규칙을 동일하게 따르며, 범위형 효과는 3.7의 범위 데미지 규칙을 적용한다.

### 3.13 피격 이펙트 처리

속성 불일치 시 피격 이펙트를 재생하지 않는다. 이는 플레이어의 혼란을 방지하기 위함이다. 피격 이펙트가 뜨면 플레이어는 "맞았는데 왜 안 죽지?"라는 혼란을 겪을 수 있으므로, 이펙트 자체를 재생하지 않아 "이 무기는 이 적에 무효"임을 명확히 전달한다.

### 3.14 변형 규칙 미사용

"속성 불일치 시 감소된 데미지로 통과" 같은 변형 규칙은 **도입하지 않는다.** 기본 전투 규칙은 단순명료하게 0/100(불일치/일치) 두 가지 결과만 가지며, 복잡한 부분 통과 메커니즘은 사용하지 않는다.

## 4. 보스 본체 및 파츠 판정

### 4.1 본체와 파츠의 구조

보스는 **본체 콜리전 + 개별 파츠 콜리전**으로 구성된다.

- 보스의 모델링 전체에 콜리전을 부여하지 않는다.
- 본체는 데미지를 받을 수 있는 영역으로 별도 콜리전을 가진다.
- 파츠는 본체와 별개로 개별 콜리전과 속성을 가진다.
- 보스 본체는 체력 모드에 따라 통합 체력 또는 페이즈별 체력을 가진다 (보스 페이즈 시스템의 체력 모드 준수).
- 파츠는 별도의 파츠 체력을 가지며, 파츠가 받은 데미지는 보스 페이즈 시스템 규칙에 따라 현재 보스 체력에도 반영된다.

탄환과 보스의 충돌 판정은 본체 또는 파츠 단위로 개별 처리된다. 본체와 파츠 사이의 빈 공간(모델링은 있으나 콜리전이 없는 영역)에는 탄환이 통과한다.

**본체·파츠 콜리전 중첩 처리:** 동일 탄환이 동일 프레임에 파츠와 그 뒤에 겹친 본체 콜리전에 동시 접촉하면 **파츠 판정을 우선**하고, 해당 프레임의 본체 직접 피격은 무시한다 (같은 위치의 파츠+본체 중첩으로 인한 우발적 이중 데미지 차단). 관통탄이 서로 떨어진 파츠들을 순차적으로 명중하는 것은 의도된 다중 명중으로 정상 허용한다.

**범위 데미지와 보스 — 단일 대상 적용:** 하나의 범위 데미지 이벤트(폭발 등)가 보스의 본체·복수 파츠를 동시에 덮어도, **보스에게는 단 1개 대상에만 데미지를 적용한다.**

- 대상 선택 절차 (순서 엄수):
  1. 범위 내 속성 일치·활성 상태 대상(본체·파츠)을 후보로 수집한다
  2. **"직격 대상 포함"이 꺼져 있으면 직격한 개체(본체 또는 파츠)를 후보군에서 제외한다** — 최근접 탐색에서 다시 선택되는 것을 방지 (직격 지점은 통상 폭발 중심과 최근접이므로, 제외를 후보 수집 단계에서 하지 않으면 설정이 무효화된다)
  3. "직격 대상 포함"이 켜져 있고 직격 대상이 후보에 있으면 직격 대상을 선택한다
  4. 그렇지 않으면 폭발 중심에서 가장 가까운 속성 일치 파츠를 선택한다
  5. 유효한 파츠가 없으면 유효한 본체를 선택한다
  - 거리 동률은 3.5의 결정론 규칙(런타임 개체 식별자 오름차순)을 따른다
- **지속형 범위 효과(장판 등)의 각 틱은 독립된 범위 데미지 이벤트**로 처리하며, 틱마다 위 단일 대상 선택을 다시 수행한다 — 폭발 1회 / 슈퍼웨폰 광역 1회 / 장판·지속 레이저의 각 틱이 전부 동일 규칙
- 단일 대상 제한은 **보스 개체 단위**로 적용한다. 하나의 범위 이벤트에 복수의 보스급 개체가 포함되면 각 개체마다 최대 1개 대상을 선택한다
- 의도: 다중 파츠 중첩 적용을 허용하면 폭발 한 번에 보스 체력이 파츠 수만큼 배수로 깎여 보스가 녹는다. 보스전에서 광역 무기는 범위가 아니라 단발 화력으로 평가된다
- **일반 적에게는 3.7의 기존 규칙 그대로** — 범위 내 속성 일치 대상 전부 개별 타격. 광역 무기의 잡몹 청소 역할은 유지된다
- 밸런스 지침: 폭발 범위 자체를 작게 설계하는 것을 기본 방침으로 한다

### 4.2 페이즈 전환 = 본체+파츠 세트 교체

보스 페이즈 전환은 **새로운 본체와 파츠 세트의 등장**으로 구현한다. 활성/비활성 토글 방식이 아니다.

- 페이즈 1의 보스가 체력 임계값 등 조건에 도달하면 변신/등장 연출 발생
- 페이즈 2의 새로운 본체+파츠 세트가 등장
- 이전 페이즈의 본체+파츠는 사라지거나 형태가 완전히 변경됨

각 페이즈는 자기만의 본체+파츠 세트를 가지며, 한 시점에는 한 페이즈의 본체+파츠만 존재한다.

### 4.3 페이즈 유형의 자연스러운 결정

페이즈 유형(양면/공중 전용/지상 전용)은 그 페이즈에 등장하는 본체와 파츠의 속성 조합으로 자연스럽게 결정된다.

| 페이즈 유형 | 본체+파츠 속성 구성 예시 |
|-------------|---------------------------|
| 양면 페이즈 | 본체 양면(지상+공중) 또는 지상/공중 파츠 모두 존재 |
| 공중 전용 페이즈 | 본체 공중 + 파츠 공중 |
| 지상 전용 페이즈 | 본체 지상 + 파츠 지상 |

### 4.4 파츠 재생과 비활성 처리

페이즈 전환과 별개로, **파괴된 파츠의 재생 메커니즘**이 존재한다.

- 파츠가 파괴되면 일정 시간 동안 비활성 상태로 전환
- 비활성 상태의 파츠는 콜리전이 사라져 탄환이 관통
- 재생 시간이 경과하면 파츠가 다시 콜리전을 가지며 활성화

비활성 상태가 발생하는 경우는 파츠 파괴 후 재생 대기 중일 때뿐이다. 페이즈 전환에서 활성/비활성 개념은 사용하지 않는다.

파츠 재생 여부 및 재생 시간은 파츠 데이터에서 설정한다 (보스 페이즈 시스템 참고).

### 4.5 시각적 연출과의 연동

페이즈 전환 시 변신/등장 연출은 시각적 신호로 작동한다. 보스의 형태 변화 자체가 "지금부터 무장 전략을 바꿔야 한다"는 신호가 되며, 3D 모델을 활용하여 풍부한 변신 연출을 제공한다.

## 5. 적 공격 판정 (적 → 플레이어)

### 5.1 단방향 시스템 원칙

속성 시스템은 **플레이어 → 적 방향에만 적용**되는 단방향 시스템이다. 적이 플레이어를 공격하는 방향에는 속성 시스템 자체가 적용되지 않는다. 이 원칙은 **공격 데미지의 속성 일치 판정**에 관한 것이며, 적 본체와의 공간 충돌 필터(6장 램)는 별개의 규칙이다.

### 5.2 적 공격의 처리

적의 공격(탄환, 근접 공격 등)은 다음과 같이 처리된다.

1. 적 공격의 콜리전과 플레이어 기체의 히트박스 충돌 감지
2. 충돌 시 데미지 적용

속성 비교 단계가 없으며, 모든 적 공격은 플레이어에게 명중 가능하다.

### 5.3 적 공격에 속성을 두지 않는 이유

플레이어 기체는 지상/공중 레이어를 오가는 존재가 아니므로, 적 공격에 속성을 부여할 의미가 없다. 시스템 복잡도를 최소화하고 단방향 시스템 원칙을 유지한다.

## 6. 본체 충돌 (램)

### 6.1 충돌 발생 조건

**플레이어 기체는 공중 적과만 본체 충돌이 발생한다. 지상 적·지상 파츠와는 충돌하지 않는다.**

- 지상 유닛은 플레이어와 고도가 다르다는 시각 설정(그림자 밀착/분리 식별)과 물리 규칙이 일치한다 — 플레이어는 전차나 지상 구조물 위를 그대로 통과한다
- 보스 파츠도 동일: 공중 속성 파츠만 충돌 발생, 지상 속성 파츠는 통과. **양면(지상+공중) 속성 대상은 공중을 포함하므로 충돌 대상이다**
- 5.1의 단방향 원칙과는 별개다: 단방향 원칙은 공격 데미지의 속성 판정에 관한 것이고, 램은 **공간 충돌 필터**다

### 6.2 충돌 처리 방식

- 램은 물리적 밀어내기가 아닌 **겹침(overlap) 데미지**로 처리한다. 플레이어와 적은 서로 밀려나거나 이동이 차단되지 않는다
- 기본적으로 **플레이어만 데미지를 받는다.** 적 측의 램 피해·자폭·소멸 여부는 개별 몬스터 행동 데이터에서 정의한다 (예: 소형 자폭기 = 충돌 시 자폭 소멸)
- **연속 접촉은 램 재피격 주기로 제어한다.** 최초 접촉 시 1회 피해 → 같은 공격자와 겹침이 유지되는 동안 램 재피격 주기마다 재판정 → 접촉이 끊기면 공격자별 램 타이머 초기화. 겹친 채 유지하는 것에 대한 반복 피해는 의도된 동작이다
- **모든 램 판정(최초 접촉 포함)은 플레이어 무적 상태를 확인한다.** 무적으로 판정이 무시된 경우에도 해당 재피격 시점은 소비되며, 다음 판정은 다시 전체 재피격 주기가 지난 뒤 수행한다 — 무적 종료 순간 보류된 피해가 즉시 들어가는 불안정한 체감을 방지 (리스폰 무적 중 적과 겹쳐 있어도 무적이 끝나는 순간 바로 맞지 않는다)
- 재피격 주기가 무적 시간과 별개로 필요한 이유: **보호막 흡수는 피격 무적을 발동시키지 않으므로** (생존 시스템), 무적 시간만으로 간격을 제어하면 보호막이 겹침 상태에서 프레임 단위로 연속 소진된다. 주기 값은 프로토타입에서 확정 [검증]
- 동시에 복수의 공중 적과 겹친 경우 **공격자별로 각각 독립 판정**한다. 다중 돌진 패턴에서 순간 피해가 과도하지 않은지는 프로토타입 검증 항목 [검증]
- 충돌 데미지량·무적 시간과의 연동 세부는 생존 시스템에서 정의한다

## 7. 화면 밖 존재 처리

### 7.1 상태별 규칙

플레이필드 밖의 존재는 판정을 발생시키지 않으며, 역할이 끝난 존재는 즉시 제거한다.

| 상태 | 처리 |
|------|------|
| 스폰 대기 (등장 예약 — 화면 밖에서 진입 전) | **제거 금지.** 판정·발사 없음 |
| 필드 내 활동 | 정상 판정 |
| 패턴 종료 후 완전 이탈 | **즉시 제거** |
| 재진입 패턴 보유 적 | 화면 밖 체류 중 제거 유예 (판정·발사는 정지), 재진입 시 정상 복귀 |
| 보스 | 제거 대상 아님 (연출상 화면 밖 이동 허용) |

**판정 기준:**
- 필드 내 활동 = 대상의 콜리전 영역이 플레이필드와 일부라도 겹쳐 있는 상태 (대형 적이 절반만 걸쳐 있어도 활동 중)
- 완전 이탈 = 대상의 콜리전 영역 전체가 플레이필드 밖에 있는 상태

**탄환 제거:** 탄환은 콜리전 영역 전체가 플레이필드를 벗어나는 즉시 제거한다. 단, 이 규칙은 일반 게임플레이 발사체에만 적용한다 — 슈퍼웨폰·지원 연출·시네마틱 전용 오브젝트(좌우 영역을 드나드는 연출체)는 각 시스템의 별도 이동/제거 규칙을 따른다.

### 7.2 화면 밖 발사 금지

발사 가능 여부는 **발사구(공격 발생 지점)가 플레이필드 내부에 있는지**로 판정한다. 대형 적의 몸 일부가 화면 안이라도 발사구가 밖이면 발사하지 않는다 — 화면 밖에서 날아드는 "보이지 않는 탄"을 금지하기 위함이다.

### 7.3 격파율 확정 시점

격파율은 "등장한 적 대비 격파한 적"이며, 확정 흐름은 다음과 같다 (클리어 평가 시스템 연동).

1. 평가 대상 적이 **최초로 필드 활동 상태에 진입**할 때 해당 개체를 격파율 분모에 등록한다
2. 격파되면 분자에 반영하고 **격파로 확정**한다
3. 재진입 없이 완전 이탈하면 **미격파로 확정**한다
4. 재진입 패턴 적은 일시적 화면 밖 이탈로 확정하지 않으며, 최종 이탈 또는 격파 시 확정한다

보조 규칙:
- **평가 대상 여부는 적 데이터로 지정한다.** 연출용·무적·장식 유닛은 집계 제외
- **보스 소환 잡몹은 격파율 집계에서 기본 제외한다.** 소환 잡몹을 분모에 넣으면 보스전이 길어질수록 격파율이 왜곡되고, 스테이지 종료 시 잔존 문제가 생긴다. 격파율 집계에서만 제외될 뿐, 격파 시 스코어·체인·슈퍼웨폰 게이지 등 일반 격파 보상은 정상 적용된다 (전투 위협·공격 기능도 일반 적과 동일). 특정 보스전에서 집계에 포함하려면 데이터로 켤 수 있다
- 시스템·연출에 의한 강제 제거(보스 진입 연출·스크롤 전환 등의 일괄 제거)와 스테이지 종료 시점의 미확정 잔존 적은 **평가에서 제외한다 (분모에서 소급 제거)** — 플레이어가 교전을 끝낼 기회가 없었던 적을 미격파로 벌하지 않는다

## 8. 플레이어 기체의 속성 처리

### 8.1 플레이어 무속성 원칙

플레이어 기체는 **속성 시스템 외부에 존재**한다. 플레이어에게는 Ground/Air 속성이 부여되지 않는다.

### 8.2 무속성 원칙의 의미

- 플레이어 기체에 적 공격이 닿으면 속성 검증 없이 모두 명중한다
- 플레이어가 어떤 빌드를 선택하더라도 적 위협의 강도는 동일하게 유지된다
- 플레이어 기체의 위치(공중에 있다는 설정)는 시나리오상 설정일 뿐, 시스템 속성으로 처리되지 않는다

## 10. UI 영역

레이아웃·화면 구성은 UI 기획 문서 소관이다. 본 시스템이 UI에 요구하는 전투 피드백 계약은 다음과 같다.

- 무장 표시(HUD·로드아웃)에는 범용/대공/대지 속성 식별 표기를 포함한다
- 유도 무장의 타겟 마커는 유효한 속성 일치 대상에만 표시한다
- 속성 불일치 접촉은 피격 이펙트·피격음·데미지 표기를 일절 출력하지 않는다
- 지상/공중의 시각 식별은 좌표계·카메라·화면 규격 문서의 고도/그림자 원칙을 따른다

## 11. 확정 사항 요약

| 항목 | 결정 사항 |
|------|-----------|
| 폭발·범위 데미지 | 발생원 효과의 속성 사용 (탄환/슈퍼웨폰/드론 등). 범위 내 개별 판정. 직격·폭발은 별개 이벤트 — 직격 대상 포함 여부는 무기 데이터 (기본 미포함, 철갑유탄류는 켬) |
| 지속형 히트 | 최초 접촉 즉시 1틱 + 틱 주기 재판정 (틱마다 재타격 정상). 틱 주기는 탄환/효과 데이터에서 단일 관리 |
| 관통 규칙 | 관통 수치 = 최대 명중 대상 수 (첫 명중 포함). 동일 개체 재타격 금지 (인스턴스 기준). 불일치 접촉은 이력·차감 없음. 명중 수 부족 시 진행 방향 근접순 |
| 유도 표적 | 속성 일치 대상만 추적 (범용은 양쪽). 일치 표적 없으면 직진. 소실 시 재탐색/직진, 획득 시점 2모드 — 무기 데이터. 프로토 기본 = 발사 시점 탐색 (확정) |
| 적탄 상쇄 | 기본 없음 — 탄환 간 충돌 검사 자체 미수행. 슈퍼웨폰/시너지 효과로만 가능 |
| 아군 발사체 | 동일 판정 규칙. 플레이어 소유 공격의 격파는 전부 플레이어 귀속 (격파율·체인·게이지·도전과제) |
| 보스 콜리전 중첩 | 파츠+본체 동시 접촉 시 파츠 우선, 해당 프레임 본체 피격 무시. 떨어진 파츠 순차 관통은 허용 |
| 램 충돌 | 공중 적·공중 파츠(양면 포함)와만 발생. overlap 데미지 (밀어내기 없음), 기본 플레이어만 피해. 연속 접촉은 무적과 별개의 램 재피격 주기로 제어 (보호막 연속 소진 방지), 공격자별 독립 판정 |
| 폭발 × 보스 | 범위 이벤트는 보스 개체당 단일 대상만 타격 (후보 수집 → 직격 제외/선택 → 최근접 파츠 → 본체). 지속형 각 틱 = 독립 이벤트. 일반 적은 전부 타격 유지. 폭발 범위는 작게 설계 |
| 화면 밖 처리 | 콜리전 영역 기준 (걸침=활동 / 전체 이탈=제거). 발사는 발사구 기준. 스폰 대기 보호 / 재진입 유예 / 보스 제외 / 연출체 예외 |
| 격파율 확정 | 활동 진입 시 분모 등록 → 격파/최종 이탈 시 확정. 보스 소환 잡몹 기본 집계 제외. 강제 제거·종료 잔존은 평가 제외 |
| 속성 분류 | Ground / Air 의 2분류 |
| 일반 적 유닛 속성 | 단일 속성 |
| 보스 본체 / 파츠 속성 | 단일 또는 양면 속성 가능 |
| 무장/탄환 속성 | 단일 또는 복수 속성 가능 |
| 범용 무장 처리 | 탄환이 지상+공중 속성을 모두 가지는 단일 객체 |
| 피격 판정 방식 | 관통 방식 (콜리전 감지 후 속성 비교, 불일치 시 데미지 무시 + 탄환 진행) |
| 탄환 충돌 후 처리 | 데이터 설정. 소멸 / 관통 / 제한 관통 |
| 속성 불일치 시 이펙트 | 피격 이펙트 미재생 |
| 변형 규칙 | 미사용. 0/100 단순 규칙 유지. |
| 보스 본체 콜리전 | 본체+파츠 모두 개별 콜리전 보유. 보스 체력은 보스 페이즈 시스템의 통합/페이즈별 모드를 따르며, 파츠 데미지는 현재 보스 체력에 반영 |
| 페이즈 전환 | 새 본체+파츠 세트 교체 방식 (활성/비활성 토글 아님) |
| 페이즈 유형 결정 | 본체+파츠 속성 조합으로 자연스럽게 결정 |
| 파츠 재생 | 파괴 후 일정 시간 비활성, 재생 시간 경과 후 재활성화 |
| 적 → 플레이어 공격 | 속성 시스템 자체가 적용되지 않음 (단방향) |
| 슈퍼웨폰 효과 | 슈퍼웨폰 시스템에서 개별 정의. 속성 일치 규칙은 동일. |
| 플레이어 기체 | 속성 시스템 외부에 존재 (무속성) |
