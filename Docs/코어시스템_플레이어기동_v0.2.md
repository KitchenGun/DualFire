## 1. 개요

본 문서는 플레이어 기체의 **기동 시스템**을 정의한다. 이동 속도 모드, 히트박스, 이동 범위, 입력 방식 등 플레이어 기체의 조작과 관련된 기본 스펙을 다룬다.

본 시스템은 모든 기체에 공통으로 적용되며, 기체별 기본 기동 차이는 두지 않는다. 단, 슈퍼웨폰 효과, 기체 특성, 슬롯 시너지 등에서 일시적으로 기동에 영향을 줄 수 있다 (6장 참고).

## 2. 이동 속도 모드

### 2.1 2단계 속도 지원

플레이어 기체는 통상 속도와 저속 모드의 2가지 이동 속도를 가진다.

| 모드 | 용도 |
|------|------|
| 통상 속도 | 기본 이동. 일반적인 전투 상황에서 사용. |
| 저속 모드 | 정밀 이동. 고난도 구간에서 정밀 회피 시 사용. |

### 2.2 2단계를 채택한 이유

이 게임은 탄막 슈팅이 아닌 피탄 허용형 설계이므로, 정밀 회피 단계를 다단계로 나눌 필요가 적다. 2단계가 입력 복잡도와 활용도의 균형점이다.

### 2.3 저속 모드 속도 비율

저속 모드의 이동 속도는 통상 속도 대비 **데이터로 설정 가능**하다. 구체적인 비율은 프로토타입에서 결정한다.

### 2.4 저속 모드 진입 방식

- **기본 설정:** 홀드 방식. 지정 버튼을 누르고 있는 동안 저속 모드 유지, 떼면 통상 속도로 복귀
- **옵션 설정:** 토글 방식으로 변경 가능. 버튼을 한 번 누르면 저속, 다시 누르면 통상으로 전환

홀드/토글 전환은 게임 옵션에서 플레이어가 선택할 수 있다.

### 2.5 저속 모드 시 시각적 피드백

저속 모드 진입 시 **히트박스를 표시하지 않는다.** 이 게임은 탄막 슈팅이 아닌 피탄 허용형 설계이므로, 히트박스 표시가 회피를 지나치게 쉽게 만들어 보호막 관리의 의미가 희석된다. 저속 모드 진입 여부는 기체 이펙트 변화(엔진 출력 변화 등) 정도의 경미한 시각적 피드백으로 처리한다.

## 3. 이동 방향 및 처리

### 3.1 8방향 이동

플레이어 기체는 **8방향(상하좌우 + 대각선) 이동**을 지원한다. 종스크롤 슈팅의 표준 방식이다.

### 3.2 즉각 반응

키 입력 즉시 최대 속도로 이동한다. 가속 또는 감속 곡선은 두지 않는다. 이는 슈팅 게임의 정밀 조작감을 위한 표준 방식이다.

### 3.3 대각 이동 속도 보정

대각 이동 시 **속도 보정을 적용**한다. 보정 없이 8방향 이동을 처리하면 대각선 방향이 다른 방향보다 빠르게 이동하는 문제가 발생한다. 모든 방향에서 동일한 이동 속도가 유지되도록 보정한다.

---

## 4. 히트박스

### 4.1 크기 방향성

히트박스 크기는 프로토타입에서 최종 결정하되, 다음 방향성을 따른다.

- 기체 모델보다 작게 설정 (모델 크기 = 히트박스가 아님)
- 탄막 슈팅 게임보다는 크게 설정 (극단적으로 작은 히트박스 미채용)
- 피탄 허용형 설계 의도와 일관되게, 회피 자체는 가능하되 완전 회피가 아닌 보호막 관리가 핵심이 되도록

### 4.2 고정 크기

히트박스 크기는 **이동 속도 모드와 무관하게 고정**이다. 통상 속도에서도 저속 모드에서도 히트박스 크기는 동일하다.

고정 크기를 채택한 이유는, 히트박스가 동적으로 바뀌면 피격 판정이 직관적이지 않게 되기 때문이다. 플레이어가 고속과 저속을 넘나들며 전투하는 상황에서 히트박스까지 변하면 "지금 맞을 건지 안 맞을 건지" 판단이 불안정해진다.

### 4.3 전 기체 동일

히트박스 크기는 **모든 기체에서 동일**하다. 기체별 기동 차이를 두지 않는 원칙의 일환이다.

---

## 5. 이동 범위

### 5.1 화면 전체 이동

플레이어 기체는 **화면 전체 범위에서 자유롭게 이동**할 수 있다. 하단 제한 같은 이동 범위 제약은 두지 않는다. 화면 경계 밖으로는 이동 불가.

### 5.2 화면 경계 처리

플레이어가 화면 경계에 도달하면 보이지 않는 벽처럼 작동하여 그 너머로 이동할 수 없다. 입력은 받아들이되 위치는 경계에서 고정된다.

### 5.3 스크롤과 플레이어 이동의 관계

자동 스크롤은 플레이어의 이동과 **완전히 독립적**으로 동작한다.

- 플레이어가 위로 이동해도 스크롤이 빨라지지 않음
- 플레이어가 아래로 이동해도 스크롤이 느려지지 않음
- 플레이어가 화면 어느 위치에 있더라도 스크롤은 정상 진행
- 스크롤 속도는 스테이지 데이터에 의해서만 결정됨

플레이어는 자동 스크롤되는 화면 내에서 자유롭게 이동하며 전투한다. 스크롤은 전장이 흘러가는 흐름이고, 플레이어는 그 안에서 움직이는 별개의 대상이다.

---

## 6. 기동 스탯과 기체의 관계

### 6.1 전 기체 동일 기본 기동

기본 기동 스탯(이동속도, 저속 모드 속도, 히트박스 크기)은 **모든 기체에서 동일**하다. 기체별 기본 기동 차이를 두지 않는다.

### 6.2 전 기체 동일 기동을 채택한 이유

- **레벨 디자인 일관성:** 기체마다 이동속도가 다르면 같은 스테이지의 난이도가 기체에 따라 달라진다. 모든 기체에서 동일한 레벨 경험을 제공하기 위해 기동을 통일한다.
- **차별화 축 집중:** 기체의 차별점은 체력 총량과 기체 특성에 집중한다. 이를 통해 기체 선택은 "어떤 스탯과 패시브 효과를 가져갈 것인가"의 판단이 되며, 조작감 차이에 의한 불균형을 방지한다.

### 6.3 일시적 기동 영향 가능성

기본 기동은 전 기체 동일이지만, 다음 시스템들이 **일시적으로 기동에 영향**을 줄 수 있다.

- 슈퍼웨폰 효과: 일시적 이동속도 증가, 무적 대시 등
- 기체 특성: 특정 조건 충족 시 기동 보정
- 슬롯 시너지: 드론 활성화로 인한 간접적 영향

이러한 일시적 영향은 각 시스템에서 정의하며, 기본 기동 자체를 변경하지 않는다.

---

## 7. 특수 기동

### 7.1 별도 특수 기동 미채용

긴급 회피, 대시, 배럴롤 같은 별도의 특수 기동 시스템은 두지 않는다.

### 7.2 슈퍼웨폰 효과로 흡수

특수 기동에 해당하는 기능(긴급 회피, 무적 돌파 등)은 **슈퍼웨폰의 효과 데이터로 구현**한다. 이를 통해 긴급 회피 능력 자체가 로드아웃 선택의 대상이 되며, 별도의 시스템을 추가하지 않고 기존 로드아웃 프레임워크 안에서 처리한다.

슈퍼웨폰 효과 사양은 **슈퍼웨폰 시스템 세부 기획**에서 다룬다.

## 8. 입력 방식

### 8.1 지원 입력 장치

- **키보드:** 기본 지원
- **게임패드:** 기본 지원

두 입력 장치 모두 기본 지원하며, 키 바인딩은 옵션에서 변경 가능하다.

### 8.2 입력 장치 우선순위 및 자동 전환

게임 시작 시 **게임패드를 우선 입력 장치**로 인식한다. 게임 진행 중 다음 규칙으로 자동 전환된다.

| 상황 | 처리 |
|------|------|
| 현재 사용 중인 입력 장치에서 입력 | 정상 처리 |
| 다른 입력 장치에서 입력 감지 | 자동 일시정지 + 인게임 메뉴 표시 |

플레이어가 인게임 메뉴에서 진행 선택 시, 새로 입력한 장치로 전환되어 게임이 재개된다. 이는 갑작스러운 장치 전환으로 인한 플레이어 혼란을 방지하기 위한 처리이다.

인게임 메뉴 자체의 사양은 **UI 시스템 기획**에서 다룬다.

### 8.3 게임패드 데드존 설정

게임패드 사용 시 아날로그 스틱의 **데드존을 데이터로 설정 가능**하다. 옵션에서 플레이어가 직접 조정할 수 있다.

| 연동 시스템 | 연동 내용 |
|-------------|-----------|

| 슈퍼웨폰 시스템 | 슈퍼웨폰 효과가 특수 기동 역할 + 일시적 기동 영향 |
| 기체 시스템 | 기체 특성에 의한 일시적 기동 영향 가능 |
| 슬롯 시너지 시스템 | 드론 활성화에 의한 간접적 기동 영향 |
| 스테이지 구조 | 자동 스크롤과 플레이어 이동의 독립성 |
| UI 시스템 | 입력 장치 전환 시 인게임 메뉴 표시 |

| 입력 우선순위 | 게임패드 우선, 다른 장치 입력 감지 시 자동 일시정지 + 메뉴 |
| 게임패드 데드존 | 옵션에서 데이터로 설정 |
