**문서 종류:** P2 시스템 세부 기획

**관련 문서:** 시스템_클리어평가_v0.2, 시스템_아이템드롭_v0.2, 시스템_보스페이즈_v0.2, 시스템_슈퍼웨폰_v0.2

## 1. 개요

본 문서는 **스코어링 시스템**의 세부 설계를 정의한다. 스코어링은 빌드 선택에 따라 유리한 전략이 달라지도록 설계되며, 특화 빌드와 범용 빌드가 각각 다른 스코어링 축에서 강점을 가지는 구조를 목표로 한다.

스코어 총점은 클리어 평가 시스템의 평가 항목 중 하나로 포함된다.

---

## 2. 스코어 기본 구조

### 2.1 기본 점수 × 배율

적 격파 시 **기본 점수**가 부여되고, 보너스 조건에 따라 **배율**이 곱해진다.

```
최종 점수 = 기본 점수 × 격파 속도 배율 × 체인 배율
```

기본 점수는 몬스터 데이터 테이블에서 개별 설정한다.

### 2.2 별도 가산 점수

배율과 별개로 **고정 점수**로 가산되는 항목이 존재한다.

- 점수 아이템 획득 점수
- 보스 격파 스코어
- 파츠 파괴 스코어
- 노데스 클리어 보너스
- 슈퍼웨폰 미사용 보너스

## 3. 격파 속도 보너스

### 3.1 기본 원리

적이 화면에 등장한 시점부터 타이머가 시작되며, 빠르게 격파할수록 높은 배율이 적용된다. 배율은 **최대값에서 시간에 따라 선형으로 감소**하며, 일정 시간이 지나면 기본 배율(1.0)에 도달하여 고정된다.

### 3.2 타이머 시작 시점

격파 속도 타이머는 **적의 콜리전이 화면 영역에 들어온 시점**부터 시작된다.

- 적 데이터가 스폰된 시점이 아니라, 실제로 화면에 보이는 시점이 기준
- 화면 밖 등장 연출(스크롤이나 애니메이션 진행 중) 시간은 타이머에 포함되지 않음
- 플레이어가 적을 인지할 수 있는 순간부터 타이머가 시작되어 공정한 보상

### 3.3 적별 독립 타이머

격파 속도 타이머는 **각 적마다 독립적으로 관리**된다. 동시에 화면에 여러 적이 존재하더라도 각자의 타이머가 별도로 작동한다.

### 3.4 선형 감소를 채택한 이유

- **0으로 뚝 떨어지는 방식과의 차이:** 시간을 넘기면 "의미 없다"가 아니라, "늦었지만 최대한 빨리"라는 동기가 유지된다.
- **기본 배율 보장:** 아무리 늦게 잡아도 기본 점수(×1.0)는 확보되므로, 격파 자체에 대한 보상이 사라지지 않는다.

### 3.5 배율 커브

```
격파 속도 배율 = max(1.0, 최대 배율 - (경과 시간 × 감소율))
```

최대 배율, 감소율, 기본 배율 도달 시간은 **데이터 테이블에서 설정 가능**하게 한다. 이를 통해 적 등급이나 스테이지에 따라 배율 커브를 차등 적용할 수 있다.

### 3.6 슈퍼웨폰 격파의 배율 적용

슈퍼웨폰으로 격파한 적도 **일반 격파와 동일하게 격파 속도 배율이 적용**된다. 슈퍼웨폰을 사용했다고 점수 손실이 발생하지 않는다.

이 정책은 슈퍼웨폰 시스템의 스코어 정책과 일관된다 (시스템_슈퍼웨폰_v0.2 7장 참고).

### 3.7 빌드와의 관계

특화 빌드는 자기 속성 적을 높은 DPS로 빠르게 처리하여 격파 속도 배율을 극대화할 수 있다. 범용 빌드는 DPS가 낮아 격파 속도 배율에서 불리하다.

## 4. 연속 격파 보너스 (체인)

### 4.1 기본 원리

적을 연속으로 격파하면 **체인 수**가 누적되며, 체인 수에 따라 배율이 증가한다. 일정 시간 내에 다음 적을 격파하지 못하면 체인이 끊긴다.

### 4.2 체인 끊김 조건

| 조건 | 체인 끊김 여부 |
|------|----------------|
| 일정 시간 내 다음 적 미격파 | 끊김 |
| 피격 | **끊기지 않음** |

### 4.3 피격 시 체인 미끊김을 채택한 이유

- **피탄 허용형 설계와의 일관성:** 이 게임은 보호막으로 맞으면서 전투하는 것이 핵심 문법이다. 피격으로 체인이 끊기면 "맞아도 되는 게임인데 맞으면 체인이 끊긴다"는 모순이 발생한다.
- **독특한 스코어링 전략:** 체인 유지를 위해 보호막을 소모하면서 적에게 돌진하는 공격적 플레이가 가능해진다. 이 게임만의 차별화된 스코어링 전략이 된다.
- **이중 페널티 방지:** 피격에 대한 페널티는 클리어 평가의 "피탄 횟수" 항목에서 이미 별도로 반영되므로, 체인에서까지 페널티를 줄 필요가 없다.

### 4.4 체인 배율 적용 시점

체인 배율은 다음 순서로 적용된다.

1. 적을 격파하는 순간, **현재 적용 중인 체인 배율**로 점수 계산
2. 격파 직후, 체인 카운트가 1 증가하며 새로운 배율로 갱신
3. 다음 격파 시 갱신된 배율 적용

**예시:**
- 1번째 적 격파: 배율 1.0 적용 → 격파 후 1.01로 증가
- 2번째 적 격파: 배율 1.01 적용 → 격파 후 1.02로 증가
- ...

이 방식은 첫 격파부터 배율 변화가 시각적으로 보여 체인 누적의 쾌감을 명확하게 전달한다.

### 4.5 다중 격파 시 처리

광역 무기나 슈퍼웨폰 등으로 여러 적이 동시에 격파될 때:

- **동시 격파의 정의:** **같은 프레임 내에서 격파된 모든 적**을 동시 격파로 간주
- **점수 계산:** 동시 격파된 모든 적에게 **격파 시점의 동일한 배율**이 적용됨
- **체인 카운트:** 격파된 적의 수만큼 체인이 한꺼번에 증가
- **배율 갱신:** 모든 동시 격파 처리 후 한 번에 갱신

이 방식은 단순하고 직관적이다. 동시 격파한 모든 적이 같은 가치를 가지며, 처리 순서에 따른 차등이 발생하지 않는다. 구체적인 처리 흐름은 시스템_전투처리흐름 문서에서 정의된다.

### 4.6 체인 배율

체인 수에 따른 배율은 **데이터 테이블에서 설정**한다. 체인 수 구간별로 배율을 지정할 수 있으며, 최대 배율 상한도 설정 가능하다.

### 4.7 체인 유지 시간

체인이 끊기기까지의 허용 시간은 **데이터로 설정 가능**하게 한다. 스테이지별 또는 전역 설정으로 운영할 수 있다.

### 4.8 체인 상한

체인 수의 상한과 배율 상한은 **데이터로 설정**한다. 상한 도달 시 더 이상 카운트되지 않는다. 구체적 상한값은 밸런싱 단계에서 결정한다.

### 4.9 보스전에서의 체인 유지

보스전 진입 시 체인은 **리셋되지 않고 유지**된다. 보스전 중 다음과 같이 체인을 누적할 수 있다.

- 보스 파츠 파괴 시 체인 누적
- 보스전 중 출현하는 잡몹 격파 시 체인 누적
- 재생 파츠 반복 파괴 시 체인 중복 누적

이 정책은 보스전을 스코어 공략의 정점으로 만든다. 잘 짜인 보스전 운용이 미션 최고 스코어로 직결된다.

### 4.10 빌드와의 관계

범용 빌드는 양쪽 적을 모두 잡아 체인 유지가 쉽지만 격파 속도가 느리다. 특화 빌드는 자기 속성은 빠르게 처리하지만 반대 속성 적이 등장하면 체인이 끊길 위험이 있다. 이를 통해 격파 속도 보너스와 체인 보너스가 서로 다른 빌드를 유리하게 만들어, 스코어링 관점에서도 빌드 선택에 트레이드오프가 존재한다.

## 5. 슈퍼웨폰 미사용 보너스

### 5.1 기본 원리

미션 클리어 시 슈퍼웨폰 사용 횟수에 따라 보너스 점수가 부여된다.

### 5.2 보너스 규칙

| 사용 횟수 | 보너스 |
|-----------|--------|
| 0회 | 최대 보너스 |
| 1회 | 최대 보너스 유지 (1회 유예) |
| 2회 이상 | 보너스 0 |

### 5.3 1회 유예를 채택한 이유

슈퍼웨폰을 완전히 봉인하고 플레이하라는 의도가 아니다. 슈퍼웨폰으로 넘겨야 할 허들을 실력으로 돌파하라는 의미이며, 1회까지는 위급한 상황에서의 사용을 허용한다. 2회째부터 보너스가 0이 되므로 "아끼다가 1회는 써도 된다"는 판단이 생기고, 이것이 슈퍼웨폰 운용의 긴장감을 만든다.

### 5.4 보너스 점수

슈퍼웨폰 미사용 보너스는 배율이 아닌 **고정 가산 점수**로 처리한다. 구체적 점수는 밸런싱 단계에서 결정한다.

## 6. 점수 아이템

### 6.1 고정 점수

점수 아이템 획득 시 부여되는 점수는 **고정 점수**이다. 격파 속도 배율이나 체인 배율이 적용되지 않는다.

### 6.2 고정 점수를 채택한 이유

- **계산 용이:** 플레이어가 점수 아이템의 가치를 직관적으로 파악할 수 있다.
- **스코어 공략:** 고정 드롭 방식과 결합하여, 스테이지 내 총 획득 가능한 아이템 점수를 사전에 계산할 수 있다.

### 6.3 등급별 차등

점수 아이템은 등급별로 세분화되어 있으며, 등급에 따라 고정 점수가 다르다. 구체적 등급 수와 점수는 밸런싱 단계에서 결정한다.

## 7. 보스 관련 스코어

### 7.1 스코어 항목

| 항목 | 방식 | 설명 |
|------|------|------|
| 보스 격파 스코어 | 고정 가산 | 보스 본체 체력을 0으로 만들어 격파 시 |
| 파츠 파괴 스코어 | 고정 가산 | 개별 파츠 파괴 시. 파츠별 차등. |
| 노데스 클리어 보너스 | 고정 가산 | 미션 전체에서 사망 없이 클리어 시 |

### 7.2 노데스 클리어 보너스 범위

노데스 클리어 보너스는 **미션 전체 기준**이다. 보스전만이 아닌 미션 전 구간에서 사망(잔기 1차 사용 포함) 없이 클리어해야 부여된다.

이 정책은 클리어 평가 시스템의 사망 횟수 항목과 일관된다. 미션 전체 사망 0회가 곧 노데스 클리어이며, 이 기준이 평가와 스코어 양쪽에 동일하게 적용된다.

### 7.3 파츠 재생과 스코어

재생 파츠를 반복 파괴하면 파츠 파괴 스코어를 **중복 획득**할 수 있다. 이를 통해 스코어 공략 시 재생 파츠를 반복 파괴하는 전략적 선택이 가능하다.

### 7.4 보스 본체와 격파율

보스 본체 격파는 클리어 평가의 격파율 카운트에는 포함되지 않으나, **본 시스템의 보스 격파 스코어로 보상이 별도 부여**된다. 이 정책은 클리어 평가 시스템의 격파율 카운트 규칙과 정합성을 가진다.

## 8. 인게임 스코어 표시

### 8.1 실시간 표시 항목

플레이 중 화면에 다음 정보를 실시간으로 표시한다.

| 표시 항목 | 설명 |
|-----------|------|
| 현재 총 스코어 | 누적된 총 점수 |
| 체인 수 | 현재 연속 격파 수 |
| 체인 배율 | 현재 체인에 의한 배율 |
| 체인 잔여 시간 | 체인 끊김까지 남은 시간 (체인 활성 시) |

### 8.2 점수 표기 방식

| 항목 | 표기 |
|------|------|
| 자릿수 구분 | 천 단위 컴마 (예: 1,234,567) |
| 자릿수 제한 | 충분히 여유 있게 (스코어가 억대까지 도달 가능하도록) |

### 8.3 체인 끊김 직전 시각 신호

체인이 끊기기 직전에는 다음 시각 신호로 플레이어에게 경고한다.

- **체인 배율 깜박임:** 배율 표시가 깜박여 임박을 알림
- **잔여 시간 타이머 표시:** 끊김까지 남은 시간을 명확히 보여줌

이를 통해 플레이어가 체인 유지를 위한 다음 격파 타이밍을 판단할 수 있다.

### 8.4 표시 목적

스코어, 체인, 배율을 실시간으로 보여줌으로써 플레이어가 "이걸 유지해야겠다"는 동기를 느끼게 한다. 체인이 끊기기 직전의 긴장감, 배율이 올라가는 쾌감이 플레이 중 지속적으로 전달된다.

## 11. 확정 사항 요약

| 항목 | 결정 사항 |
|------|-----------|
| 기본 구조 | 기본 점수 × 격파 속도 배율 × 체인 배율 |
| 격파 속도 타이머 시작 | 적 콜리전이 화면 영역에 들어온 시점 |
| 격파 속도 타이머 관리 | 적별 독립 관리 |
| 격파 속도 배율 | 최대 배율에서 시간에 따라 선형 감소, 기본 배율(1.0)에서 고정 |
| 슈퍼웨폰 격파 | 일반 격파와 동일하게 배율 정상 적용 |
| 배율 커브 | 데이터 테이블에서 설정 가능 |
| 체인 끊김 조건 | 일정 시간 내 미격파 시 끊김. 피격으로는 끊기지 않음. |
| 체인 배율 적용 시점 | 격파 시점의 배율로 점수 계산, 격파 후 배율 갱신 |
| 다중 격파 시 처리 | 동시 격파된 모든 적에게 동일 배율, 격파 후 한꺼번에 갱신 |
| 체인 배율 / 유지 시간 / 상한 | 데이터로 설정 가능 |
| 보스전 체인 유지 | 보스전 진입 시 체인 리셋 없음. 파츠 파괴/잡몹/재생 파츠 활용 가능. |
| 슈퍼웨폰 미사용 보너스 | 0~1회 사용 시 최대 보너스, 2회 이상 시 보너스 0 |
| 점수 아이템 | 고정 점수 (배율 미적용) |
| 보스 스코어 | 격파/파츠 파괴/노데스 모두 고정 가산 |
| 노데스 보너스 범위 | 미션 전체 사망 0회 |
| 파츠 재생 반복 파괴 | 스코어 중복 획득 가능 |
| 인게임 표시 | 총 스코어, 체인 수, 체인 배율, 체인 잔여 시간 |
| 점수 표기 | 천 단위 컴마, 자릿수 여유 (억대까지) |
| 체인 끊김 시각 신호 | 배율 깜박임 + 잔여 시간 타이머 |
