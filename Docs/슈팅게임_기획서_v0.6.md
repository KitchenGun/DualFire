# VERTICAL SHOOTING GAME — 게임 제작 기획서

**Version 0.6 — 초안**
**2026.04.15**

---

## 0. 문서 운영 원칙

본 기획서는 게임의 **전체 시스템 개요와 시스템 간 관계**를 정의한다. 각 시스템의 세부 설계는 별도의 세부 기획 문서에서 다루며, 본 문서에서는 핵심 방향성과 다른 시스템과의 연결 지점에 집중한다.

세부 사항이 필요한 경우 해당 시스템의 세부 기획 문서를 참조한다.

## 1. 게임 개요

### 1.1 컨셉

3D 그래픽으로 구현된 2D 종스크롤 슈팅게임. 지상과 공중의 피격 판정이 분리되어 있어 무장 선택과 상황 판단이 전략적 핵심이 된다.

일격 격파형 하드코어 슈팅을 지양하고, 체력과 보호막을 통해 피탄을 허용하여 진입장벽을 낮추는 동시에 보호막 관리라는 리소스 판단 요소를 제공한다.

### 1.2 레퍼런스

| 타이틀 | 참고 요소 |
|--------|-----------|
| Raptor: Call of the Shadows | 미션 기반 진행, 상점 시스템, 미션 브리핑 구조 |
| Strikers 1945 | 클래식 종스크롤 슈팅 문법, 보스 페이즈 전환 |
| Raystorm | 3D 그래픽 기반 2D 슈팅 |
| Radiant Silvergun | 무기 운용 판단 기반 보스전 |
| Ace Combat X | 동적 캠페인 구조 |
| R-TYPE | 다중 기체 시스템 |

### 1.3 핵심 키워드

- **지상/공중 판정 분리:** 모든 적과 무장이 지상/공중 속성으로 분류
- **로드아웃 시스템:** 출격 전 기체+장비 세팅으로 빌드 구성
- **다중 기체 + 슬롯 시너지:** 기체 선택과 장비 조합의 깊이
- **동적 캠페인:** 미션 결과가 이후 미션에 영향을 미치는 비선형 구조
- **피탄 허용형 설계:** 체력+보호막의 2층 생존 자원 관리
- **수집 + 도전 동기:** 다양한 장비/기체와 도전과제 기반 해금

### 1.4 플랫폼

PC (Unreal Engine 기반)

## 3. 핵심 게임 루프

```
미션 선택 → 미션 브리핑 → 기체 선택 + 로드아웃 세팅 → 출격
   → 전투 (스테이지 진행, 아이템 획득, 보스전)
   → 클리어 평가 (랭크, 빌드 재고)
   → 캠페인 진행 (분기 영향)
   → 다음 미션 선택으로 복귀
```

각 단계의 세부 동작은 해당 시스템 문서를 참조한다.

## 4. 시스템 간 관계

### 4.1 무장 선택의 흐름

지상/공중 판정 분리 시스템이 모든 무장 시스템의 기반이 된다. 로드아웃에서 무장의 속성을 선택하고, 미션 브리핑에서 적 구성 힌트를 받아 판단하며, 출격 후 보스 페이즈에서 활성 파츠 속성에 따라 무장 선택의 결과가 시험된다. 클리어 평가의 격파율로 판단의 결과가 측정되어 다음 빌드 재고로 이어진다.

### 4.2 빌드 다양성의 축

다음 요소들이 결합되어 빌드 다양성을 만든다.

- 기체 선택 (10대 이상의 다중 기체)
- 로드아웃 슬롯 4개 조합 (기본 무기 1, 특수무장 2, 슈퍼웨폰 1, 보호막 1)
- 슈퍼웨폰의 효과 조합 설계
- 슬롯 시너지에 의한 드론 활성화

이론적 빌드 조합 수는 매우 크지만, 미션 브리핑과 적 구성에 따라 유효한 조합은 제한된다.

### 4.3 리플레이 동기 4층 구조

| 층 | 동기 |
|----|------|
| 1회차 | 브리핑 정보 기반 로드아웃 판단 |
| 2회차 | 빌드 변경으로 다른 공략 시도 |
| 고난도 | 변화된 적 구성 + 숨겨진 정보 |
| 스코어링 | 격파 속도/체인/슈퍼웨폰 미사용 극대화 |

여기에 동적 캠페인의 분기 미션 탐색과 슬롯 시너지 발견까지 더해져, 같은 미션을 반복 플레이하는 다층적 동기가 형성된다.

### 4.4 도전과 보상의 순환

클리어 평가 결과가 도전과제 조건으로 활용되고, 도전과제 달성이 새로운 장비/기체를 해금한다. 해금된 장비/기체가 새로운 빌드 가능성을 열어 다시 더 높은 도전을 시도하게 만드는 순환 구조이다.

## 5. 개발 우선순위

### 5.1 우선순위 테이블

| 우선순위 | 항목 | 비고 |
|----------|------|------|
| P0 - 코어 | 지상/공중 판정 분리 | 게임의 정체성 |
| P0 - 코어 | 로드아웃 시스템 | 빌드 자유도 |
| P0 - 코어 | 생존 시스템 | 피탄 허용형 기반 |
| P0 - 코어 | 플레이어 기동 | 기본 조작 스펙 |
| P1 - 중요 | 기체 시스템 | 다중 기체 + 특성 |
| P1 - 중요 | 슈퍼웨폰 시스템 | 효과 기반 설계 |
| P1 - 중요 | 보스 페이즈 시스템 | 무장 시스템의 시험대 |
| P1 - 중요 | 미션 브리핑 | 로드아웃 판단 근거 |
| P1 - 중요 | 클리어 평가 시스템 | 리플레이 동기 |
| P1 - 중요 | 인게임 아이템 드롭 | 회복/점수/슈퍼웨폰 충전 |
| P1 - 중요 | 스테이지 구조 | 자동 스크롤 + 멈춤 구간 |
| P2 - 확장 | 스코어링 시스템 | 격파 속도/체인/미사용 3축 |
| P2 - 확장 | 장비 해금 시스템 | 상점 + 조건 해금 |
| P2 - 확장 | 동적 캠페인 | 미션 간 인과관계 |
| P2 - 확장 | 난이도 시스템 | 3단계 미션별 선택 |
| 별도 | 슬롯 시너지 시스템 | 드론 활성화 |
| P3 - 후순위 | 난이도 커브 설계 | 프로토타입 후 진행 |
| P3 - 후순위 | 2인 멀티플레이 (P2P) | 최후순위 |

### 5.2 프로토타입 권장 스코프

P0 코어 4개 + 1스테이지 구성으로 핵심 재미 검증 권장.

- 지상/공중 판정 분리의 시각적 식별성
- 로드아웃 빌드 선택의 의미
- 피탄 허용형 생존감
- 기본 조작감

이 검증이 완료된 후 P1 시스템을 단계적으로 추가한다.
