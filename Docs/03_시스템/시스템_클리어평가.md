## 1. 개요

본 문서는 미션 클리어 후 플레이어에게 피드백을 제공하는 **클리어 평가 시스템**을 정의한다. 평가는 플레이어의 빌드 재고와 리플레이 동기를 유도하는 핵심 시스템이며, 도전과제 및 장비/기체 해금과 연동된다.

---

## 2. 평가 항목

### 2.1 개별 평가 항목 (5개)

미션 클리어 시 다음 5개 항목에 대해 **각각 개별 랭크**를 산출한다.

| 항목 | 측정 기준 | 게임 내 의미 |
|------|-----------|-------------|
| 공중 격파율 | 공중 적 총 등장 수 대비 격파 비율 | 대공 무장 운용 효율 |
| 지상 격파율 | 지상 적 총 등장 수 대비 격파 비율 | 대지 무장 운용 효율 |
| 피탄 횟수 | 미션 중 피격 횟수 (보호막 흡수 포함) | 회피 숙련도 |
| 스코어 | 스코어링 시스템 총점 | 격파 속도/체인/슈퍼웨폰 미사용 보너스 종합 |
| 사망 횟수 | 미션 중 사망 횟수 | 생존 능력 |

### 2.2 공중/지상 격파율 분리의 의미

격파율을 공중과 지상으로 분리하여 보여주는 것이 이 시스템의 핵심이다. 플레이어가 "공중은 거의 다 잡았는데 지상 격파율이 낮네, 다음엔 대지 무장을 늘려볼까"라는 판단으로 자연스럽게 이어져야 한다. 이 분리 표시가 로드아웃 재고 → 리플레이의 동기를 만드는 연결고리이다.

### 2.3 격파율 카운트 규칙

| 대상 | 카운트 처리 |
|------|-------------|
| 공중 일반 적 | 공중 격파율에 카운트 |
| 지상 일반 적 | 지상 격파율에 카운트 |
| 양면 속성 적 | 공중/지상 양쪽에 카운트 |
| 보스 본체 | 격파율 평가 제외 (미션 클리어 필수 조건이므로) |
| 보스 파츠 | 격파율 평가 제외 (별도 스코어로만 처리) |

보스는 미션 클리어 자체가 격파를 의미하므로, 격파율 항목에서는 의미가 없다. 보스 격파에 대한 보상은 스코어링 시스템의 보스 격파 스코어와 파츠 파괴 스코어로 별도 반영된다.

### 2.4 피탄 카운트 규칙

미션 중 피격되는 모든 경우를 피탄으로 카운트한다.

| 상황 | 피탄 카운트 여부 |
|------|------------------|
| 보호막이 데미지 흡수 | 카운트 |
| 체력에 데미지 적용 | 카운트 |
| 무적 시간 중 피격 | 카운트 안 함 (애초에 피격 자체가 무시됨) |

보호막 흡수도 피탄으로 카운트하는 이유는 극단적으로 어려운 도전(노피탄 클리어 등)을 도전과제 영역에서 활용 가능하게 하기 위함이다. 일반 평가에서는 보호막 흡수 피탄도 그대로 카운트되며, 도전과제 시스템에서 이를 어떻게 활용할지 결정한다.

### 2.5 사망 카운트 규칙

| 상황 | 사망 카운트 |
|------|-------------|
| 1차 사망 (예비기 리스폰) | 1 카운트 |
| 2차 사망 | 미션 실패 (평가 산출 안 됨) |

미션 실패 시에는 클리어 평가가 산출되지 않으므로, 사망 카운트는 사실상 0회 또는 1회로 한정된다.

## 3. 랭크 시스템

### 3.1 랭크 등급

| 랭크 | 의미 |
|------|------|
| S | 최고 등급 |
| A | 우수 |
| B | 양호 |
| C | 보통 |
| D | 미흡 |

### 3.2 개별 랭크 산출

각 평가 항목은 해당 항목의 수치를 기준으로 **개별 랭크**를 산출한다.

- 격파율 항목: 격파 비율(%)에 따라 등급 부여. 100%가 S, 그 이하 구간별 차등.
- 피탄 횟수: 피격 횟수가 적을수록 높은 등급. 0회가 S.
- 스코어: 총점 구간에 따라 등급 부여.
- 사망 횟수: 0회가 S, 1회는 일정 등급 이하.

구체적인 등급 경계값은 밸런싱 단계에서 결정한다.

### 3.3 종합 랭크 산출

5개 개별 랭크를 종합하여 **종합 랭크**를 산출한다. 종합 시 **격파율 항목의 가중치가 높다.** 이 게임의 핵심이 무장 선택을 통한 적 격파이므로, 공중/지상 격파율이 종합 랭크에 가장 큰 영향을 미친다.

가중치 비중 방향성:

| 항목 | 가중치 |
|------|--------|
| 공중 격파율 | 높음 |
| 지상 격파율 | 높음 |
| 피탄 횟수 | 보통 |
| 스코어 | 보통 |
| 사망 횟수 | 보통 |

구체적인 가중치 수치는 밸런싱 단계에서 결정한다.

### 3.4 적용 불가 항목 처리

특정 미션에서 평가 항목이 적용 불가능한 경우(예: 공중 적이 0인 지상 100% 미션의 공중 격파율), 해당 항목은 **종합 랭크 산출에서 제외**된다.

| 케이스 | 처리 |
|--------|------|
| 공중 적 0인 미션 | 공중 격파율 항목 미산출, 종합 랭크 산출에서 제외 |
| 지상 적 0인 미션 | 지상 격파율 항목 미산출, 종합 랭크 산출에서 제외 |

평가 제외 처리를 채택한 이유는 자동 S랭크 처리 시 "쉬운 S 자동 획득"이 되어 평가 의미가 약해지기 때문이다. 제외 시 다른 항목들의 가중치가 자동 조정되어 의미 있는 평가가 유지된다.

격파율 두 항목이 모두 적용되지 않는 미션은 디자인되지 않는다 (클리어가 불가능한 미션이므로).

## 4. 스코어링 시스템 연동

### 4.1 스코어가 평가에 반영

스코어링 시스템(격파 속도 보너스, 연속 격파 보너스, 슈퍼웨폰 미사용 보너스)의 총점이 평가 항목의 하나로 포함된다. 스코어와 랭크는 별개의 축이 아니라, 스코어가 랭크 산출에 기여하는 구조이다.

### 4.2 스코어 랭크의 역할

스코어 랭크는 단순 격파율이나 피탄 이외의 **플레이 품질**을 반영한다. 같은 격파율이라도 빠르게 잡고 체인을 유지한 플레이어가 더 높은 스코어 랭크를 받는다.

### 4.3 슈퍼웨폰 미사용 보너스의 간접 반영

슈퍼웨폰 사용 횟수는 별도 평가 항목으로 두지 않으며, **스코어에 포함된 슈퍼웨폰 미사용 보너스**로 간접 반영된다. 슈퍼웨폰을 절제한 플레이는 스코어 점수에 반영되어 평가 종합 랭크 향상에 기여한다.

## 5. 결과 화면 표시

### 5.1 표시 항목

미션 클리어 후 결과 화면에 다음 정보를 표시한다.

| 표시 항목 | 설명 |
|-----------|------|
| 공중 격파율 + 개별 랭크 | 공중 적 격파 비율과 등급 |
| 지상 격파율 + 개별 랭크 | 지상 적 격파 비율과 등급 |
| 피탄 횟수 + 개별 랭크 | 피격 횟수와 등급 |
| 스코어 + 개별 랭크 | 총 스코어와 등급 |
| 사망 횟수 + 개별 랭크 | 사망 횟수와 등급 |
| 종합 랭크 | S ~ D |
| 클리어 시간 | 미션 클리어에 소요된 시간 |
| 현재 난이도 | 이 미션을 클리어한 난이도 |

격파율 적용 불가 항목이 있는 경우 해당 항목은 결과 화면에 "해당 없음" 등으로 표기된다.

### 5.2 결과 화면 액션

결과 화면에서 플레이어는 다음 두 가지 액션을 선택할 수 있다.

| 액션 | 동작 |
|------|------|
| 미션 선택으로 돌아가기 | 캠페인 맵 또는 미션 선택 화면으로 복귀 |
| 리플레이 | 동일 미션을 동일 난이도로 다시 플레이 (브리핑 → 로드아웃 → 출격 흐름으로 진입) |

"다음 미션으로" 자동 진행은 제공하지 않는다. 동적 캠페인 분기 시스템 때문에 다음 미션 선택은 플레이어가 캠페인 맵에서 명시적으로 결정해야 한다.

리플레이 시에는 **동일 난이도로 자동 진행**된다. 다른 난이도로 시도하려면 미션 선택 화면으로 돌아가서 난이도를 다시 선택해야 한다. 이는 즉시 리플레이의 빠른 반복 흐름을 유지하면서도 난이도 변경 시 명시적 선택을 요구하기 위함이다.

### 5.3 리플레이 유도

결과 화면에서 "이 항목을 올리면 랭크가 올라갑니다" 같은 가이드는 **제공하지 않는다.** 랭크를 보여주면 플레이어가 낮은 항목을 스스로 파악하고 개선 방법을 연구하게 되며, 이 반복 학습 과정 자체가 게임의 재미이다.

## 6. 평가 데이터 보존

### 6.1 전체 플레이 기록 저장

미션 플레이 결과는 **모든 플레이 기록을 저장**한다. 같은 미션을 여러 번 플레이해도 각 플레이의 평가 결과가 누적되어 보존된다.

### 6.2 전체 기록 보존을 채택한 이유

도전과제 시스템에 단발형 조건과 누적형 조건이 모두 존재하기 때문이다.

| 도전과제 유형 | 예시 | 필요 데이터 |
|----------------|------|-------------|
| 단발형 | "미션 5에서 종합 S랭크 달성" | 최고 기록 (전체 기록에서 추출) |
| 누적형 | "공중 격파율 S랭크 누적 3회 달성" | 모든 플레이 기록 |

전체 플레이 기록을 저장하면 두 유형의 도전과제 판정에 모두 대응 가능하다. 단발형 조건은 저장된 기록 중 최고치를 참조하면 되고, 누적형 조건은 조건 충족 횟수를 카운트하면 된다.

### 6.3 보존 단위

평가 데이터의 보존 단위는 **세이브 데이터 단위**이다. 새 세이브를 시작하면 이전 세이브의 평가 기록은 새 세이브에서 사용되지 않는다.

단, 도전과제 시스템에서 처리되는 일부 누적 데이터는 게임 전체 공유될 수 있다 (도전과제 시스템 세부 기획 참고).

## 7. 도전과제 및 해금 연동

### 7.1 연동 구조

클리어 평가 결과는 도전과제 달성 조건의 판정 데이터로 활용된다. 도전과제 중 장비/기체 해금이 붙은 항목의 조건으로 평가 결과가 참조될 수 있다.

**예시:**
- "공중 격파율 S랭크 3회 달성" → S급 대공 특수무장 해금
- "종합 랭크 S를 5개 미션에서 달성" → 특수 기체 해금
- "노피탄 클리어 (보호막 흡수 포함)" → 특수 보호막 해금

### 7.2 난이도별 해금 차등

도전과제 조건에 난이도 조건을 포함할 수 있다. 예를 들어 "Hard 이상에서 종합 S랭크"는 Normal에서의 S랭크보다 높은 보상을 제공할 수 있다. 구체적 조건은 컨텐츠 기획에서 결정한다.

## 8. 시스템 간 연동 지점

| 연동 시스템 | 연동 내용 |
|-------------|-----------|
| 스코어링 시스템 | 스코어 총점이 평가 항목의 하나로 포함. 슈퍼웨폰 미사용 보너스 간접 반영. |
| 장비 해금 시스템 | 평가 결과가 도전과제 조건으로 활용 |
| 기체 시스템 | 기체 해금 조건으로 활용 |
| 보스 페이즈 시스템 | 보스 격파/파츠 파괴는 격파율이 아닌 스코어링으로 처리 |
| 스테이지 구조 | 스테이지 내 평가 데이터 집계. 스테이지 ID + 난이도 조합별 독립 기록. |
| 동적 캠페인 시스템 | 분기 조건 판정에 평가 데이터 활용 |
| 난이도 시스템 | 평가 기록은 스테이지 ID + 난이도 조합별 독립 기록 |
| 생존 시스템 | 피탄 카운트, 사망 카운트의 트리거 |

## 10. 확정 사항 요약

| 항목 | 결정 사항 |
|------|-----------|
| 평가 항목 | 공중 격파율, 지상 격파율, 피탄 횟수, 스코어, 사망 횟수 (총 5개) |
| 보스 격파 처리 | 격파율 평가 제외 (미션 클리어 필수 조건이므로) |
| 파츠 격파 처리 | 격파율 평가 제외 (스코어로만 반영) |
| 양면 속성 적 | 공중/지상 양쪽에 카운트 |
| 피탄 카운트 | 보호막 흡수 포함 모든 피격 카운트 (무적 시간 중 피격은 미카운트) |
| 사망 카운트 | 1차 사망 시 1 카운트 (2차 사망은 미션 실패) |
| 랭크 등급 | S / A / B / C / D |
| 랭크 산출 | 항목별 개별 랭크 + 종합 랭크 |
| 가중치 | 격파율 비중 높음, 나머지 보통 (구체적 수치는 밸런싱에서) |
| 적용 불가 항목 처리 | 종합 랭크 산출에서 제외 (자동 S 처리 미채용) |
| 슈퍼웨폰 사용 횟수 항목 | 별도 항목 없음. 스코어 미사용 보너스로 간접 반영. |
| 스코어링 연동 | 스코어가 평가 항목에 포함 |
| 결과 화면 액션 | 미션 선택으로 돌아가기 / 리플레이 (동일 난이도로 자동 진행, 다음 미션 자동 진행 없음) |
| 리플레이 가이드 | 제공하지 않음 (플레이어 자율 학습) |
| 평가 데이터 보존 | 모든 플레이 기록 저장 (단발형 + 누적형 도전과제 양쪽 만족) |
| 보존 단위 | 세이브 데이터 단위 |
