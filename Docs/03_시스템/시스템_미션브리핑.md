## 1. 개요

본 문서는 **미션 브리핑 시스템**의 세부 설계를 정의한다. 미션 브리핑은 플레이어가 미션 선택 후 출격 전에 확인하는 정보 화면으로, 로드아웃 판단의 근거를 제공하는 역할을 한다.

---

## 2. 브리핑의 역할

### 2.1 정보 제공 범위

브리핑은 다음 2가지 정보를 제공한다.

| 정보 | 설명 | 출처 |
|------|------|------|
| 미션 내용 및 목표 | 시나리오/스토리에 따른 미션 설명과 목표 | 시나리오 기획 |
| 적 구성 힌트 | 지상/공중 적 비중에 대한 러프한 힌트 | 미션 데이터 |

이 외에 동적 캠페인 결과에 따른 **연동 메시지**가 추가로 표시될 수 있다 (5절 참고).

### 2.2 노출하지 않는 정보

다음 정보는 브리핑에서 **노출하지 않는다.**

| 비노출 정보 | 사유 |
|-------------|------|
| 보스 정보 | 노출 시 난이도가 지나치게 하락 |
| 스테이지 길이 | 플레이어 판단에 불필요한 정보 |
| 엘리트 유무 | 몬스터 구성의 일부이므로 별도 노출 불필요 |

브리핑에서 제공하는 유일한 전투 정보는 **지상/공중 비중 힌트**이며, 이를 통해 정보 과잉 없이 로드아웃 판단에 집중할 수 있도록 한다.

---

## 3. 적 구성 힌트

### 3.1 힌트 형태

적 구성 힌트는 **러프한 텍스트 힌트**로 제공한다. 정확한 비율이나 수치를 노출하지 않으며, 대략적인 경향만 안내한다.

**힌트 예시:**
- '지상 적 다수 예상'
- '공중 위협 높음'
- '혼합 구성 예상'

### 3.2 러프한 힌트를 채택한 이유

- **최적해 수렴 방지:** 정확한 비율을 주면 로드아웃 최적해가 하나로 수렴한다.
- **빌드 고민 유도:** '범용으로 안전하게 갈까 vs 특화로 밀어붙일까'라는 판단이 살아난다.
- **리플레이 가치:** 1회차에서 힌트 기반으로 판단하고, 2회차에서 실제 경험을 바탕으로 빌드를 재고하는 흐름이 유지된다.

### 3.3 로드아웃 유효성 경고 연동

적 구성 힌트는 로드아웃 시스템의 빌드 유효성 경고 기준으로 활용된다. 힌트에서 '지상 적 다수 예상'이라고 안내했는데 플레이어가 대지/범용 무장을 하나도 장착하지 않으면 경고가 표시된다 (Normal 난이도에서만 작동, 4.4절 참고).

상세는 코어시스템_로드아웃 6절 참고.

## 4. 난이도별 정보 차등

### 4.1 차등 규칙

| 난이도 | 미션 내용/목표 | 적 구성 힌트 | 적 구성 |
|--------|----------------|--------------|---------|
| Normal | 표시 | 표시 | 기본 구성 |
| Hard | 표시 | **비표시** | 변화된 구성 |
| 3단계 | 표시 | **비표시** | 추가 변화 (패턴 다양화, 보스 패턴 변화 등) |

3단계 난이도의 적 구성/패턴 차별화는 스테이지 구조 시스템 및 보스 페이즈 시스템에서 처리하며, 본 시스템은 정보 표시 차등만 담당한다.

### 4.2 적 구성 힌트 비표시 방식

Hard 이상 난이도에서 적 구성 힌트는 **자리는 유지하되 안내 메시지로 대체**한다. 부정확한 정보를 주는 방식(거짓 힌트)은 채용하지 않는다.

| 난이도 | 적 구성 힌트 영역 표시 |
|--------|------------------------|
| Normal | 실제 힌트 텍스트 표시 |
| Hard / 3단계 | "적 구성 정보 부족" 등 안내 메시지 표시 |

비표시를 채택한 이유:
- 거짓 정보는 플레이어에게 불공정한 느낌을 줄 수 있다.
- 정보가 없으면 플레이어가 직접 경험으로 적 구성을 파악해야 하므로, 리플레이 동기가 자연스럽게 발생한다.
- 안내 메시지를 통해 정보가 의도적으로 제한되었음을 플레이어에게 알린다.

### 4.3 이중 난이도 효과

높은 난이도에서는 두 가지가 동시에 작용한다.

1. **적 구성/패턴 자체가 변화:** Normal에서 학습한 적 구성 패턴이 통하지 않음.
2. **브리핑 정보가 제거:** 변화된 구성을 사전에 알 수 없음.

이 이중 효과를 통해 별도의 적 스탯 조절 없이도 정보 비대칭만으로 유의미한 난이도 차이를 만들어낸다.

### 4.4 빌드 유효성 경고와의 연동

Hard 이상 난이도에서는 **빌드 유효성 경고도 함께 비활성화**된다.

이유:
- 빌드 유효성 경고는 적 구성 힌트를 기준으로 동작하므로, 힌트가 비표시인 상황에서 경고만 동작하면 정보가 간접적으로 누설됨.
- Hard 이상은 플레이어의 자율적 빌드 선택에 무게를 두는 난이도이며, 사전 경고 없이 본인 판단으로 빌드를 구성하는 것이 컨셉에 맞음.

세부 처리는 코어시스템_로드아웃 6절 참고.

## 5. 동적 캠페인 연동

### 5.1 연동 미션 클리어 시 메시지 변경

동적 캠페인 구조에서 **해당 미션과 연동된 분기 조건을 충족했을 경우**, 브리핑 메시지가 변경된다. 이전 미션의 결과가 현재 미션의 상황에 영향을 미쳤음을 브리핑에서 안내한다.

**예시:**
- 분기 조건 미충족 시: "적 보급기지가 가동 중입니다. 강력한 저항이 예상됩니다."
- 분기 조건 충족 시: "아군의 선제 공격으로 적 보급기지가 파괴되었습니다. 적 물량이 감소할 것으로 예상됩니다."

### 5.2 분기 조건 충족 판정

분기 미션이 열리거나 스테이지가 치환되는 분기 조건은 **모든 조건이 충족되어야** 발동한다. 일부 조건만 충족되는 경우는 분기 미발동 = 기본 메시지 표시이다. 분기 조건의 부분 충족에 대한 별도 처리는 없다.

### 5.3 연동 메시지의 난이도 처리

동적 캠페인 연동 메시지는 **난이도와 무관하게 항상 표시**된다.

이는 적 구성 힌트(Hard 이상에서 비표시)와 다른 처리이다. 정보의 성격이 다르기 때문이다.

| 정보 종류 | 성격 | 난이도 처리 |
|-----------|------|-------------|
| 적 구성 힌트 | 미션 내부에서 무엇이 나올지에 대한 사전 정보 | Hard 이상 비표시 (정보 비대칭 형성) |
| 동적 캠페인 연동 메시지 | 플레이어 행동의 결과 피드백 | 난이도 무관 항상 표시 |

연동 메시지를 가리면 플레이어가 "이전 행동의 결과를 인지하지 못해" 동적 캠페인의 의미가 약해진다. 따라서 결과 피드백 성격의 정보는 모든 난이도에서 표시한다.

## 6. 브리핑 재방문 및 스킵

### 6.1 브리핑 재방문

플레이어는 출격 전 로드아웃 씬에서 **브리핑 정보를 다시 확인할 수 있다.** 한 번 표시된 브리핑이 이후 단계에서도 접근 가능하도록 한다.

이는 다음을 위해 필요하다.
- 로드아웃 세팅 중 적 구성 힌트나 미션 내용을 다시 확인
- 분기 조건 충족 메시지의 재확인

### 6.2 브리핑 스킵

플레이어는 브리핑 화면에서 **언제든 스킵하고 다음 단계(로드아웃 씬)로 진행할 수 있다.**

| 시점 | 스킵 가능 여부 |
|------|---------------|
| 첫 방문 | 가능 |
| 재방문 (이미 클리어한 미션) | 가능 |
| 리플레이 | 가능 |

스킵 가능을 모든 경우로 확장한 이유는 즉시 리플레이 방식으로 같은 미션 반복이 잦기 때문이다. 첫 방문에서도 스킵 가능하게 둠으로써, 시나리오에 관심 없는 플레이어가 빠르게 출격할 수 있도록 한다. 시나리오를 보고 싶은 플레이어는 자연스럽게 끝까지 읽을 것이다.

## 7. 브리핑 데이터

### 7.1 미션 브리핑 데이터

브리핑은 미션 제목, 미션 설명(시나리오 기획에서 작성), 적 구성 힌트(Normal에서만 표시), 분기 조건과 분기 충족/미충족 시의 메시지로 구성된다.

(본 시스템의 데이터 항목 세부 정의는 별도의 데이터 테이블 문서에서 관리한다.)

### 7.2 브리핑 UI

브리핑 UI의 구체적 구성(텍스트 레이아웃, 시각적 요소, 스킵 버튼 위치 등)은 추후 UI 기획에서 결정한다.

## 8. 출격 플로우에서의 위치

```
미션 선택 → [미션 브리핑] → 기체 선택 + 로드아웃 씬 → 출격
              ↑
              로드아웃 씬에서 재방문 가능
```

브리핑은 미션 선택 직후, 로드아웃 씬 진입 전에 표시된다. 플레이어는 브리핑 정보를 확인한 뒤 기체와 로드아웃을 세팅한다. 로드아웃 씬에서 브리핑 정보를 다시 확인할 수 있다.

## 9. 시스템 간 연동 지점

| 연동 시스템 | 연동 내용 |
|-------------|-----------|
| 로드아웃 시스템 | 적 구성 힌트가 로드아웃 판단 근거 제공, 빌드 유효성 경고 기준 (Normal에서만 작동) |
| 동적 캠페인 시스템 | 분기 조건 충족 여부에 따른 메시지 변경 |
| 난이도 시스템 | 난이도에 따른 적 구성 힌트 표시/비표시 제어. 연동 메시지는 난이도 무관 표시. |
| 스테이지 구조 / 보스 페이즈 시스템 | Hard/3단계 난이도의 실제 적/패턴 변화는 해당 시스템에서 처리 |

## 11. 확정 사항 요약

| 항목 | 결정 사항 |
|------|-----------|
| 브리핑 제공 정보 | 미션 내용/목표 + 적 구성 힌트 (지상/공중 비중) + 동적 캠페인 연동 메시지 |
| 비노출 정보 | 보스 정보, 스테이지 길이, 엘리트 유무 |
| 힌트 형태 | 러프한 텍스트 (정확한 비율 미노출) |
| Normal 난이도 | 적 구성 힌트 표시, 빌드 유효성 경고 작동 |
| Hard / 3단계 난이도 | 적 구성 힌트 비표시 (안내 메시지 대체), 빌드 유효성 경고 비작동 |
| 동적 캠페인 연동 메시지 | 난이도 무관 항상 표시 |
| 분기 조건 처리 | 모든 조건 충족 시에만 분기 발동, 부분 충족 처리 없음 |
| 브리핑 재방문 | 로드아웃 씬에서 다시 확인 가능 |
| 브리핑 스킵 | 첫 방문 포함 모든 경우 스킵 가능 |
| 브리핑 UI | 추후 결정 |
