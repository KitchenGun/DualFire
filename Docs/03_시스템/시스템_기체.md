# 기체 시스템 — 세부 기획

**문서 종류:** P1 시스템 세부 기획
**상위 문서:** 슈팅게임 기획서 v0.6
**관련 문서:** 코어시스템_생존_v0.3, 코어시스템_로드아웃_v0.2, 코어시스템_플레이어기동_v0.2
**Version 0.3**
**2026.04.15**

---

## 1. 개요

본 문서는 플레이어가 출격 시 선택하는 **기체 시스템**의 세부 설계를 정의한다. 플레이어는 다수의 기체 중 하나를 선택하여 출격하며, 기체마다 고유한 체력 수치와 특성을 가진다.

기체 시스템은 로드아웃과 결합하여 빌드 다양성의 한 축을 담당하며, 수집 요소를 통해 장기 플레이 동기를 제공한다.

---

## 2. 기체 선택 구조

### 2.1 다중 기체 시스템

플레이어는 **여러 기체 중 하나를 선택**하여 출격한다. R-TYPE 시리즈의 기체 선택 시스템을 레퍼런스로 하며, 각 기체가 고유한 성격과 플레이 스타일을 가지도록 설계한다.

### 2.2 기체 수량

**10대 이상**을 목표로 한다. 수집 요소를 극대화하여 "다음에 어떤 기체를 해금할까"라는 장기 플레이 동기를 지속적으로 제공한다.

최종 기체 수는 컨텐츠 기획 단계에서 결정한다.

### 2.3 기체와 로드아웃 슬롯의 관계

로드아웃 슬롯 구성(기본 무기 1, 특수무장 2, 슈퍼웨폰 1, 보호막 1)은 **전 기체 동일**하다. 기체 선택이 슬롯 수나 구조에 영향을 주지 않는다. 기체 차별화는 체력과 특성으로만 이루어지며, 로드아웃의 자유도는 기체와 무관하게 보장된다.

### 2.4 기체와 슬롯 시너지의 관계

기체는 **슬롯 시너지 시스템의 활성화 조건에 포함되지 않는다.** 슬롯 시너지는 무장 속성(범용/대공/대지) 조합으로만 운영되며, 기체와 시너지 시스템은 독립적이다.

이를 통해 기체 시스템은 "스탯+특성의 베이스 차별화"에 집중하고, 빌드 깊이는 기체 선택 × 무장 속성 조합 × 슬롯 시너지의 곱셈 효과로 형성된다.

## 3. 기체의 결정 요소

### 3.1 기체가 결정하는 항목

| 항목 | 설명 |
|------|------|
| 체력 총량 | 기체 고유 스탯. 기체마다 다름. |
| 기체 특성 | 상시 특성 + 조건부 특성(0개 또는 1개) |

### 3.2 기체가 결정하지 않는 항목

| 항목 | 결정 요소 | 참고 문서 |
|------|-----------|-----------|
| 보호막 | 보호막 장비 슬롯 | 코어시스템_생존_v0.3 |
| 기본 기동 스탯 | 전 기체 동일 고정값 | 코어시스템_플레이어기동_v0.2 |
| 로드아웃 슬롯 구성 | 전 기체 동일 | 코어시스템_로드아웃_v0.2 |

## 4. 기체 데이터

기체는 식별 정보(이름 등), 체력 총량, 상시 특성 목록, 조건부 특성(0개 또는 1개), 외형, 설명 텍스트, 해금 방식과 조건을 가진다. 전체 시스템 확정 후 필요에 따라 항목이 추가될 수 있도록 확장 가능하게 설계한다.

(본 시스템의 데이터 항목 세부 정의는 별도의 데이터 테이블 문서에서 관리한다.)

## 5. 기체 특성

### 5.1 특성 분류

기체 특성은 **상시 특성**과 **조건부 특성**의 2종류로 분류한다.

| 분류 | 동작 방식 | 보유 개수 | 예시 방향성 |
|------|-----------|-----------|-------------|
| 상시 특성 | 항상 적용되는 패시브 효과 | 기체별 차등 | 슈퍼웨폰 게이지 충전량 증가, 회복 아이템 효과 증가, 점수 아이템 획득량 증가 등 |
| 조건부 특성 | 특정 조건 달성 시 발동, 조건 유지 동안 효과 지속 | 기체당 0개 또는 1개 | 연속 격파 N 이상 유지 시 발동 등 |

### 5.2 조건부 특성의 동작 원리

조건부 특성은 다음 원리로 동작한다.

- 조건이 충족되면 특성 효과 발동
- 조건이 유지되는 동안 효과 지속
- 조건이 깨지면 효과 즉시 해제

예: "보호막 만충 시 슈퍼웨폰 게이지 충전 속도 +50%" 특성이라면, 보호막이 만충 상태인 동안만 충전 속도 보너스가 적용되고, 보호막이 1이라도 깎이면 보너스가 해제된다.

### 5.3 조건부 특성의 발동 조건 방향성

조건부 특성의 발동 조건은 회복 시스템과 충돌하지 않는 축에서 설계한다. 고려 가능한 발동 조건 방향성:

- **연속 격파 기반:** 체인 N 이상 유지 시 효과 발동
- **슈퍼웨폰 기반:** 슈퍼웨폰 게이지 만충 상태에서 효과 발동
- **보호막 기반:** 보호막 만충 상태에서 효과 발동
- **무피격 기반:** 피격 없이 N초 유지 시 효과 발동

구체적인 특성 목록 및 수치는 전체 시스템 기획 완료 후 컨텐츠 기획 단계에서 정의한다.

### 5.4 조건부 특성 단수 보유 원칙

기체당 조건부 특성은 **최대 1개**이다. 이를 통해 다음을 달성한다.

- 조건부 특성의 동시 발동 처리 같은 복잡한 로직 회피
- 기체별 정체성을 명확히 (이 기체는 어떤 조건에서 강해지는가가 단순하게 인지됨)
- 다수의 약한 조건부 특성보다 하나의 명확한 조건부 특성이 플레이 경험 면에서 유리

### 5.5 안정형 기체

모든 기체가 조건부 특성을 가질 필요는 없다. **조건부 특성 없이 상시 특성만으로 구성된 안정형 기체**도 존재해야 한다. 이를 통해 특성 발동을 신경 쓰지 않고 안정적으로 플레이하고 싶은 플레이어에게 선택지를 제공한다.

## 6. 기체 해금

### 6.1 이중 구조

기체 해금은 **상점 구매와 도전과제 해금**의 이중 구조로 운영한다. 장비 해금 시스템과 동일한 철학을 적용한다.

| 해금 방식 | 대상 | 역할 | 보존 단위 |
|-----------|------|------|-----------|
| 상점 구매 | 기본~중급 기체 | 캠페인 진행에 따른 자연스러운 기체 확보 | 세이브 데이터 단위 |
| 도전과제 해금 | 고급~특수 기체 | 숙련 보상 | 게임 전체 공유 |

### 6.2 해금 보존 단위 차별화

도전과제 해금 기체는 **게임 전체에 영구 공유**된다. 도전과제 해금은 플레이어의 숙련을 증명한 보상이므로, 새로운 세이브 데이터를 시작해도 이미 달성한 도전과제 해금 기체는 즉시 사용 가능하다.

상점 구매 기체는 **세이브 데이터 단위**로 보존된다. 새 세이브를 시작하면 다시 구매해야 한다.

이 차별화는 즉시 리플레이 방식으로 다회차의 의미가 약한 본 게임의 특성을 고려한 절충안이다. 모든 기체를 세이브 단위로 잠그면 도전과제 해금의 가치가 떨어지고, 모든 기체를 게임 전체 공유로 하면 새 세이브의 진행감이 약해진다.

### 6.3 영구 보유

해금된 기체는 **영구 보유**된다. 사용 횟수 제한이나 소모 같은 메커니즘은 없다.

### 6.4 수집 동기

10대 이상의 기체를 목표로 하므로, 해금 조건을 다양하게 설계하여 플레이어가 다양한 플레이 스타일과 도전을 시도하도록 유도한다. 해금 조건은 특정 빌드를 강제하지 않고, 자연스러운 플레이 과정에서 달성할 수 있는 수준과 고난도 도전이 혼합되도록 한다.

구체적인 해금 조건은 컨텐츠 기획 단계에서 정의한다.

## 7. 기체 변경

### 7.1 변경 가능 시점

기체 변경은 로드아웃 시스템과 동일한 규칙을 따른다.

- **미션 출격 전:** 로드아웃 씬에서 변경 가능
- **스테이지 클리어 후:** 다음 스테이지 출격 전 변경 가능
- **미션 실패 후 재도전 시:** 변경 가능
- **미션 진행 중:** 변경 불가

### 7.2 변경 비용

기체 변경에 비용은 발생하지 않는다. 자유롭게 변경 가능하다. 단, 상점에서 새 기체를 구매할 때만 비용이 발생한다.

## 8. 기체 선택 UI

### 8.1 스탯 표기

기체 선택 화면에서 플레이어에게 표시하는 정보:

| 항목 | 표기 방식 |
|------|-----------|
| 체력 | 1~10 추상화 지표 (로드아웃 스탯 표기와 동일 원칙) |
| 상시 특성 | 텍스트로 표시 (특성 이름 + 간략 설명) |
| 조건부 특성 | 텍스트로 표시 (조건 + 효과 안내). 없으면 미표시. |
| 기체 설명 | 플레이 스타일 안내 텍스트 |
| 외형 | 기체 모델 프리뷰 |

체력 이외의 수치적 스탯(기동 관련)은 전 기체 동일이므로 별도 표기하지 않는다.

## 9. 출격 플로우에서의 위치

기체 선택은 로드아웃 플로우에 통합한다.

```
미션 선택 → 미션 브리핑 → 기체 선택 + 로드아웃 씬 → 출격
```

기체 선택과 로드아웃 세팅은 동일한 씬 내에서 이루어진다. 기체를 먼저 선택한 후 해당 기체에 장비를 세팅하는 순서. 프리셋 시스템은 기체+로드아웃 조합을 함께 저장할 수 있다.

## 10. 시스템 간 연동 지점

| 연동 시스템 | 연동 내용 |
|-------------|-----------|
| 생존 시스템 | 기체가 체력 총량 결정 |
| 로드아웃 시스템 | 기체 선택 후 로드아웃 세팅. 슬롯 구성은 기체와 무관. 프리셋이 기체+로드아웃 조합 저장. |
| 플레이어 기동 시스템 | 기본 기동은 전 기체 동일. 기체 특성에 의한 일시적 기동 영향은 가능. |
| 슈퍼웨폰 시스템 | 기체 특성이 슈퍼웨폰 관련 보정을 가질 수 있음 (충전속도, 효과 등) |
| 슬롯 시너지 시스템 | 기체와 시너지는 독립적. 기체는 시너지 활성화 조건에 포함되지 않음. |
| 장비 해금 시스템 | 기체 해금도 동일한 이중 구조 적용 |
| 도전과제 시스템 | 기체 도전과제 해금 |
