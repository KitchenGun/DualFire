지원 포격 — 절벽 위에서 필드로 진입

A안 — 레터박스 HUD

  • 플레이필드 완전 청정. 배경 연속 정책과 조합 시 HUD에 반투명 패널 배킹 필수 (목업 반영됨)
  • 연출 시뮬레이션을 켜면 좌측 HUD가 연출에 가려짐 → 연출 중 HUD 정책 별도 필요

B안 — 필드 내 오버레이

  • 레터박스가 순수 배경+연출 전용으로 보존. 절벽 위 풍경과 연출이 간섭 없이 공존
  • 필드 가장자리 잠식 — 탄막과 겹칠 위험. 반투명 필수

C안 — 혼합

  • 상시 정보는 레터박스, 순간 정보(체인·특수무장 쿨다운)는 필드 안. 쿨다운이 기체 근처라 가려 쏘기 조작과 궁합 좋음
  • 연출 충돌은 좌측만 부분 발생 — A안보다 완화

경계 처리 후보 (하단 토글)

  • 1 명도 차이만 — 절벽 상단을 어둡게. 가장 자연스럽지만 경계가 흐릿할 수 있음
  • 2 + 절벽 그림자 밴드 — 절벽이 협곡 바닥에 그림자를 드리움 + 절벽 에지 하이라이트. 라이트 각도 시스템과 논리적으로 일치하는 자연 경계
  • 3 + 명시 라인 — HUD 톤의 인공 경계선 추가. 판정 영역이 기계적으로 명확, 대신 월드 연속감은 감소
  • 협곡은 예시 — 해상/시가지 등 절벽이 없는 테마에서도 같은 경계 문법이 성립해야 함
