상점 — 구현 포인트

  • 카테고리 탭 5종. 보유 장비는 목록 유지 + "보유" 표시 (재구매 불가)
  • 특화 슈퍼웨폰의 운용 환경 표시 — 태그 + 상세의 "운용 가능 전장" 명시 (모르고 사는 상황 방지, 슈퍼웨폰 3.6 결정)
  • 재화 부족 시 가격 회색 처리. 구매 = 확인 1회 (소비적 행동)
  • 구매 즉시 보유 반영 — 로드아웃 리스트에 자동 등장

시너지 도감 — 발견 단계 (우상단 토글로 확인)

  • 1 미발견: 전부 ? / 2 부분 발견: 보유 소재만 실명 표시
  • 3 조합 완성: 소재 전부 공개 + 계열 힌트만 ("공격 강화") — 정확한 효과는 비공개. "로드아웃에서 장착하면 완성" 안내로 다음 행동 유도
  • 4 장착 발견: 로드아웃에서 실제 장착한 순간 완전 공개 (출격 불요). 이후 영구 전체 공개
  • 발견 기록은 게임 전체 공유 (시너지 발견 시스템 준수)

도전과제 — 구현 포인트

  • 단계형 도전과제: 현재 단계 목표만 표시 + 진행도 바 (다음 단계는 달성 후 갱신)
  • 보상 미리 표시 (다음 보상: 장비/재화/트로피) — 동기 부여
  • 보상은 달성 시 자동 지급 (수령 조작 없음, 장비 해금 시스템 준수)
  • 게임 전체 공유임을 화면에 명시

기록실 — 구현 포인트

  • 미션 × 난이도별 최고 랭크 일람 — 캠페인 맵(지도형)이 갖지 못한 표 형태 일람성을 여기서 흡수
  • 격파율 최고 기록은 공중/지상 속성 색상 분리 표시
  • 분기 미션(2-B)도 목록 포함. 지상 적 없는 미션은 "—" (적용 제외)
  • 미션 선택 → 상세 기록 (빌드/일시 등, ClearRecord 기반) [제안 — 후순위]

결정 요청 — 시너지 도감 발견 단계

  • 토글의 4단계가 이전에 논의한 추천 조합: 점진 공개(1→2→3) + 3단계 계열 힌트 + 장착 시 완전 공개(4)
  • 장착만으로 발견 처리 (출격 불요) — "모르고 출격해서 한 판 날리는" 문제 없음
  • 대안이 있으면 지시: 3단계에서 계열도 숨김(완전 비공개) / 효과명까지 공개 등
