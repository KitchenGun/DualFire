브리핑 — 구현 포인트

  • 분기 충족 토글: 브리핑 본문이 분기 상태에 따라 변형됨 (미션 브리핑 시스템의 분기별 메시지) — 앰버색이 변형 메시지
  • HARD 토글: 적 구성 힌트가 난이도에 따라 숨김 처리 (정보 차등 정책). 환경 태그·목표는 난이도 무관 상시
  • 힌트의 속성 언급은 속성 색상 코딩 적용 (공중=하늘/지상=주황)
  • 스킵 지원, 뒤로 = 캠페인 맵, 진행 = 로드아웃 (자유 왕복)

세이브 슬롯 — 구현 포인트

  • 5슬롯 고정. 사용 슬롯: 진행도/난이도/플레이타임/마지막 플레이
  • 빈 슬롯의 "도전과제 누적 보상 지급" 안내 — 게임 전체 공유 재화·장비가 새 세이브에 적용됨을 시작 전에 고지 (해당 결정의 UI 반영 지점)
  • 삭제는 파괴적 행동 — 확인 다이얼로그 1회

타이틀 — 구현 포인트

  • 계속하기 = 최상단 기본 포커스 — 마지막 세이브로 즉시 진입 (루프 속도 원칙의 시작점)
  • 계속하기에 슬롯 요약 표시 (어느 세이브로 들어가는지 명시)
  • 로고/배경은 아트 영역 — 자리만 확보

옵션 — 구현 포인트

  • 카테고리 4탭: 게임플레이/사운드/화면/조작 [제안]
  • 조작 탭: 패드 = 프리셋 선택, 키보드 = 전체 리매핑 (입력 v0.2 준수). 패드/키보드 할당을 한 행에 병기
  • 충돌 키 할당 시 경고 후 교체(swap), 기본값 복원 제공
  • 옵션 변경 = 자동 저장 트리거. 설정은 게임 전체 공유

이 목업의 성격

  • 이 4화면은 배치 자유도가 낮아 A/B 비교 없이 단일 제안 — 이대로 확정하거나 수정 지시
  • 브리핑의 상태 토글 2종은 프로그래머 구현 참조용 (분기 변형 / 난이도 차등이 실제 데이터 분기 지점)
  • 타이틀 메뉴 구성(계속하기/세이브 선택/옵션/종료)과 옵션 카테고리 구성은 [제안] — 이견 있으면 조정
