A안 — 작전 지도형

  • 세계관 몰입 최고. 전역을 훑으며 진군하는 캠페인 서사감. 환경 타입(지상/해상/고고도)이 지형과 대응
  • 분기 힌트("?" + 파생선)가 지도 공간에서 갈라져 보임 — ③ 정책 표현력 좋음
  • 지도 아트 제작 비용 발생 — 로우폴리/스타일라이즈 지도로 비용 통제 가능하나 0은 아님
  • 미션 배치가 지형에 종속 — 미션 추가/변경 시 공간 재설계

B안 — 노드 그래프형 (작전 계통도)

  • 분기 구조 시인성 최고. 본선에서 위아래로 갈라지는 파생이 즉각 읽힘 — ③ 정책 표현력 가장 명확
  • 아트 비용 최소 — 배경 없는 계통도. 군사 작전도 스타일링으로 분위기 확보 가능
  • 미션 추가/변경에 무한 대응 (노드만 추가)
  • 지도형 대비 세계관 몰입 약함 — "어디서 싸우는가"의 공간감 없음

C안 — 미션 리스트형

  • 정보 밀도·리플레이 대상 탐색 최속. 환경/랭크/상태가 표로 한눈에
  • 아트 비용 0, 확장 무한
  • 분기가 들여쓰기 행(└)으로 표현 — 구조감이 가장 약하고 "메뉴" 인상
  • 캠페인 진행의 공간적 성취감 없음

이 목업으로 확인할 것

  • 노드 상태 5종이 전부 표시됨: 클리어(랭크) / 현재 / 순차 잠김(조건 공개) / 분기 해금·클리어(2-B) / 분기 힌트(? — 5-B)
  • ③ 정책의 핵심인 "? 노드 + 파생 연결선"이 각 배치에서 어떻게 읽히는지 — A/B는 선으로, C는 들여쓰기로
  • 중간 절충 [참고]: B안 계통도에 스테이지 테마 썸네일/환경 색상을 입히면 아트 비용을 낮게 유지하면서 공간감 일부 보완 가능
  • 리스트형의 랭크 일람성은 A/B 채택 시에도 기록실(7호)이 흡수 가능
