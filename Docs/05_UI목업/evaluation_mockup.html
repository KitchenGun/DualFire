아무 키 — 연출 스킵 (즉시 전체 표시)

A안 — 순차 카드형 (콘솔 클래식)

  • 알림이 모달 카드로 하나씩 등장 — 개별 알림의 주목도 최고
  • 다중 발생 시 조작 피로. 시뮬레이션을 켜면 4건을 전부 확인으로 넘겨야 평가로 돌아옴 — 리플레이 루프 속도 원칙과 충돌
  • 카드가 평가 결과를 가림 (딤 처리) — 격파율 확인과 알림 확인이 순차로 강제됨

B안 — 정산 대시보드형

  • 조작 0회. 평가+알림+행동이 동시 표시 — 리플레이 루프 최속
  • 다중 알림도 우측 스택에 그냥 쌓임 — 개수와 무관하게 화면 1장
  • 연출 없음 — 클리어의 보상감·랭크 확인의 긴장감이 약함
  • 알림 개별 주목도 낮음 — 중요 알림(분기 해금)이 묻힐 수 있음

C안 — 연출 + 스택형

  • 평가 항목이 순차 도장 연출로 등장 → 종합 랭크 → 알림 스택 등장 (연출 다시 재생 버튼으로 확인)
  • 아무 키로 연출 스킵 → 즉시 전체 표시 — 첫 클리어의 긴장감과 반복 플레이의 속도를 양립
  • 알림은 B안처럼 스택 — 다중 발생에도 조작 불필요
  • 연출 총 길이가 루프 속도의 상한 — 짧게 유지 필요 [검증]

이 목업으로 확인할 것

  • 다중 알림 시뮬레이션을 켜고 A안과 B/C안의 조작량 차이를 비교 — 이 화면 설계의 핵심 결정
  • 공중/지상 격파율의 속성 색상 분리 표시 — "지상이 B네, 대지 무장 보강해서 리플레이" 판단이 이 화면에서 일어남 (코어 루프의 귀결점)
  • 리플레이 버튼이 최우선 위치(우하단 강조)인지 — 루프 속도 원칙
  • 기록 비교(TAB): 이전 최고 기록과의 비교 표시는 상세 뷰로 분리 [제안]
  • 랭크 색상(S금/A녹/B청/C회/D적)은 가정값 — 아트 확정 시 조정
