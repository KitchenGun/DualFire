A안 — 감상형 + 프리뷰 무대

  • 중앙 기체 뷰가 그대로 프리뷰 무대가 됨 — 장비를 고르면 화면의 내 기체가 그 무장을 발사. 감상과 정보가 하나로 합쳐짐
  • 선택 캐러셀이 좌측으로 비켜나 기체를 가리지 않도록 조정됨
  • 상세 스탯 표시 공간이 여전히 좁음 (우하단 소형 카드)

B안 — 정비 패널형 + 전용 프리뷰 박스

  • 우측 컬럼 상단에 전용 프리뷰 박스 추가 — 리스트 포커스 이동에 따라 즉시 재생 전환
  • 프리뷰+스탯+시너지가 한 컬럼에 수직 정렬 — 정보 완결성 최고
  • 프리뷰 무대가 작음 — 슈퍼웨폰의 대형 연출(레터박스 확산 등)은 축소 표현 한계

C안 — 혼합형 + 프리뷰 무대

  • 좌측 기체 뷰가 상시 프리뷰 무대 — 선택 오버레이는 우측만 덮으므로 프리뷰가 절대 가려지지 않음
  • 리스트 포커스 이동 → 좌측에서 즉시 동작 재생: "고르면서 본다" 동선이 가장 자연스러움
  • A안 대비 기체 뷰 크기 절반 — 프리뷰 무대도 그만큼 작음

D안 — 무뎁스 3컬럼 + 프리뷰 무대 (C 개선안)

  • 뎁스 0 (B안 구조) — 슬롯 포커스 이동만으로 우측 리스트 자동 갱신, 열고 닫는 모달 없음
  • 프리뷰 무대 상시 비가림 (C안 장점) — 좌측 무대가 어떤 상태에서도 가려지지 않음
  • 리스트 포커스 이동 → 좌측에서 즉시 동작 재생 + 하단 상세 갱신. "고르면서 본다" 완성형
  • 기체 감상 크기는 최소 — 대신 기체 슬롯 포커스 시 무대가 회전 감상 뷰로 전환되어 감상 요구를 흡수 [제안]

동작 프리뷰 — 요구사항 정리

  • 모든 장비는 선택(포커스) 시 실제 동작을 반복 재생으로 보여준다 (신규 확정 요건)
  • 장비별 프리뷰 내용: 기본무기/특수무장=발사 패턴, 슈퍼웨폰=발동 연출 축소판, 보호막=피격 흡수→파괴 데모, 기체=[정의 필요], 시너지 드론=동행+동작
  • 구현 방향 [제안]: 사전 제작 영상이 아닌 실제 게임 데이터 기반 미니 씬 반복 재생 — 밸런스 수정이 프리뷰에 자동 반영, 별도 영상 제작 비용 없음
  • 목업의 레이저 반복 재생은 예시 — 실제로는 선택 장비에 따라 프리뷰가 전환됨
  • UI 뎁스 비교: A +1(캐러셀 모달) / B 0(공간 이동) / C +1(오버레이 모달) / D 0(공간 이동)+프리뷰 상시
