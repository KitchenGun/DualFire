## 1. 개요

본 문서는 게임 전체의 입력 체계를 정의한다. 게임플레이 입력(프로토타입 사양서에 상세 정의됨)의 설계 의도를 요약하고, 메뉴 조작·입력 장치 정책·예외 처리 등 주변 입력 체계를 정의한다.

---

## 2. 지원 입력 장치

| 장치 | 지원 수준 |
|------|-----------|
| 게임패드 | 1급 지원 (권장 장치) |
| 키보드 | 1급 지원 |
| 마우스 | 메뉴 조작 한정 보조 지원 (인게임 조작 없음) |

**활성 장치 규칙 (단일 규칙 — 상황별 분리):**

| 상황 | 규칙 |
|------|------|
| 게임 시작 | 연결된 게임패드가 있으면 게임패드, 없으면 키보드를 초기 활성 장치로 설정 |
| 메뉴 중 | 다른 장치의 의미 있는 입력 발생 시 **즉시 활성 장치 변경** — 일시정지·확인 절차 없음, UI 프롬프트 즉시 갱신 |
| 인게임 중 | 다른 장치의 의미 있는 최초 입력은 **게임플레이에 전달하지 않고** 자동 일시정지 + 해당 장치를 전환 대기로 설정 (확정/취소 규칙은 아래) |

- UI의 버튼 프롬프트 아이콘은 활성 장치 기준으로 표시한다
- "의미 있는 입력" = 버튼 입력 또는 **장치 전환 축 임계값**을 넘는 축 입력. 이 임계값은 이동 데드존과 **별개의 값**이며, 스틱 드리프트 방지를 위해 이동 데드존보다 높게 설정할 수 있다
- **마우스 이동·호버는 인게임 장치 전환을 발생시키지 않는다** (마우스는 인게임 조작이 없으므로)

**전환 대기의 확정/취소:**

- **전환 대기 장치의 확인 입력** → 해당 장치를 활성화하고 게임 재개
- **기존 활성 장치의 취소 입력** → 장치 전환을 취소하고 기존 장치로 게임 재개
- 전환 메뉴가 열린 동안 제3의 장치에서 의미 있는 입력이 발생하면 전환 대기 장치를 해당 장치로 갱신한다

## 3. 게임플레이 입력 (설계 의도 요약)

구체 매핑과 처리 규칙은 프로토타입 사양서를 따른다. 본 절은 설계 의도만 정의한다.

| 조작 | 설계 의도 |
|------|-----------|
| 이동 | 키보드 = 8방향 / 게임패드 = 연속 방향 + 입력 크기 디지털화. 해석 규칙은 플레이어 기동 시스템 준수 |
| 저속 모드 | 기본 홀드, 옵션에서 토글 전환 가능. 토글 상태·리셋 규칙은 플레이어 기동 시스템 준수 |
| 기본 무기 발사 | 홀드 연사. "쏘지 않을 이유가 없는" 주력 무장 |
| 특수무장 1 발사 | 슬롯 1 전용 키. 슬롯별 쿨다운 독립 |
| 특수무장 2 발사 | 슬롯 2 전용 키. 슬롯별 쿨다운 독립 |
| 슈퍼웨폰 발동 | 명시적 단일 키. 오발 방지를 위해 이동/사격 키와 물리적으로 분리된 위치 권장 |
| 일시정지 | 즉시 반응. 일시정지 중 게임 상태 완전 정지 — **정지 대상의 세부(타임라인·AI·탄환·쿨다운·게이지·무적/버프 시간 등)는 게임플로우·씬 구조 문서를 단일 기준으로 따른다** |

조작 수를 늘리지 않는 것이 원칙이다. 신규 시스템이 추가되어도 신규 키 할당은 최소화하고, 기존 조작의 조합이나 자동화(시너지 드론의 자동 작동 등)로 해결한다.

**특수무장 슬롯별 개별 키는 이 원칙의 의도된 예외다.** 지상/공중 속성 분리가 이 게임의 코어이므로, "지금 어느 표적에 어느 무장을 쓸 것인가"라는 순간 판단이 조작으로 이어져야 속성 분리의 의미가 인게임까지 유지된다. 단일 키 동시 발사는 이 판단을 제거하고 불필요한 쿨다운 소모(표적이 없는 속성의 무장까지 발사됨)를 유발하므로 채택하지 않는다.

**동시 입력 지원은 필수 요건이다.** 특수무장을 동시에 발사할 수 있는 선택권은 플레이어에게 있어야 한다.

- 두 특수무장 키가 같은 프레임에 입력되면 두 슬롯 모두 해당 프레임에 발사된다 (각자 쿨다운 조건 충족 시)
- 두 키 사이에 상호 배제, 입력 잠금, 우선순위 처리를 두지 않는다 — 각 키는 완전히 독립적으로 병렬 처리된다
- 한 키를 홀드한 상태에서 다른 키를 추가 입력하는 것도 정상 동작해야 한다

즉 개별 키 분리는 "따로 쏠 수 있는 선택권"을 주는 것이지 "같이 쏘는 것을 막는 제약"이 아니다. 가려 쏠지, 한꺼번에 퍼부을지는 전적으로 플레이어의 전술 선택이다.

부수 규칙:
- **슬롯 1·2는 속성 지정이 없는 자유 슬롯이다.** 대공×2, 대지×2 같은 동일 속성 조합도 허용된다 (로드아웃 시스템 준수). 키는 슬롯 위치에 고정될 뿐, 속성에 고정되지 않는다
- 슬롯 1/2와 키의 대응은 고정이며, 로드아웃 화면에서 어느 슬롯이 어느 키인지 명확히 표시되어야 한다 (근육 기억과 빌드 구성이 연결되도록) — UI 기획으로 이관
- 기본 키 배치(패드 프리셋 포함)는 두 특수무장 키를 **동시에 누르기 물리적으로 편한 위치**에 두어야 한다 (예: 양쪽 숄더 버튼처럼 서로 다른 손가락으로 자연스럽게 동시 입력 가능한 배치)

## 4. 메뉴/UI 조작

### 4.1 공통 조작 문법

모든 메뉴 씬에서 동일한 조작 문법을 유지한다.

| 조작 | 동작 |
|------|------|
| 방향 | 항목 이동 |
| 확인 | 선택/진입 |
| 취소 | 뒤로/닫기 |
| 탭 전환 | 화면 내 카테고리 전환 (로드아웃의 슬롯 종류, 도감 페이지 등) |
| 상세 보기 | 항목의 상세 정보 토글 (장비 스탯 지표 등) |

- 마우스 사용 시: 클릭 = 확인, 우클릭(또는 화면 내 뒤로 버튼) = 취소. **호버는 항목 포커스만 변경하며 활성 장치를 바꾸지 않는다** — 클릭·휠 입력이 발생할 때만 활성 장치가 키보드/마우스로 전환된다 (책상 진동 수준의 마우스 이동으로 버튼 프롬프트가 깜박이는 것 방지)
- 취소 입력은 **현재 화면의 직전 부모 화면**으로 이동하며, 반복하면 **현재 컨텍스트의 루트 화면**까지 복귀한다 (동선 미아 방지)
  - 세이브 선택 전 컨텍스트의 루트: 타이틀
  - 세이브 로드 후 캠페인 컨텍스트의 루트: 캠페인 맵 (허브)
  - 인게임 컨텍스트의 루트: 일시정지 메뉴 (세부는 게임플로우 문서)

### 4.2 출격 직전 확인

로드아웃에서 출격은 오조작 방지를 위해 명시적 확정 입력으로 처리한다 (즉시 출격이 아닌 확인 단계 1회). 단, 리플레이 루프의 속도를 해치지 않도록 확인 단계는 1회를 초과하지 않는다.

## 5. 입력 장치 예외 처리

| 상황 | 처리 |
|------|------|
| 인게임 중 다른 장치의 의미 있는 입력 | 2장 활성 장치 규칙 준수 — 게임플레이 미전달 + 자동 일시정지 + 전환 대기. 감지는 버튼 또는 장치 전환 축 임계값 초과 입력만 (드리프트 오발 방지, 임계값은 이동 데드존과 별개) |
| 인게임 중 **활성** 게임패드 연결 해제 | 자동 일시정지 + 재연결/장치 변경 안내 |
| 인게임 중 **비활성** 게임패드 연결 해제 | 게임 진행에 영향 없음 |
| 게임 창 포커스 아웃 | 자동 일시정지. **포커스 복귀 시 자동 재개하지 않는다** — 플레이어의 명시적 재개 입력 필요 (Alt+Tab 복귀 순간 기체가 움직이거나 맞는 사고 방지) |
| 메뉴 중 장치 변경 | 일시정지 없이 즉시 전환, 프롬프트 아이콘 갱신 (2장 준수) |

## 6. 키 리매핑

- 키보드: 전 게임플레이 키 리매핑 지원
- 게임패드: 프리셋 제공 (기본 + 대체 1~2종). 완전 자유 리매핑은 후순위
- 리매핑 화면은 옵션 하위. 충돌 키 할당 시 경고 후 교체(swap) 방식
- 저장 단위: 게임 전체 공유 (세이브 슬롯과 무관)

---

## 7. 입력 반응성 원칙

- 게임플레이 입력은 입력 버퍼링 없이 즉시 반영한다 (프로토타입 사양서의 반응성 기준을 따름)
- 메뉴 입력은 방향키 홀드 시 리피트(초기 지연 후 연속 이동) 지원
- 일시정지/옵션 진입은 어떤 처리 중에도 즉시 반응

## 9. 확정 사항 요약

| 항목 | 결정 사항 |
|------|-----------|
| 지원 장치 | 패드/키보드 1급, 마우스는 메뉴 한정 |
| 장치 전환 | 자동 감지, 활성 장치 기준 프롬프트 표시 |
| 게임플레이 조작 | 이동/저속/기본무기/특수무장 슬롯별 개별 키/슈퍼웨폰/일시정지 |
| 특수무장 조작 | 슬롯 1·2 개별 키 (속성 분리의 순간 판단을 조작으로 유지). **동시 입력 지원 필수** — 두 키 병렬 독립 처리, 상호 배제 없음 |
| 메뉴 문법 | 방향/확인/취소/탭/상세 5종 공통. 취소 연타 = 현재 컨텍스트의 루트까지 복귀 (타이틀/캠페인 맵/일시정지 메뉴) |
| 출격 확인 | 명시적 확정 1회 (초과 금지) |
| 예외 처리 | 활성 장치 변경·활성 패드 해제·포커스 아웃 시 인게임 자동 일시정지. 포커스 복귀 자동 재개 금지. 전환 감지 임계값은 이동 데드존과 별개 |
| 리매핑 | 키보드 전체 지원, 패드는 프리셋. 게임 전체 공유 저장 |
