## 1. 개요

본 문서는 **슈퍼웨폰 시스템**의 세부 설계를 정의한다. 슈퍼웨폰은 게이지 충전 후 스톡으로 전환하여 사용하는 강력한 능력이며, 로드아웃에서 1개를 선택하여 장착한다.

슈퍼웨폰은 효과의 조합으로 정의되며, 카테고리(공격/방어/유틸리티 등)는 효과 구성에 의해 자연스럽게 결정되는 레이블이다.

---

## 2. 설계 철학

### 2.1 효과 기반 설계

슈퍼웨폰의 성격은 **보유한 효과의 조합에 의해 결정**된다.

- 데미지를 주니까 공격형이다 (공격형이니까 데미지를 줘야 한다 ✕)
- 보호막이 제공되니까 방어형이다 (방어형이니까 보호막을 줘야 한다 ✕)
- 긴급 회피를 주니까 유틸리티형이다 (유틸리티형이니까 회피를 줘야 한다 ✕)

이 철학에 따라, 하나의 슈퍼웨폰이 여러 카테고리에 걸친 복합 효과를 가지는 것도 자연스럽게 허용된다. 예를 들어 "데미지를 주면서 보호막을 회복하는" 슈퍼웨폰은 공격+방어 복합형이 된다.

### 2.2 카테고리 태그의 역할

카테고리 태그(공격/방어/유틸/복합 등)는 두 가지 역할을 가진다.

| 역할 | 용도 |
|------|------|
| UI 표시 | 플레이어에게 슈퍼웨폰의 성격을 직관적으로 전달 |
| 슬롯 시너지 매칭 조건 | 슬롯 시너지 시스템에서 카테고리를 매칭 조건으로 활용 가능 |

시스템 로직의 일반적 분기에는 사용하지 않으나, 슬롯 시너지 매칭에는 사용 가능하다.

### 2.3 속성은 효과 단위

슈퍼웨폰 자체에 속성(범용/대공/대지)이 붙는 것이 아니라, 개별 효과에 속성이 부여된다. 하나의 슈퍼웨폰이 "대공 데미지 + 범용 보호막 회복"처럼 효과마다 다른 속성을 가질 수 있다.

## 3. 슈퍼웨폰 구성

### 3.1 슈퍼웨폰 데이터

슈퍼웨폰은 식별 정보(이름, 설명), 효과 배열(핵심 데이터, 3.2절 참고), 소비 스톡 수, 최대 스톡 수, 게이지 충전 속도 보정, 사용 중 무적/이동/공격 가능 여부, 중첩 사용 가능 여부, 카테고리 태그(공격/방어/유틸/복합 — UI 표시와 슬롯 시너지 매칭에 사용), 해금 조건을 가진다.

### 3.2 효과 데이터

슈퍼웨폰의 효과 배열에 포함되는 개별 효과는 효과 종류(데미지/회복/무적/이동 등), 속성(데미지 효과 등에 의미), 강도 수치, 적용 범위(전체/전방/주변/자신), 지속 시간(즉발은 0)으로 구성된다.

(본 시스템의 데이터 항목 세부 정의는 별도의 데이터 테이블 문서에서 관리한다.)

### 3.3 효과 종류 카탈로그

효과 종류의 구체적 카탈로그는 **컨텐츠 기획 단계에서 정의**한다. 본 시스템은 효과 종류를 자유롭게 추가할 수 있는 확장 가능한 구조로 설계하며, 데미지/회복/무적/이동 효과 등 기본 카테고리만 미리 가정한다.

### 3.4 효과 조합 예시

구체적 수치는 밸런싱 단계에서 결정하며, 본 예시는 효과 조합의 활용 방식을 보여주기 위한 것이다.

**예시 A — 순수 공격형 (대공)**

슈퍼웨폰 데이터:
- 사용 중 무적: false / 사용 중 이동: true / 사용 중 공격: true
- 중첩 사용 가능: true
- 소비 스톡: 1 / 카테고리 태그: 공격

효과: 화면 전체의 공중 적에게 즉발 데미지.

**예시 B — 방어형 (범용)**

슈퍼웨폰 데이터:
- 사용 중 무적: false / 사용 중 이동: true / 사용 중 공격: true
- 중첩 사용 가능: false
- 소비 스톡: 1 / 카테고리 태그: 방어

효과: 보호막 즉시 회복 + 5초간 피해 감소.

**예시 C — 유틸리티형 (긴급 회피)**

슈퍼웨폰 데이터:
- 사용 중 무적: true / 사용 중 이동: true (특수 대시 이동) / 사용 중 공격: false
- 중첩 사용 가능: false
- 소비 스톡: 1 / 카테고리 태그: 유틸

효과: 1초간 긴급 대시 (무적 이동).

**예시 D — 복합형 (공격+방어)**

슈퍼웨폰 데이터:
- 사용 중 무적: true / 사용 중 이동: false / 사용 중 공격: false
- 중첩 사용 가능: false
- 소비 스톡: 2 / 카테고리 태그: 복합

효과: 화면 전체의 지상+공중 적에게 즉발 데미지 + 보호막 즉시 회복.

## 4. 게이지 및 스톡 시스템

### 4.1 게이지 → 스톡 전환

게이지가 100% 채워지면 **1스톡으로 자동 전환**된다. 스톡이 최대치에 도달하면 게이지는 더 이상 충전되지 않는다.

### 4.2 충전 경로

슈퍼웨폰 게이지는 3가지 경로로 충전된다.

| 경로 | 역할 | 충전량 결정 |
|------|------|-------------|
| 적 격파 (메인) | 주요 충전 수단 | 몬스터 데이터 테이블에 개별 설정 |
| 자연 충전 (서브) | 적을 잡지 못하는 구간의 안전망 | 슈퍼웨폰별 게이지 충전 속도 보정 |
| 아이템 드롭 (보너스) | 슈퍼웨폰 충전 아이템 획득 시 | 아이템 데이터로 관리 |

### 4.3 적 격파 충전량

적 격파 시 게이지 충전량은 **몬스터 데이터 테이블에 컬럼으로 포함**한다. 적 등급(잡몹/엘리트/중간보스/보스)에 따라 충전량을 개별 설정할 수 있다.

### 4.4 자연 충전

시간 경과에 따라 소량씩 자동 충전된다. 충전 속도는 슈퍼웨폰별 데이터로 관리되며, 느린 속도로 설정한다. 주 역할은 특화 빌드에서 반대 속성 페이즈에 걸려 적을 격파하지 못하는 구간에서의 최소 안전망이다.

### 4.5 스톡 소비

| 소비 스톡 | 포지셔닝 |
|-----------|----------|
| 1스톡 | 기본. 대부분의 슈퍼웨폰. |
| 2스톡 | 강력한 복합 효과를 가진 상위 슈퍼웨폰. |

소비 스톡이 높은 슈퍼웨폰은 강력하지만, 사용 기회가 제한되어 리스크-보상 트레이드오프가 성립한다.

### 4.6 스톡 밸런스 원칙

최대 스톡과 소비 스톡의 관계가 슈퍼웨폰의 성격을 결정한다.

- **최대 스톡 높음 + 소비 1:** 약하지만 여러 번 사용 가능. 유연한 운용.
- **최대 스톡 낮음 + 소비 1:** 사용 기회가 적지만 강력한 효과.
- **최대 스톡 높음 + 소비 2:** 강력하지만 사용 횟수는 제한적. 스톡 관리 판단이 중요.

## 5. 발동 및 사용 처리

### 5.1 발동 키

슈퍼웨폰 발동은 **별도 조작키**에 할당된다. 기본 무기, 특수무장과 별도의 키로 운영하여 슈퍼웨폰의 무게감을 유지한다.

### 5.2 발동 즉시성

슈퍼웨폰은 키 입력 즉시 효과가 시작된다. 발동 모션이 있더라도 모션 완료를 기다리지 않으며, **시각적 모션과 효과 발동이 동시에 시작**된다. 즉 모션이 진행 중인 동안 이미 효과는 적용되고 있다.

### 5.3 사용 중 플레이어 상태

슈퍼웨폰 발동 후 효과가 종료될 때까지의 플레이어 상태는 **슈퍼웨폰 단위로 데이터에서 설정**한다.

| 항목 | 설정 |
|------|------|
| 사용 중 무적 | true / false |
| 사용 중 이동 | true / false |
| 사용 중 공격 | true / false |

효과별이 아닌 슈퍼웨폰 단위 단일 값으로 운영하여, 발동 중 플레이어 상태가 단순하고 일관되게 유지된다.

### 5.4 중첩 사용 가능 여부

슈퍼웨폰 효과가 지속되는 동안 다른 스톡으로 추가 발동이 가능한지 여부는 **슈퍼웨폰 단위 데이터로 제어**한다.

- **중첩 사용 가능 (true):** 효과 지속 중에도 다른 스톡 사용 가능. 효과가 누적되거나 동시 적용됨.
- **중첩 사용 불가 (false):** 효과 지속 중에는 다른 스톡 사용 불가. 효과 종료 후 다음 발동 가능.

중첩 사용 가능 슈퍼웨폰의 존재를 보장하기 위한 데이터 항목이다. 슈퍼웨폰별로 효과 성격에 맞게 설정한다.

### 5.5 스톡 0 상태에서의 사용 시도

스톡이 0인 상태에서 발동 키를 누르면 **간단한 시각 피드백**으로 사용 불가를 표시한다. 경고음은 사용하지 않는다 (연타 시 불쾌감 방지).

UI에서 명확히 사용 불가임을 표시하는 것으로 충분하므로, 시각 피드백도 최소화하거나 무반응 처리해도 무방하다. 구체적 처리는 UI 시스템에서 결정한다.

### 5.6 효과의 판정 처리

슈퍼웨폰 효과는 일반 탄환의 관통 방식 판정을 그대로 따르지 않는다. 효과별로 판정 처리가 개별 정의된다.

| 효과 종류 | 판정 처리 방향성 |
|-----------|------------------|
| 데미지 효과 (광역) | 범위 내 모든 적 중 효과 속성과 일치하는 적에게 데미지 적용 |
| 회복 효과 | 자신 또는 지정 대상에 적용. 콜리전 판정 없음. |
| 무적 효과 | 플레이어 상태 변경. 콜리전 판정 없음. |
| 이동 효과 | 플레이어 위치/속도 변경. 콜리전 판정 없음. |

데미지 효과의 속성 일치 규칙은 판정 분리 시스템의 규칙을 따른다 (코어시스템_지상공중판정분리_v0.2 참고).

## 6. UI 표시

### 6.1 게이지 표시

게이지가 0%에서 100%까지 채워지는 과정이 인게임 UI에 시각적으로 표시된다. 100% 도달 시 1스톡으로 전환되며, 게이지는 0%로 리셋된다 (또는 다음 스톡 충전을 위한 새 게이지가 시작).

### 6.2 스톡 표시

보유 중인 스톡 수는 **UI에 아이콘으로 표시**된다. 아이콘 개수가 현재 스톡 수를 시각적으로 전달한다.

UI의 구체적 디자인은 UI 시스템 기획에서 다룬다.

## 7. 스코어링과의 관계

### 7.1 스코어 처리 정책

슈퍼웨폰으로 격파한 적도 **다른 격파와 동일하게 스코어 처리**된다. 격파 속도 배율, 체인 배율 모두 정상 적용된다.

이 정책의 의도는 "슈퍼웨폰을 썼다고 점수가 떨어지는 심리적 불쾌감"을 주지 않는 것이다. 슈퍼웨폰 사용은 스코어 손실로 처벌되지 않으며, 사용 자체가 자유로운 전술적 선택이다.

### 7.2 스코어 공식 설계 시 고려 사항

슈퍼웨폰 다수 격파 시 점수가 폭발적으로 늘어날 수 있다는 점은 스코어 공식 설계 시 별도로 고려한다. 슈퍼웨폰 미사용 보너스의 가치도 이 점을 감안하여 충분한 크기로 설정한다.

구체적 수치는 스코어링 시스템 밸런싱 단계에서 결정한다.

## 8. 슈퍼웨폰과 특수 기동의 관계

### 8.1 특수 기동 대체

별도의 특수 기동 시스템(긴급 회피, 대시 등)은 두지 않는다. 해당 기능은 **슈퍼웨폰의 효과 데이터로 구현**한다. 긴급 회피 효과를 가진 슈퍼웨폰을 장착하면 그것이 곧 해당 기체의 특수 기동이 된다.

### 8.2 효과 기반 설계의 장점

특수 기동을 슈퍼웨폰에 흡수함으로써:

- 긴급 회피 능력 자체가 로드아웃 선택의 대상이 된다.
- 별도 시스템을 추가하지 않고 기존 프레임워크 안에서 처리된다.
- "강력한 공격 슈퍼웨폰 vs 안전한 회피 슈퍼웨폰"이라는 로드아웃 트레이드오프가 생긴다.

## 9. 시스템 간 연동 지점

| 연동 시스템 | 연동 내용 |
|-------------|-----------|
| 지상/공중 판정 분리 시스템 | 슈퍼웨폰 효과의 속성 판정 (효과별 개별 처리) |
| 로드아웃 시스템 | 슈퍼웨폰 슬롯 1개에 장착 |
| 생존 시스템 | 회복/오버차지 효과는 슈퍼웨폰 명시 동작 따름 (생존 시스템 규칙 무시) |
| 플레이어 기동 시스템 | 유틸리티 효과(대시, 이동속도 등)가 특수 기동 대체 |
| 스코어링 시스템 | 슈퍼웨폰 격파도 일반 격파와 동일 처리. 미사용 보너스 별도 존재. |
| 인게임 아이템 드롭 | 슈퍼웨폰 충전 아이템 |
| 스테이지 구조 | 스테이지 내 적 격파 시 게이지 충전 |
| 보스 페이즈 시스템 | 보스전 중 슈퍼웨폰 운용. 잡몹 격파 시 게이지 충전. |
| 몬스터 데이터 | 적 격파 시 게이지 충전량 |
| 기체 시스템 | 기체 특성 중 슈퍼웨폰 관련 보정 (충전속도 등) |
| 슬롯 시너지 시스템 | 카테고리 태그가 시너지 매칭 조건으로 활용 가능 |

## 11. 확정 사항 요약

| 항목 | 결정 사항 |
|------|-----------|
| 설계 철학 | 효과 기반 설계. 카테고리는 효과에 의해 결정되는 레이블. |
| 카테고리 역할 | UI 표시 + 슬롯 시너지 매칭 조건 |
| 속성 | 효과 단위로 부여. 슈퍼웨폰 단위가 아님. |
| 효과 조합 | 하나의 슈퍼웨폰이 복수의 효과를 가질 수 있음 (복합형 허용) |
| 효과 종류 카탈로그 | 컨텐츠 기획에서 채워나감 |
| 사용 중 무적/이동/공격 | 슈퍼웨폰 단위 데이터 (효과별 아님) |
| 중첩 사용 가능 여부 | 슈퍼웨폰 단위 데이터로 제어 |
| 발동 키 | 별도 조작키 |
| 발동 즉시성 | 입력 즉시 효과 시작. 모션과 효과는 동시 진행. |
| 소비 스톡 | 1스톡 기본, 2스톡 강력형 존재 |
| 최대 스톡 | 슈퍼웨폰별 차등 |
| 게이지 → 스톡 | 게이지 100% 도달 시 1스톡 생성 |
| 게이지 충전 경로 | 적 격파(메인) + 자연 충전(서브) + 아이템(보너스) |
| 적 격파 충전량 | 몬스터 데이터 테이블에 컬럼으로 포함 |
| 스톡 0 사용 시도 | 간단한 시각 피드백 또는 무반응 (경고음 없음) |
| 게이지/스톡 UI | 게이지 바 + 스톡 아이콘 |
| 스코어 처리 | 슈퍼웨폰 격파도 일반 격파와 동일 (격파 속도/체인 배율 정상 적용) |
| 효과 판정 처리 | 효과별 개별 처리. 데미지 효과는 속성 일치 규칙 적용. |
| 특수 기동 | 슈퍼웨폰 효과로 흡수 (별도 시스템 없음) |
