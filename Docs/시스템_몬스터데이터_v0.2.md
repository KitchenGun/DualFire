## 1. 개요

본 문서는 게임 내 모든 적 유닛의 **몬스터 데이터 구조**를 정의한다. 잡몹/엘리트/중간보스/보스 등 모든 적의 데이터 항목을 통합 관리하며, 다른 시스템들이 참조하는 데이터의 단일 출처 역할을 한다.

본 문서는 데이터 항목의 종류와 의미를 정의하며, 구체적인 데이터 테이블 스키마(컬럼 타입, 정규화 등)는 별도의 데이터 테이블 설계 단계에서 다룬다.

---

## 2. 몬스터 분류

### 2.1 등급별 분류

게임 내 모든 적은 다음 4등급으로 분류된다 (스테이지 구조 시스템 6장 참고).

| 등급 | 역할 |
|------|------|
| 잡몹 | 웨이브 단위 기본 적 |
| 엘리트 | 잡몹과 보스 사이의 중간 위협 |
| 중간보스 | 스테이지 중반 강적 |
| 보스 | 스테이지 최종 적 |

### 2.2 보스 데이터의 별도 관리

보스는 본체+파츠 세트, 페이즈 구성 등 추가 구조를 가진다. 본 문서에서는 잡몹/엘리트/중간보스의 일반 몬스터 데이터를 정의하며, 보스의 특수 데이터 구조는 **보스 페이즈 시스템** 세부 기획에서 다룬다.

다만 보스 본체와 보스 파츠도 본 시스템의 기본 항목(속성, 콜리전 등) 일부를 공유하므로, 보스 페이즈 시스템 문서에서 본 문서를 참조한다.

## 3. 몬스터 데이터 항목

(본 시스템의 데이터 항목 세부 정의는 별도의 데이터 테이블 문서에서 관리한다.)

### 3.1 식별 정보

몬스터는 고유 식별 정보, 표시 이름(도감용, 선택적), 등급(잡몹/엘리트/중간보스)을 가진다.

### 3.2 시각/물리 정보

외형 모델 참조와 피격 영역(콜리전) 정의를 가진다. 콜리전은 모델과 별개로 정의된다.

### 3.3 전투 속성 정보

속성(지상 또는 공중, 잡몹은 단일 속성), 체력, 공격 패턴 참조를 가진다. 양면 속성은 보스 본체/파츠에서만 가능하다 (보스 페이즈 시스템 참고).

### 3.4 보상/연동 정보

격파 시 기본 점수와 격파 속도 배율 커브(스코어링 시스템 연동), 슈퍼웨폰 게이지 충전량(슈퍼웨폰 시스템 연동), 드롭 아이템 목록(다중 드롭 지원, 아이템 드롭 시스템 연동)을 가진다.

### 3.5 등장 정보 (스테이지 데이터에서 결정)

다음 정보는 몬스터 데이터 자체가 아닌 **스테이지의 웨이브 데이터**에서 결정한다.

| 항목 | 결정 위치 |
|------|-----------|
| 등장 시점 | 웨이브 데이터의 트리거 시간 |
| 등장 위치 | 웨이브 데이터의 몬스터 배치 |
| 등장 방향 | 웨이브 데이터의 등장 방향/이동 경로 |
| 등장 지연 | 웨이브 데이터의 등장 지연 |

이 정보는 같은 몬스터 데이터를 여러 위치/시점에 재사용할 수 있게 분리되어 있다.

## 4. 외형 재사용 원칙

### 4.1 같은 외형 다른 데이터

같은 아트 프리팹(외형)을 사용하더라도 **드롭 아이템이나 다른 보상이 다르면 별도의 몬스터 데이터로 관리**한다. 이는 아이템 드롭 시스템 v0.2 3.3에서 정의된 원칙이다.

이를 통해:
- 동일 외형의 적을 다양한 드롭 용도로 재활용 가능
- 웨이브 데이터에서 어떤 적을 배치하느냐에 따라 아이템 분포가 자연스럽게 결정
- 레벨 디자이너가 정밀하게 보상 분포를 제어 가능

### 4.2 데이터 항목 차이로 분류

같은 외형이라도 다음 항목 중 어느 하나라도 다르면 별도 데이터로 관리한다.

- 속성 (지상/공중)
- 체력
- 공격 패턴
- 기본 점수
- 격파 속도 배율 커브
- 슈퍼웨폰 게이지 충전량
- 드롭 아이템 배열

## 5. 시스템 간 연동 지점

| 연동 시스템 | 연동 내용 |
|-------------|-----------|
| 지상/공중 판정 분리 시스템 | 몬스터의 속성 정보 제공 |
| 보스 페이즈 시스템 | 보스 본체/파츠도 본 시스템의 기본 항목 공유 |
| 스테이지 구조 시스템 | 웨이브 데이터에서 몬스터 ID 참조, 배치 정보는 웨이브에서 결정 |
| 스코어링 시스템 | 기본 점수, 격파 속도 배율 커브 제공 |
| 슈퍼웨폰 시스템 | 슈퍼웨폰 게이지 충전량 제공 |
| 아이템 드롭 시스템 | 드롭 테이블 (드롭 아이템 배열) 제공 |
| 클리어 평가 시스템 | 격파율 집계 시 몬스터 속성 참조 |
