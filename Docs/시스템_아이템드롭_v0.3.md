**문서 종류:** P1 시스템 세부 기획

**관련 문서:** 코어시스템_생존_v0.3, 시스템_슈퍼웨폰_v0.2, 시스템_보스페이즈_v0.2

## 1. 개요

본 문서는 적 격파 시 드롭되는 **인게임 아이템 드롭 시스템**을 정의한다. 모든 아이템 드롭은 고정 드롭 방식으로 운영되며, 플레이어가 드롭 타이밍과 위치를 학습하여 공략에 활용할 수 있도록 설계한다.

인게임 화력 강화 아이템은 두지 않는다. 이 게임의 화력 판단은 출격 전 로드아웃에서 완결되며, 인게임 드롭은 생존 보조와 스코어링에 집중한다.

---

## 2. 아이템 종류

### 2.1 아이템 목록

| 아이템 | 효과 | 세분화 |
|--------|------|--------|
| 회복 아이템 | 체력 우선 회복 → 체력 만충 시 보호막 충전 | 1종 (회복량은 데이터로 설정) |
| 점수 아이템 | 스코어 획득 | 등급별 세분화 (소/중/대 등) |
| 슈퍼웨폰 충전 아이템 | 슈퍼웨폰 게이지 대량 충전 | 1종 (충전량은 데이터로 설정) |

### 2.2 점수 아이템 세분화

점수 아이템은 **등급별로 세분화**한다. 등급에 따라 획득 스코어가 달라지며, 어떤 적이 어떤 등급의 점수 아이템을 드롭하는지를 데이터로 제어한다.

구체적인 등급 수와 스코어 수치는 밸런싱 단계에서 결정한다.

### 2.3 시스템 측면의 시각 구분

세 종류 아이템(회복, 점수, 슈퍼웨폰 충전)은 **시각적으로 한눈에 구분 가능**하도록 디자인되어야 한다. 종류별 시각 디자인의 구체적 가이드는 UI 시스템 기획에서 정의한다.

## 3. 드롭 규칙

### 3.1 고정 드롭 방식

모든 아이템 드롭은 **고정 드롭**으로 운영한다. 확률 기반 드롭은 사용하지 않는다. 특정 몬스터를 격파하면 항상 동일한 아이템이 드롭된다.

### 3.2 고정 드롭을 채택한 이유

- **공략 학습:** 플레이어가 "이 적을 잡으면 여기서 회복이 나온다"를 학습하여, 아이템 획득 자체가 공략의 일부가 된다.
- **스코어 계산:** 점수 아이템의 드롭이 확정적이므로, 스코어 공략 시 총 획득 가능 점수를 사전에 계산할 수 있다.
- **아이템 분포 제어:** 스테이지 내 회복 아이템과 슈퍼웨폰 충전 아이템의 위치와 타이밍을 레벨 디자이너가 정밀하게 제어할 수 있다.

### 3.3 몬스터 데이터 분리

같은 형태(아트 프리팹)의 몬스터라도 **드롭 아이템이 다른 몬스터 데이터를 별도로 생성**하여 사용한다. 예를 들어 동일한 외형의 전투기 몬스터라도, 회복 아이템을 드롭하는 버전과 점수 아이템을 드롭하는 버전을 별도의 몬스터 데이터로 관리한다.

이를 통해:
- 동일 외형의 적을 다양한 드롭 용도로 재활용할 수 있다.
- 웨이브 데이터에서 어떤 적을 배치하느냐에 따라 아이템 분포가 자연스럽게 결정된다.

### 3.4 다중 드롭 지원

한 번의 격파로 **여러 종류의 아이템을 동시에 드롭**하는 것이 시스템적으로 지원된다. 보스 파츠 파괴처럼 강력한 적의 격파 시 회복 아이템과 점수 아이템을 동시에 드롭하는 등의 활용이 가능하다.

실제 사용 여부는 컨텐츠 디자인 단계에서 결정한다.

### 3.5 보스 본체 격파 시 드롭 미적용

보스 본체 격파 시에는 **아이템이 드롭되지 않는다.** 보스 본체 격파는 곧 스테이지 종료를 의미하므로, 이 시점의 드롭은 의미가 없다.

보스 파츠 파괴 시 드롭은 보스 페이즈 시스템에서 정의되며, 본 시스템 규칙을 따른다.

## 4. 드롭 테이블 구조

### 4.1 몬스터별 개별 드롭 테이블

모든 개별 몬스터가 **자신의 드롭 테이블**을 가진다. 스테이지 전역 드롭률이나 공용 드롭 테이블은 사용하지 않는다.

### 4.2 몬스터별 드롭 테이블을 채택한 이유

- **정밀 제어:** 아이템 드롭 타이밍, 스테이지 전체에 분포될 점수 아이템의 수량을 레벨 디자이너가 정확하게 제어할 수 있다.
- **난이도 설계:** 회복 아이템의 배치 밀도가 곧 난이도 변수가 되므로, 개별 제어가 가능해야 한다.
- **고정 드롭과의 일관성:** 고정 드롭 방식에서 몬스터별 테이블은 자연스러운 구조이다.

### 4.3 드롭 데이터 항목

몬스터 데이터에는 드롭하는 아이템 목록이 포함된다. 다중 드롭을 지원하며, 목록이 비어있으면 드롭하지 않는다. 목록의 각 항목은 드롭할 아이템과 수량(기본 1)으로 구성된다.

(본 시스템의 데이터 항목 세부 정의는 별도의 데이터 테이블 문서에서 관리한다.)

## 5. 드롭 위치 및 이동

### 5.1 드롭 위치

아이템은 **적 격파 위치에서 드롭**된다. 적이 위치한 좌표가 드롭 시작점이 된다.

### 5.2 드롭 후 이동 패턴

드롭된 아이템은 격파 지점에서 **랜덤한 방향으로 튕겨나가** 화면 내부를 이동한다.

| 단계 | 동작 |
|------|------|
| 드롭 시작 | 격파 위치에서 등장 |
| 튕김 이동 | 랜덤한 방향으로 일정 속도로 이동 |
| 화면 경계 충돌 | 벽에 부딪히면 반사되어 튕겨나옴 |

이 이동 패턴의 의미:
- 아이템이 가만히 있는 경우, 회피 동선과 일치할 때만 획득 가능하여 단조로움
- 튕김 이동을 통해 플레이어가 아이템 경로를 예측하고 미리 움직이는 판단이 생김
- 회수 동선이 다양해져 게임플레이가 풍부해짐

### 5.3 화면 밖 소멸

자동 스크롤에 의해 아이템이 화면 밖으로 밀려나면 소멸한다. 화면 영역 밖의 아이템은 획득할 수 없다.

화면 경계는 5.2에서 정의된 반사 처리와 별개로, 자동 스크롤로 인한 화면 밖 이탈에는 적용된다.

## 6. 아이템 획득 방식

### 6.1 접촉 획득

플레이어 기체가 드롭된 아이템에 **직접 접촉**해야 획득된다. 자동 흡수나 자동 획득은 지원하지 않는다.

### 6.2 접촉 획득을 채택한 이유

- **위치 판단:** 아이템을 먹으러 이동하는 과정에서 피탄 리스크가 발생하여, "지금 먹으러 갈까 vs 안전하게 회피할까"라는 판단이 생긴다.
- **회복 타이밍 선택:** 회복 아이템이 체력 우선 회복 구조이므로, 체력이 깎인 상태에서 먹을지 보호막이 깎인 상태에서 먹을지 플레이어가 타이밍을 조절할 수 있다.

### 6.3 다중 동시 획득

플레이어가 여러 아이템에 동시에 접촉하면 **모두 획득**된다. 한 번에 하나씩 획득되는 제한은 없다.

### 6.4 무적 시간 중 획득

무적 시간 중에도 아이템 획득은 정상적으로 가능하다. 무적은 적 공격에 대한 처리이며, 아이템 획득 처리와는 무관하다.

---

## 7. 아이템 체류 및 소멸

### 7.1 체류 시간

드롭된 아이템은 **일정 시간 동안 화면에 체류**한다. 체류 시간이 만료되면 아이템이 깜박이기 시작하고, 깜박임 후 소멸한다.

| 상태 | 설명 |
|------|------|
| 체류 | 드롭 후 화면에 머무름. 5.2 이동 패턴에 따라 이동 중. |
| 깜박임 | 소멸 직전 경고. 플레이어에게 "곧 사라진다"는 시각적 신호. |
| 소멸 | 아이템 제거 |

깜박임은 플레이어에게 빠른 획득을 재촉하는 시각적 신호로 작동한다.

구체적인 체류 시간 및 깜박임 시간은 프로토타입에서 결정한다.

### 7.2 회복 아이템의 시각 우선순위

여러 아이템이 화면에 동시에 존재할 때, **회복 아이템의 시인성이 최우선**으로 처리되어야 한다. 회복 아이템은 플레이어 생존에 직결되므로 다른 아이템들 사이에서도 명확히 식별 가능해야 한다.

구체적인 시각 처리(외곽선, 빛 효과 등)는 UI 시스템 기획에서 정의한다.

## 8. 시스템 간 연동 지점

| 연동 시스템 | 연동 내용 |
|-------------|-----------|
| 생존 시스템 | 회복 아이템의 체력/보호막 회복 처리 |
| 슈퍼웨폰 시스템 | 충전 아이템의 게이지 충전 처리 |
| 스코어링 시스템 | 점수 아이템의 스코어 반영 |
| 보스 페이즈 시스템 | 보스 파츠 파괴 시 아이템 드롭. 보스 본체 격파 시 드롭 없음. |
| 몬스터 데이터 | 개별 몬스터의 드롭 테이블 |
| 스테이지 구조 | 웨이브 내 몬스터 배치에 따른 아이템 분포 결정 |
