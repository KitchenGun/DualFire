## 1. 개요

본 문서는 **보스 페이즈 시스템**의 세부 설계를 정의한다. 보스전은 이 게임의 무장 시스템이 가장 강하게 발휘되는 구간이며, 본체와 파츠의 속성 구성, 페이즈 전환을 통해 플레이어에게 무장 운용 판단의 긴장감을 제공한다.

---

## 2. 보스 구성

보스는 보스 단위 정보(이름, 체력 모드, 페이즈 구성, 외형)와 페이즈별 본체+파츠 세트로 구성된다.

- **본체**는 속성(지상/공중/양면), 체력, 콜리전 영역(모델 전체가 아닌 별도 정의), 공격 패턴을 가진다. 본체 체력은 페이즈 전환과 격파 판정의 기준이다 (5장 참고).
- **파츠**는 속성, 파괴 판정용 체력(보스 총 체력과 별개, 3장 참고), 보스 내 배치 위치, 공격 패턴, 파괴 가능 여부, 재생 여부와 재생 시간, 파괴 시 스코어와 아이템 드롭, 파괴 시 페이즈 전환 트리거 여부를 가진다.

(본 시스템의 데이터 항목 세부 정의는 별도의 데이터 테이블 문서에서 관리한다.)

---

## 3. 체력 구조

### 3.1 핵심 원칙

보스의 체력 구조는 다음 원칙을 따른다.

1. **보스 총 체력 = 본체 체력** (단일 게이지)
2. 파츠는 고유 체력을 가지며, 이 체력이 0이 되면 해당 파츠가 파괴
3. 파츠가 받는 데미지를 본체가 동일하게 받음
4. 파괴된 파츠는 더 이상 데미지를 받을 수 없음 (재생 가능한 파츠는 재생 후 위 규칙을 다시 따름)
5. 본체 체력이 0이 되면 보스 격파

### 3.2 데미지 적용 흐름

플레이어가 보스에게 데미지를 줄 때:

| 공격 대상 | 데미지 적용 |
|-----------|-------------|
| 본체 직접 공격 | 본체 체력 감소 |
| 살아있는 파츠 공격 | 해당 파츠 체력 감소 + 본체 체력 동일 데미지 감소 |
| 파괴된 파츠 공격 | 데미지 적용 안 됨 (콜리전이 비활성 상태이므로 탄환 관통) |

### 3.3 파츠 파괴의 게임플레이 의미

파츠 파괴는 다음 효과를 가진다.

- **공격 패턴 무력화:** 해당 파츠의 공격이 중단됨
- **스코어 획득:** 파츠 파괴 스코어 + 아이템 드롭 가능
- **데미지 루트 차단:** 그 파츠를 통한 본체 데미지 루트가 닫힘. 살아있는 다른 파츠나 본체를 공격해야 함

플레이어는 "파츠 파괴를 통한 패턴 무력화 + 스코어"와 "파츠를 공격해 본체 데미지 누적"의 두 가지 가치를 모두 추구할 수 있다. 재생 가능한 파츠라면 파괴 후 재생을 활용하여 두 가치를 동시에 노릴 수 있다.

### 3.4 파츠 재생

일부 파츠는 파괴 후 일정 시간이 지나면 재생된다. 재생 여부와 재생 시간은 파츠 데이터로 설정한다.

- 파괴된 파츠는 재생 시간 동안 비활성 상태 (콜리전 사라지고 탄환 관통, 공격 패턴 중단)
- 재생 시간 경과 시 파츠 체력 최대치로 복구되며 활성화
- 재생 후에는 다시 데미지를 받을 수 있으며, 본체에도 데미지가 누적됨

## 4. 페이즈 시스템

### 4.1 페이즈 = 본체+파츠 세트

각 페이즈는 **고유한 본체와 파츠 세트**를 가진다. 페이즈 전환 시 이전 페이즈의 본체+파츠는 사라지고 새로운 본체+파츠가 등장한다. 활성/비활성 토글이 아닌, 새 세트 교체 방식이다.

### 4.2 페이즈 구성

각 페이즈는 페이즈 순번, 해당 페이즈의 본체와 파츠 목록(2장 참고), 다음 페이즈로의 전환 조건(5장 참고), 페이즈 종료 시 재생되는 전환 연출(변신/폭발/새 등장 등)로 구성된다.

### 4.3 페이즈 유형의 자연스러운 결정

각 페이즈의 성격(양면/공중 전용/지상 전용)은 본체와 파츠의 속성 구성으로 자연스럽게 결정된다.

| 페이즈 유형 | 본체+파츠 속성 구성 예시 |
|-------------|---------------------------|
| 양면 페이즈 | 본체 양면(지상+공중) 또는 지상/공중 파츠 모두 존재 |
| 공중 전용 페이즈 | 본체 공중 + 파츠 공중 |
| 지상 전용 페이즈 | 본체 지상 + 파츠 지상 |

페이즈 유형은 시스템이 강제하는 분류가 아니라 데이터의 결과로 나타난다.

### 4.4 페이즈 보유 수

보스는 **최소 2페이즈 이상**으로 구성한다. 페이즈 수에 상한선은 두지 않으며, 보스마다 자유롭게 설정 가능하다.

## 5. 페이즈 전환

### 5.1 체력 모드 (보스별 선택)

보스는 데이터에서 두 가지 체력 모드 중 하나를 선택한다. 페이즈 전환 메커니즘이 모드에 따라 달라진다.

#### 5.1.1 모드 A: 통합 체력 (페이즈 공유)

- 보스가 단일 본체 체력을 가지며, 모든 페이즈가 이를 공유
- 페이즈 전환 시 본체 체력은 그대로 이어감
- 페이즈 1에서 30% 깎였으면 페이즈 2 시작 시 70%에서 시작
- **페이즈 전환 조건:** 체력 임계값 (예: 70%, 30%)
- **연출 컨셉:** 보스가 점점 변형되어가는 진화 느낌

#### 5.1.2 모드 B: 페이즈별 독립 체력

- 각 페이즈가 자기만의 본체 체력 풀을 가짐
- 한 페이즈의 본체 체력이 0이 되면 다음 페이즈로 전환, 새 본체 체력으로 다시 시작
- **페이즈 전환 조건:** 페이즈 본체 체력 0 도달
- **연출 컨셉:** 단계마다 새로운 적이 등장하는 다단 보스 느낌

### 5.2 추가 전환 트리거 (선택적)

기본 전환 조건(체력 모드에 따른 체력 트리거) 외에, 다음과 같은 추가 트리거를 데이터로 설정할 수 있다.

- **파츠 파괴 트리거:** 특정 파츠 파괴 시 페이즈 전환
- **시간 트리거:** 페이즈 진입 후 일정 시간 경과 시 페이즈 전환

이 트리거들은 기본 체력 트리거와 함께 사용 가능하며, 어느 조건이든 먼저 충족되면 페이즈가 전환된다.

### 5.3 페이즈 전환 시 상태 처리

페이즈 전환이 발생하면 다음 처리가 이루어진다.

| 항목 | 처리 |
|------|------|
| 이전 페이즈의 본체+파츠 | 사라짐 (연출에 따라 폭발/변신 등) |
| 이전 페이즈의 파괴된 파츠 | 자연스럽게 사라짐 (다음 페이즈에서 의미 없음) |
| 이전 페이즈의 재생 대기 중 파츠 | 재생 타이머 무효화 (다음 페이즈에서 사라짐) |
| 새 페이즈의 본체+파츠 | 등장. 새 페이즈의 데이터 기반으로 초기화. |
| 본체 체력 | 모드 A: 이어감 / 모드 B: 새 본체의 최대 체력 |

### 5.4 전환 중 보스 상태

페이즈 전환 중 보스(이전 본체+파츠 및 새 본체+파츠 모두)는 **반드시 무적**이다. 전환 연출이 끝날 때까지 플레이어의 공격이 데미지를 주지 않는다. 이는 전환 연출 중에 딜이 들어가 다음 페이즈가 스킵되는 것을 방지한다.

### 5.5 전환 중 플레이어 상태

페이즈 전환 중 플레이어의 조작 가능 여부는 **연출에 따라 데이터로 설정**한다.

| 항목 | 설정 가능 값 |
|------|-------------|
| 플레이어 이동 | 가능 / 불가 |
| 플레이어 공격 | 가능 / 불가 |
| 적 잡몹 출현 | 유지 / 중단 |

연출이 짧은 경우 조작을 허용하고, 카메라 이동이나 컷씬이 포함된 긴 연출에서는 조작을 제한할 수 있다.

### 5.6 시각적 신호

페이즈 전환은 보스의 변신/폭발/새 등장 연출로 플레이어에게 전달된다. 스트라이커즈 1945의 보스 변신 연출(레일 위 열차 → 로봇 비행)처럼, 보스의 형태 변화 자체가 "지금부터 무장 전략을 바꿔야 한다"는 신호가 된다. 3D 모델을 활용하여 다양한 변신/등장 연출을 풍부하게 표현한다.

## 6. 보스전 중 아이템 드롭 및 잡몹

### 6.1 파츠 파괴 시 아이템 드롭

파츠 파괴 시 아이템 드롭 여부와 내용은 파츠 데이터에서 설정한다. 시스템적으로 드롭을 지원하며, 실제 사용 여부는 밸런싱 시 결정한다.

### 6.2 보스전 중 잡몹 출현

보스전 중 잡몹이 출현하는 것도 시스템적으로 지원한다. 보스의 페이즈 데이터 또는 공격 패턴에서 잡몹 스폰을 호출할 수 있다. 실제 사용 여부는 밸런싱 시 결정한다.

잡몹 출현 시 슈퍼웨폰 게이지 충전원이 확보되므로, 보스전 중 슈퍼웨폰 운용에 영향을 줄 수 있다.

## 7. 보스와 스코어링

### 7.1 스코어 항목

| 항목 | 설명 |
|------|------|
| 보스 격파 스코어 | 본체 체력을 0으로 만들어 격파 시 획득 |
| 파츠 파괴 스코어 | 개별 파츠 파괴 시 획득. 파츠별 차등. |
| 노데스 클리어 보너스 | 미션 전체에서 사망 없이 클리어 시 추가 스코어 |

### 7.2 파츠 파괴 스코어의 역할

파츠 파괴 스코어는 플레이어에게 "파츠를 노려서 파괴하는" 추가 목표를 제공한다. 특히 재생 파츠의 경우, 재생되기 전후로 반복 파괴하면 스코어를 중복 획득할 수 있어 스코어 공략의 깊이가 생긴다.

## 8. 시스템 간 연동 지점

| 연동 시스템 | 연동 내용 |
|-------------|-----------|
| 지상/공중 판정 분리 시스템 | 본체/파츠별 속성 태그, 관통 방식 판정 적용 |
| 스테이지 구조 | 스테이지 최종 보스로 연결, 보스 진입 트리거에서 호출 |
| 슈퍼웨폰 시스템 | 보스전 중 슈퍼웨폰 운용, 잡몹 격파 시 게이지 충전 |
| 스코어링 시스템 | 보스 격파/파츠 파괴/노데스 스코어 |
| 인게임 아이템 드롭 | 파츠 파괴 시 아이템 드롭 |
| 클리어 평가 시스템 | 보스 격파/파츠 파괴는 격파율 평가 미포함, 스코어링 시스템으로만 반영 |
| 난이도 시스템 | 난이도별 보스 패턴/페이즈 변화 (Nightmare 차별화의 핵심) |
| 미션 브리핑 시스템 | 보스 정보는 브리핑에서 비노출. 보스 변화는 본 시스템에서 처리. |

## 10. 확정 사항 요약

| 항목 | 결정 사항 |
|------|-----------|
| 페이즈 모델 | 페이즈 전환 = 새 본체+파츠 세트 등장 (활성/비활성 토글 아님) |
| 보스 구성 | 페이즈마다 본체+파츠 세트 보유. 본체와 파츠는 각각 독립적으로 관리. |
| 본체 속성 | 단일 또는 양면 |
| 파츠 속성 | 단일 또는 양면 |
| 체력 구조 | 보스 총 체력 = 본체 체력. 파츠는 별도 체력 (파괴 판정용). |
| 데미지 적용 | 파츠 공격 = 파츠 체력 + 본체 체력 동시 감소. 파괴된 파츠는 데미지 통과 안 됨. |
| 보스 격파 | 본체 체력 0 도달 시 |
| 페이즈 수 | 최소 2페이즈 이상 (상한 없음) |
| 체력 모드 | 보스별 선택. 모드 A 통합 / 모드 B 페이즈별 독립. |
| 전환 트리거 | 기본 = 체력 트리거 (모드에 따라 다름). 추가 = 파츠 파괴 트리거 / 시간 트리거 (선택적). |
| 전환 시 파츠 상태 | 이전 페이즈의 파괴/재생 대기 상태는 자연스럽게 무효화 |
| 전환 중 보스 상태 | 반드시 무적 |
| 전환 중 플레이어 상태 | 연출에 따라 데이터로 설정 |
